# Multilingual Learner Program Guide Skill

## Step 1 — Gather Inputs

- School demographics and languages
- Program model: sheltered/bilingual/dual-language
- Staffing and resources
- State requirements
- Family engagement goals

## Step 2 — Core Output

Program guide: Model selection rationale → Student identification and placement → Service delivery structure → Instructional approach per level → Family communication in home languages → Teacher professional development plan → Progress monitoring system → Program evaluation metrics. Home language as asset — not deficit.

## Step 3 — Quality & Polish

- Home language treated as asset throughout
- Family engagement in home language — not just translated notices
- Program evaluation includes language AND academic outcomes

Always offer a relevant next step.
