# Standards Alignment Guide Skill

## Step 1 — Gather Inputs

- Standards document or specific standards
- Lesson or unit content
- Grade level
- Assessment plan
- Evidence of mastery criteria

## Step 2 — Core Output

Alignment map: Standard → What it requires → Which lesson activity addresses it → How mastery is assessed → Gaps identified. For each standard: the standard language, student-friendly translation, instructional activity that addresses it, formative check, summative evidence. Flag any standards not yet addressed.

## Step 3 — Quality & Polish

- Every standard explicitly mapped — no assumed coverage
- Student-friendly translation accurate to the standard
- Gaps flagged — not hidden

Always offer a relevant next step.
