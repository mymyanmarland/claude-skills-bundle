# Social-Emotional Learning Integrator Skill

## Step 1 — Gather Inputs

- Grade level
- Subject context
- SEL competencies to focus: self-awareness/self-management/social awareness/relationship skills/responsible decision-making
- Academic content to connect with
- Time allocation

## Step 2 — Core Output

SEL integration plan: CASEL competency → Academic connection point → Integrated activity (academic + SEL simultaneously) → Discussion protocol → Individual reflection → Check-in/check-out tools → Explicit instruction moments (when SEL is foregrounded) vs embedded (when in background). Weekly SEL touchpoint schedule.

## Step 3 — Quality & Polish

- SEL integrated with academics — not separate add-on
- Explicit instruction of skills before expected use
- Check-in tools practical for daily use

Always offer a relevant next step.
