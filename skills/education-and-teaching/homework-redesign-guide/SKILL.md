# Homework Redesign Guide Skill

## Step 1 — Gather Inputs

- Grade level
- Current homework practices
- Equity concerns
- Family capacity context
- Learning goals homework should serve

## Step 2 — Core Output

Homework redesign: Audit current homework purpose (practice/preview/extension) → Equity audit (what does this assume about home?) → Redesigned homework types with clear purpose → Student choice options → Non-completion protocol (inquiry not punishment) → Communication to families → Grade book integration → Research base for recommendations.

## Step 3 — Quality & Polish

- Purpose of each homework type explicit
- Equity lens applied to each assignment type
- Non-completion protocol starts with curiosity — not consequences

Always offer a relevant next step.
