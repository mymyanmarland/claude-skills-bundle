# Learning Objective Writer Skill

## Step 1 — Gather Inputs

- Topic being taught
- Grade level
- Standards addressed
- Assessment planned
- Time frame for the lesson/unit

## Step 2 — Core Output

Learning objectives using SWBAT format (Students will be able to...) at multiple Bloom's levels: Knowledge level (identify, define, recall) → Comprehension (explain, describe) → Application (demonstrate, use, solve) → Analysis (compare, differentiate) → Evaluation (justify, assess) → Creation (design, create). 2-3 objectives per lesson, 5-8 per unit. Each measurable and observable.

## Step 3 — Quality & Polish

- Every objective measurable — 'understand' not acceptable alone
- Verb matches Bloom's level accurately
- Assessment implied by objective verb choice

Always offer a relevant next step.
