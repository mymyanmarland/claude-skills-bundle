# Montessori Activity Designer Skill

## Step 1 — Gather Inputs

- Age group (3-6/6-12/12-18)
- Curriculum area: practical life/sensorial/language/math/cultural
- Concept to introduce
- Materials available
- Independence level

## Step 2 — Core Output

Montessori activity design: Material description and presentation → Three-period lesson script (naming/recognition/recall) → Control of error built in → Extensions for each level → Shelf placement and organization → Observation notes template → Mastery indicators. Self-correction key feature — teacher not needed to tell if correct.

## Step 3 — Quality & Polish

- Self-correction built into material — not teacher-dependent
- Three-period lesson carefully sequenced
- Extensions maintain child's intrinsic motivation

Always offer a relevant next step.
