# Rubric Designer Skill

## Step 1 — Gather Inputs

- Assignment type
- Grade level
- Learning standards addressed
- Number of criteria
- Scale: 4-point/percentage/pass-fail

## Step 2 — Core Output

Rubric with 4-6 criteria rows × 4 performance levels. Each cell: specific, observable descriptors (not vague like 'excellent'). Headers: Exceeds/Meets/Approaching/Beginning or 4/3/2/1. Student-friendly language. Total points calculation. Can be used for self-assessment and peer assessment. Include one-point analytic or holistic option.

## Step 3 — Quality & Polish

- Every descriptor specific and observable — no vague language
- Student can self-assess using this rubric
- Performance levels genuinely different — not just more/fewer errors

Always offer a relevant next step.
