# Tech Integration Lesson Planner Skill

## Step 1 — Gather Inputs

- Lesson topic and objective
- Technology available
- Current tech use level (substitution vs transformation)
- Student tech proficiency
- Learning goal that tech should enhance

## Step 2 — Core Output

Tech integration plan: SAMR level analysis (current vs target) → Tool selection rationale → Student activity with tech (not just teacher presentation) → Learning enhancement explanation (what does tech enable that couldn't happen without it?) → Digital citizenship connection → Backup plan if tech fails → Assessment of learning (not just tech use).

## Step 3 — Quality & Polish

- Technology enhances learning — doesn't just substitute analog activity
- Students use tech actively — not just consume
- Assessment measures learning — not tech proficiency

Always offer a relevant next step.
