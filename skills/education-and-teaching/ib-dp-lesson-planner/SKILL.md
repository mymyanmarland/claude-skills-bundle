# IB/DP Lesson Planner Skill

## Step 1 — Gather Inputs

- Subject and level: MYP/DP
- Key and related concepts
- Global context or topic
- ATL skills to develop
- Assessment criteria

## Step 2 — Core Output

IB-aligned lesson: Key concept connection → Related concepts (2-3) → Global context application → Statement of inquiry → ATL skills (which and how developed) → Learning activities (inquiry-based) → Formative task → Connection to summative criteria. Inquiry cycle embedded.

## Step 3 — Quality & Polish

- Statement of inquiry genuine — not just topic restated
- ATL skills developed explicitly — not assumed
- Assessment criteria referenced in lesson activities

Always offer a relevant next step.
