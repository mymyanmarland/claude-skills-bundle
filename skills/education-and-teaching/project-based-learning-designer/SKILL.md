# Project-Based Learning Designer Skill

## Step 1 — Gather Inputs

- Subject and grade level
- Standards to address
- Time available
- Community or authentic audience access
- Student interest areas

## Step 2 — Core Output

PBL design: Driving question (real, open-ended, student-relevant) → Entry event (hook that creates need to know) → Need-to-know list (students generate) → Learning milestones (4-6 checkpoints) → Product/presentation description → Authentic audience plan → Reflection protocol → Rubric outline. Buck Institute Gold Standard PBL principles applied.

## Step 3 — Quality & Polish

- Driving question genuinely open — no single right answer
- Entry event creates authentic need to know
- Authentic audience outside the classroom

Always offer a relevant next step.
