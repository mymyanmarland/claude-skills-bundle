# Cooperative Learning Activity Designer Skill

## Step 1 — Gather Inputs

- Lesson topic and objective
- Group size
- Cooperative structure: Jigsaw/Numbered Heads/Gallery Walk/Stations
- Available time
- Individual accountability method

## Step 2 — Core Output

Cooperative activity: Structure explanation → Group composition guidance → Role cards (if applicable) → Task instructions (each phase) → Individual accountability component → Group product description → Debrief questions. Positive interdependence built in — groups only succeed together. Individual accountability ensures everyone contributes.

## Step 3 — Quality & Polish

- Positive interdependence built in — not just group work
- Individual accountability prevents social loafing
- Debrief connects activity to learning objective

Always offer a relevant next step.
