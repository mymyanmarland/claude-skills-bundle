# Differentiated Instruction Planner Skill

## Step 1 — Gather Inputs

- Lesson topic and grade
- Student ability range
- Learning modalities in the class
- Available resources
- Time constraints

## Step 2 — Core Output

Differentiation plan: Core concept all students must master → Scaffolded version (step-by-step support, visual aids, sentence frames) → Grade-level version (standard instruction) → Extension version (deeper thinking, creative application). For each: specific activity, materials, success criteria. Grouping strategy included.

## Step 3 — Quality & Polish

- All versions address same core standard
- Scaffolded version genuinely accessible — not just simpler
- Extension genuinely extends — not just more work

Always offer a relevant next step.
