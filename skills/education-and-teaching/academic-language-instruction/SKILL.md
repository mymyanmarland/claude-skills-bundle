# Academic Language Instruction Skill

## Step 1 — Gather Inputs

- Content area
- Grade level
- Language demands: vocabulary/syntax/discourse
- Student language backgrounds
- Assessment of current academic language

## Step 2 — Core Output

Academic language instruction: Demand analysis (what language does this content require?) → Word-level instruction (Tier 2 and 3 vocabulary, morphology) → Sentence-level structures (discipline-specific syntax) → Discourse-level (how to participate in [subject] conversation) → Sentence frames and starters → Practice activities → Assessment of language use.

## Step 3 — Quality & Polish

- Language demands specific to content analyzed before instruction
- Sentence frames support production — not just comprehension
- Academic language assessed in context — not isolation

Always offer a relevant next step.
