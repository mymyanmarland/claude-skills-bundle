# Unit Plan Builder Skill

## Step 1 — Gather Inputs

- Topic and grade level
- Number of weeks
- Standards to address
- Available resources and technology
- Summative assessment type

## Step 2 — Core Output

Unit plan: Essential questions (2-3 that frame the unit) → Enduring understandings (what students remember in 10 years) → Daily lesson arc (topic per day/week) → Formative assessment checkpoints → Summative assessment description → Resource list → Differentiation notes. Backward design: start with summative, work backward.

## Step 3 — Quality & Polish

- Essential questions genuinely open and worth exploring
- Formative assessments inform instruction — not just grades
- Unit builds toward summative — skills scaffolded progressively

Always offer a relevant next step.
