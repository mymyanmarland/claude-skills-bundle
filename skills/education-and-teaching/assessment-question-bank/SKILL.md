# Assessment Question Bank Skill

## Step 1 — Gather Inputs

- Subject and topic
- Grade level
- Bloom's taxonomy levels to include
- Question types needed
- Number of questions

## Step 2 — Core Output

Question bank organized by Bloom's level: Remember (recall, define, list) → Understand (explain, summarize, classify) → Apply (use, solve, demonstrate) → Analyze (compare, examine, differentiate) → Evaluate (judge, justify, critique) → Create (design, construct, compose). 5 questions per level minimum. Answer key with explanations.

## Step 3 — Quality & Polish

- Questions distributed across Bloom's levels — not all recall
- Each question has one clearly correct answer (for objective items)
- Answer key includes explanation for why correct answer is right

Always offer a relevant next step.
