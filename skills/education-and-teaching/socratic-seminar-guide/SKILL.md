# Socratic Seminar Guide Skill

## Step 1 — Gather Inputs

- Text or topic for discussion
- Grade level
- Class experience with Socratic seminar
- Discussion goals
- Assessment focus: participation/thinking/listening

## Step 2 — Core Output

Seminar guide: Pre-seminar preparation (text annotation protocol, personal position statement) → Opening question (text-grounded, no single answer) → 8-10 seminar questions in progression → Probing follow-up questions → Fishbowl structure if needed → Observation/assessment tool → Post-seminar reflection → Norms co-creation process.

## Step 3 — Quality & Polish

- Questions text-grounded — must cite evidence to answer
- No yes/no questions in the seminar
- Assessment focuses on quality of thinking — not number of contributions

Always offer a relevant next step.
