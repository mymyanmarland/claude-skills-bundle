# Classroom Discussion Facilitator Skill

## Step 1 — Gather Inputs

- Discussion topic
- Grade level and class size
- Discussion protocol: Socratic/Fishbowl/Think-Pair-Share/Philosophical Chairs
- Prior knowledge of students
- Discussion goal: explore/debate/analyze

## Step 2 — Core Output

Discussion plan: Pre-discussion reading or preparation (what students need beforehand) → Opening question (low-stakes, everyone can answer) → Core questions (4-6 in ascending depth) → Devil's advocate questions (challenge comfortable consensus) → Synthesis question → Facilitation notes (what to do if discussion stalls/dominates) → Assessment criteria.

## Step 3 — Quality & Polish

- Opening question genuinely accessible to all
- Core questions increase in cognitive demand
- Facilitation notes anticipate common discussion problems

Always offer a relevant next step.
