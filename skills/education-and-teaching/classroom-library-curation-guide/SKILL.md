# Classroom Library Curation Guide Skill

## Step 1 — Gather Inputs

- Grade level
- Available budget
- Current library gaps
- Student demographics
- Reading level range in class

## Step 2 — Core Output

Curation guide: Mirror/window/sliding glass door framework → Genre balance recommendations → Reading level distribution → Diversity audit tool (representation checklist) → High-interest titles by category → Book acquisition strategies (grants, Donors Choose, used book sources) → Book display and access design → Student choice integration.

## Step 3 — Quality & Polish

- Mirror/window framework applied specifically to the student population
- Diversity audit honest about current gaps
- Budget-conscious acquisition strategies included

Always offer a relevant next step.
