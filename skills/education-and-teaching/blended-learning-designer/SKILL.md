# Blended Learning Designer Skill

## Step 1 — Gather Inputs

- Blended model: station rotation/flipped/flex/enriched virtual
- Grade level and subject
- Technology available
- Learning objectives
- Student autonomy level

## Step 2 — Core Output

Blended learning design: Model selection with rationale → Online component design (what happens digitally and why) → Face-to-face component design (what requires human interaction) → Student navigation and pacing → Data from online informs face-to-face (the key to blended success) → Assessment across modes → Contingency plan if tech fails.

## Step 3 — Quality & Polish

- Online and face-to-face components genuinely complementary
- Data from online platform informs next day's instruction
- Tech failure plan exists and is practiced

Always offer a relevant next step.
