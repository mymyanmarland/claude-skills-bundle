# Data-Driven Instruction Guide Skill

## Step 1 — Gather Inputs

- Assessment data available
- Learning standards assessed
- Student performance patterns
- Instructional response options
- Grouping flexibility

## Step 2 — Core Output

DDI cycle: Data collection and organization → Data analysis protocol (what patterns emerge, who needs what) → Instructional response plan (re-teach/extension/intervention groups) → Progress monitoring plan → Re-assessment timeline. Data analysis protocol asks: what did students do well, what's the error pattern, what's the instructional implication.

## Step 3 — Quality & Polish

- Analysis identifies error patterns — not just percent correct
- Instructional response specific to error type
- Progress monitoring scheduled — not just end-of-unit test

Always offer a relevant next step.
