# Formative Assessment Toolkit Skill

## Step 1 — Gather Inputs

- Subject and grade level
- Lesson type
- Time available for check-ins
- Technology availability
- Learning objectives to check

## Step 2 — Core Output

Toolkit of 15 formative strategies: Exit tickets (3 types) → Whiteboards/show me → Thumbs/traffic light → Think-pair-share → Mini-whiteboards → Fist to five → Four corners → Quick write → 3-2-1 reflection → Partner quiz → Misconception hunt → Muddiest point → Plus-delta → Tweet summary → Error analysis. Each: when to use, how to run it, what to look for, response protocol.

## Step 3 — Quality & Polish

- Each strategy assesses specific learning — not just engagement
- Response protocol included — what to do with data
- Strategies varied: verbal/written/movement

Always offer a relevant next step.
