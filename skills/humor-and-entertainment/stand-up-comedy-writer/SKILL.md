# Stand-Up Comedy Writer Skill

## Step 1 — Gather Inputs

- Topic, occasion, or subject matter
- Target audience and context
- Tone: gentle/cutting/absurdist/observational
- Constraints or sensitivities
- Goal: entertain/roast/satirize/educate

## Step 2 — Core Output

Stand-up material: Premise → Setup (shortest path to punchline) → Punchline (subverted expectation) → Tags (additional punchlines) → Act-outs → Callbacks → Set structure (opener/body/closer). Every joke earns its word count.

## Step 3 — Quality & Polish

- Setup shortest path to punchline — economy of language
- Tags extend the laugh beyond initial punchline
- Callbacks reward attentive audience — plan from start

Always offer a relevant next step.
