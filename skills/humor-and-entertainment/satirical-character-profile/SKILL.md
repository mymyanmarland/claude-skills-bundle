# Satirical Character Profile Writer Skill

## Step 1 — Gather Inputs

- Topic, occasion, or subject matter
- Target audience and context
- Tone: gentle/cutting/absurdist/observational
- Constraints or sensitivities
- Goal: entertain/roast/satirize/educate

## Step 2 — Core Output

Satirical profile: Type distilled to essence → Signature phrases → Natural habitat → Behavioral quirks → Self-perception vs reality → Social media relationship → Response to criticism. Satire works when the type recognizes themselves.

## Step 3 — Quality & Polish

- Type distilled — recognizable without naming names
- Self-perception vs reality gap — the comic engine
- Type recognizes themselves — best satire is a mirror

Always offer a relevant next step.
