# Late Night Monologue Writer Skill

## Step 1 — Gather Inputs

- Topic, occasion, or subject matter
- Target audience and context
- Tone: gentle/cutting/absurdist/observational
- Constraints or sensitivities
- Goal: entertain/roast/satirize/educate

## Step 2 — Core Output

Late night monologue: Topical premise → Setup (what everyone knows) → Angle (unexpected take) → Punchline → Tag → Callback potential → Running theme across 5-7 jokes → Button joke (strongest closer).

## Step 3 — Quality & Polish

- Angle unexpected — not what everyone already said
- Tags extend without repeating
- Button joke strongest — monologue memory lives here

Always offer a relevant next step.
