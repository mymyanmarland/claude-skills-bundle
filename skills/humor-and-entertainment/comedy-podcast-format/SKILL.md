# Comedy Podcast Format Designer Skill

## Step 1 — Gather Inputs

- Topic, occasion, or subject matter
- Target audience and context
- Tone: gentle/cutting/absurdist/observational
- Constraints or sensitivities
- Goal: entertain/roast/satirize/educate

## Step 2 — Core Output

Comedy podcast design: Show concept → Host dynamic (roles and chemistry) → Recurring segments → Guest format → Listener interaction → Episode length → Cold open → Closing bit → Show bible.

## Step 3 — Quality & Polish

- Show concept specific — vague podcasts fail
- Recurring segments — what listeners return for
- Chemistry dynamics — roles clear between hosts

Always offer a relevant next step.
