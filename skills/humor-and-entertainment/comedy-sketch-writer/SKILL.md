# Comedy Sketch Writer Skill

## Step 1 — Gather Inputs

- Topic, occasion, or subject matter
- Target audience and context
- Tone: gentle/cutting/absurdist/observational
- Constraints or sensitivities
- Goal: entertain/roast/satirize/educate

## Step 2 — Core Output

Sketch structure: The game (one funny idea everything escalates from) → Establish normal → First unusual thing → Escalation beats → Height (most absurd) → Button (final ending). If you cannot state the game in one sentence, the sketch is not ready.

## Step 3 — Quality & Polish

- The game clear — the sketch engine
- Escalation beats each funnier — not repetition
- Button strong — sketches often fall apart at the end

Always offer a relevant next step.
