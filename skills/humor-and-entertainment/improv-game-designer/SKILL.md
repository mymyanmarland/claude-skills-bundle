# Improv Game Designer Skill

## Step 1 — Gather Inputs

- Topic, occasion, or subject matter
- Target audience and context
- Tone: gentle/cutting/absurdist/observational
- Constraints or sensitivities
- Goal: entertain/roast/satirize/educate

## Step 2 — Core Output

Improv game design: Game concept (skill being built) → Rules (simple enough to explain in 60 seconds) → Trigger mechanism → Escalation structure → Failure mode and recovery → Group size → Debrief questions → Variations. Rules create freedom, not restriction.

## Step 3 — Quality & Polish

- Rules simple enough to explain in 60 seconds
- Failure mode addressed — improv needs graceful exits
- Debrief questions extract learning from play

Always offer a relevant next step.
