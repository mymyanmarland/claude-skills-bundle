# Game Show Format Designer Skill

## Step 1 — Gather Inputs

- Topic, occasion, or subject matter
- Target audience and context
- Tone: gentle/cutting/absurdist/observational
- Constraints or sensitivities
- Goal: entertain/roast/satirize/educate

## Step 2 — Core Output

Game show design: Core mechanic → Round structure → Scoring system → Host scripts → Audience participation → Drama amplification (music/countdown/reveal) → Prize structure → Risk element. Simple rules, infinite variety.

## Step 3 — Quality & Polish

- Core mechanic simple — complexity kills game shows
- Drama amplification specific — the host toolkit
- Risk element creates audience investment

Always offer a relevant next step.
