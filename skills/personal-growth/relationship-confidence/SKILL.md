# Relationship Confidence Guide Skill

## Step 1 — Gather Inputs

- Current situation and specific challenge
- Previous attempts and what happened
- Goals and desired outcome
- Relevant life context
- Support available

## Step 2 — Core Output

Relationship confidence: Attachment styles overview → Core wound identification → Security from within (not from partner behavior) → Self-soothing for relationship anxiety → Secure base script → Communication from security vs fear → Neediness vs genuine need distinction → Earned security development.

## Step 3 — Quality & Polish

- Security from within — not dependent on partner behavior
- Neediness vs genuine need distinction important
- Earned security is possible with any attachment style

Always offer a relevant next step.
