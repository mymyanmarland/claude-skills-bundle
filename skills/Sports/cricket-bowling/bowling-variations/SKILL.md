# Bowling Variations Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Bowling variations: Off-cutter (seam cut off-side) → Leg-cutter (seam cut leg-side) → Knuckleball (ball on knuckle joints) → Back-of-hand slower ball → Bouncer variations (into body vs away) → Wide yorker → Spin variations (arm ball, flipper) → Set up with stock ball before using variation → Concealment: same run-up, same action, different release only.

## Step 3 — Quality & Polish

- Set up variations with stock ball — variation first is predictable
- Same action for all variations — different release only
- Practise variations in nets before match use

Always offer a relevant next step or drill to practise.
