# Video Analysis Guide Skill

## Step 1 — Gather Inputs

- Sport and competitive level
- Current data collection methods
- Technical capability of coaching staff
- Budget for analytics tools
- Specific performance questions to answer

## Step 2 — Core Output

Video analysis: Camera placement (fixed wide-angle for tactical / close for technical) → Tagging software (Hudl / Dartfish / Coach's Eye — label key events for quick review) → Review process (coach reviews first / select key clips / present to athlete within 24 hours) → The feedback sandwich (show a positive → identify the improvement → show the positive again) → Athlete self-review (athletes improve faster when they see themselves) → Clip length (30-90 seconds — longer clips lose attention).

## Step 3 — Quality & Polish

- Athlete self-review: fastest learning tool in video analysis — they see what coaching cannot describe
- 24-hour review: longer gaps reduce relevance of the footage
- 30-90 second clips: longer loses athlete attention — short and purposeful

Always offer a relevant next step or drill to practise.
