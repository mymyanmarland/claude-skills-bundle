# Match Analysis for Coaches Skill

## Step 1 — Gather Inputs

- Sport and competitive level
- Current data collection methods
- Technical capability of coaching staff
- Budget for analytics tools
- Specific performance questions to answer

## Step 2 — Core Output

Match analysis: Analysis framework (what are you looking for before watching?) → Attacking KPIs (shots on target / chances created / final third entries / set piece execution) → Defensive KPIs (tackles won / high turnovers / set piece conceded) → Pattern identification (what happens repeatedly — positive and negative) → Opposition analysis (their strengths, weaknesses, patterns) → Training response (session after analysis addresses findings).

## Step 3 — Quality & Polish

- Define what you are looking for before watching: aimless viewing finds nothing
- Pattern identification: one occurrence is noise — three is a pattern
- Training response: analysis only valuable if it changes what you train

Always offer a relevant next step or drill to practise.
