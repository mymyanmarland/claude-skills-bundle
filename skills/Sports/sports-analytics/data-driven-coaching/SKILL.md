# Data-Driven Coaching Skill

## Step 1 — Gather Inputs

- Sport and competitive level
- Current data collection methods
- Technical capability of coaching staff
- Budget for analytics tools
- Specific performance questions to answer

## Step 2 — Core Output

Data-driven coaching: The data-eye-heart model (data + observation + player input = best decisions) → Where data helps most (load monitoring / identifying patterns / talent comparison / tracking improvement) → Where data misleads (small samples / missing context / measuring what is easy not what matters) → Athlete communication (share relevant data with athletes — avoid data overload) → Building a data culture (every staff member understands what and why) → Data literacy for coaches.

## Step 3 — Quality & Polish

- Data-eye-heart model: no single source tells the full story
- Small sample warning: resist acting on 3 games of data
- Share data with athletes: athletes who see their data take more ownership

Always offer a relevant next step or drill to practise.
