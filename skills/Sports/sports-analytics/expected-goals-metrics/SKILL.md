# Expected Goals and Advanced Metrics Skill

## Step 1 — Gather Inputs

- Sport and competitive level
- Current data collection methods
- Technical capability of coaching staff
- Budget for analytics tools
- Specific performance questions to answer

## Step 2 — Core Output

Advanced metrics: Expected Goals xG (the probability that a shot results in a goal based on historical data from similar situations) → xG vs actual goals (over or under-performing xG reveals finishing quality or luck) → Expected Assists xA → PPDA (passes per defensive action — pressing efficiency) → Progressive passes and carries → Limiting factors (these metrics work best with large sample sizes — unreliable over 5-10 games) → Using xG practically (shots from high xG positions are a trainable behaviour).

## Step 3 — Quality & Polish

- xG is a probability not a guarantee: context always matters
- Sample size limitation: advanced metrics need 15+ games for reliability
- Practical application: train players to create and take high-xG shots
