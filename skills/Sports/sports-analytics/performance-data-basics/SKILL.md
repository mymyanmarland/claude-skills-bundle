# Sports Performance Data Basics Skill

## Step 1 — Gather Inputs

- Sport and competitive level
- Current data collection methods
- Technical capability of coaching staff
- Budget for analytics tools
- Specific performance questions to answer

## Step 2 — Core Output

Performance data basics: What data is useful (data that informs decisions — not data for its own sake) → Metric selection (choose 3-5 key metrics that align with performance goals) → Data collection methods (wearables/video analysis/manual tally/GPS) → Reliability (is the data accurate and consistent?) → Visualisation (charts and tables that communicate clearly) → From data to decision (insights must lead to action) → Data privacy for athletes.

## Step 3 — Quality & Polish

- Data that informs decisions: avoid collecting data you never use
- 3-5 key metrics: focus on the vital few — too many metrics dilutes focus
- From data to action: data without a decision is wasted effort

Always offer a relevant next step or drill to practise.
