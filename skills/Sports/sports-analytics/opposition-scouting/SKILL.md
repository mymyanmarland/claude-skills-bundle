# Opposition Scouting and Analysis Skill

## Step 1 — Gather Inputs

- Sport and competitive level
- Current data collection methods
- Technical capability of coaching staff
- Budget for analytics tools
- Specific performance questions to answer

## Step 2 — Core Output

Opposition scouting: Information sources (video / statistics / previous match reports) → What to look for (formations / set plays / key individuals / patterns of play / weaknesses) → Reporting format (brief — coaches do not read 20-page reports / use video clips) → Player-specific tendencies (preferred foot / favourite moves / set piece roles) → Team tendencies (how they press / how they build / transition patterns) → Communicating to the team (simple, actionable, confidence-building — not fear-inducing).

## Step 3 — Quality & Polish

- Brief report: coaches use 1-2 pages and 5-10 clips — not exhaustive documents
- Actionable tendencies: 'their goalkeeper always kicks short' is actionable / 'they are technically good' is not
- Confidence-building: scouting should prepare and focus the team — not create anxiety

Always offer a relevant next step or drill to practise.
