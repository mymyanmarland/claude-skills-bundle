# Sports Analytics Tools Guide Skill

## Step 1 — Gather Inputs

- Sport and competitive level
- Current data collection methods
- Technical capability of coaching staff
- Budget for analytics tools
- Specific performance questions to answer

## Step 2 — Core Output

Analytics tools: Free tools (YouTube for video / Google Sheets for data / Canva for visualisation) → Affordable tools (Hudl Technique / Coach's Eye / iStat for specific sports) → Professional tools (Hudl full platform / Wyscout / Opta — require budget and training) → Wearable options (Catapult / STATSports GPS — team use / Whoop / Garmin — individual use) → Selection criteria (what questions do you want to answer? choose the tool that answers them within your budget) → Building analytics capacity in a club.

## Step 3 — Quality & Polish

- Start with free tools: most coaching questions can be answered with video and a spreadsheet
- Tool selection: match the tool to the question — not to the budget
- Build capacity: one analyst shared across multiple teams multiplies the value

Always offer a relevant next step or drill to practise.
