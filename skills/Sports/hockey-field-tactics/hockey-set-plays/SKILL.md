# Hockey Set Plays Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Hockey set plays: Sideline hit (quick tap and run / long hit to corner / switch) → Short corner from free hit → Long corner (aerial into D) → Penalty corner set plays (primary/variation/drag flick) → Free hits on edge of D → Every set play needs primary and safety option.

## Step 3 — Quality & Polish

- Every set play needs a primary and safety option
- Quick free hits: catch opposition before they set
- Penalty corner variation: alternate options — prevents scouting

Always offer a relevant next step or drill to practise.
