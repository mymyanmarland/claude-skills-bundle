# Rugby Set Plays and Moves Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Set plays: Lineout moves (miss pass / crash ball / loop runners) → Scrum moves (fly half miss / fullback into line) → Restart plays → Quick tap penalty → Every set play needs a primary and a safety option → Walk-jog-full speed progression.

## Step 3 — Quality & Polish

- Safety option: every set play needs one
- Walk-jog-full: never run full speed before walking it
- Signal system: clear and known by all 15

Always offer a relevant next step or drill to practise.
