# Athletics Coaching Guide Skill

## Step 1 — Gather Inputs

- Athletics event
- Current performance level
- Training environment
- Age and physical development
- Competition goals

## Step 2 — Core Output

Athletics coaching: Track and field breadth (sprints / hurdles / jumps / throws — different coaching demands) → Technical coaching model (observe / analyse / select key point / demonstrate / practise / feedback) → Warm-up standards (specific to event — sprints need more activation than distance) → Youth athletics (sample all events before specialising — under-13 multi-event) → Competition preparation → Event-specific injury awareness → Qualification pathways.

## Step 3 — Quality & Polish

- Youth multi-event: specialise after 15 — sample everything before
- Technical coaching: one key point at a time
- Competition preparation: rehearse the routine — warm-up, call room, event

Always offer a relevant next step or drill to practise.
