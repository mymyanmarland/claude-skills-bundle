# Sprint Start Mechanics Skill

## Step 1 — Gather Inputs

- Athletics event
- Current performance level
- Training environment
- Age and physical development
- Competition goals

## Step 2 — Core Output

Sprint start: Block setup (front block 2 foot-lengths from line, rear block 3) → Set position (hips above shoulders, weight forward, first movement is forward not up) → Drive phase (push into the ground, not up — stay low for first 10m) → Arm action (powerful, drives forward momentum) → Body angle (45 degrees for first 3 steps, gradually rise) → 10m to 30m acceleration (gradual rise to upright, increasing stride length not frequency).

## Step 3 — Quality & Polish

- Hips above shoulders in set: weight forward enables forward first step
- Stay low: standing up too early kills acceleration
- Drive phase: push backward into the ground — reaction propels you forward

Always offer a relevant next step or drill to practise.
