# Tennis Match Preparation Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Match preparation: Scouting (opponent tendencies, serve patterns, weak shots) → Game plan (2-3 clear tactical objectives) → Warm-up (specific physical and ball warm-up) → First game strategy (feel the ball, build into the match) → Adjustments (what if plan A does not work — have plan B) → Between-set adjustments → Post-match review (what worked and what did not).

## Step 3 — Quality & Polish

- Game plan: maximum 3 points — brain cannot hold more under pressure
- First game: build into match — not explosively from the first ball
- Post-match review within 24 hours: memory fades quickly

Always offer a relevant next step or drill to practise.
