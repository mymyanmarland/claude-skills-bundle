# Return Tactics Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Return tactics: Stand closer on weak second serve → Stand further back on big first serve → Chip return (neutralise pace, stay in rally) → Aggressive return (step in on weak second serve) → Body language (confident approach regardless of previous point) → Return targets by situation (safe crosscourt vs aggressive down line) → Reading serve direction from toss and body.

## Step 3 — Quality & Polish

- Reading the toss: consistent servers reveal direction before contact
- Aggressive return stance: step inside baseline on second serve
- Crosscourt return: the percentage choice in most situations
