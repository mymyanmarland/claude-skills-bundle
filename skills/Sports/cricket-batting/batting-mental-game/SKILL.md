# Batting Mental Game Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Batting mental game: Pre-innings routine (consistent warm-up, visualisation of key shots) → Ball-by-ball reset (clear the mind between deliveries) → Trigger words (1-2 word focus cues: 'watch it' or 'still head') → Handling pressure moments → Getting-out recovery (process quickly, learn not dwell) → Building an innings mindset (leave + score + leave + score rhythm).

## Step 3 — Quality & Polish

- Reset between every ball — each delivery is a new event
- Pre-innings routine same every time — trains the mind
- Dismissal processing — learn quickly, move on faster

Always offer a relevant next step or drill to practise.
