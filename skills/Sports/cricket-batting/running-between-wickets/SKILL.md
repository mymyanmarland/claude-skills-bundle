# Running Between Wickets Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Running between wickets: Calling system (striker calls for straight hits, non-striker for behind the wicket) → The three calls: yes/no/wait — clear and loud → Ground making technique (bat grounded inside crease, slide if needed) → Backing up: non-striker's movement as ball is bowled → Turning and setting off second run → Situational awareness (fielder position, arm strength, match situation).

## Step 3 — Quality & Polish

- Clear loud calls — hesitation causes run-outs
- Non-striker backs up every ball — not optional
- Both batters responsible for the call

Always offer a relevant next step or drill to practise.
