# Volleyball Set Plays and Quick Attacks Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Set plays: X play (middle and outside cross) → Tandem → Stack → Slide (back quick set) → Design to create blocking confusion → Timing precision essential — drill repeatedly.

## Step 3 — Quality & Polish

- Combination plays require 100 reps before match use
- Creating blocking confusion: the purpose of all combination attacks
- Quick set precision: poor pass, call it off and go simple

Always offer a relevant next step or drill to practise.
