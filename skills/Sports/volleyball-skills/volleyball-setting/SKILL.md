# Volleyball Setting Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Setting: Move early under the ball → Fingertips only (not palms — causes lift call) → Spring up and forward by extending fingers and wrists → Overhead set (toward antenna) → Back set (same mechanics, push backward) → Jump set → Decide before the ball arrives.

## Step 3 — Quality & Polish

- Fingertips only: palms cause lift or double contact
- Move early: scrambling under the ball produces poor sets
- Decide before: great setters read the passer and decide in advance
