# Multi-Sport Periodisation Skill

## Step 1 — Gather Inputs

- Sports participated in
- Current fitness level
- Training hours available per week
- Primary performance goal
- Any injury history or concerns

## Step 2 — Core Output

Multi-sport periodisation: Identify priority events (A-events: peak for these / B-events: competitive but secondary) → Sport-specific blocks (emphasise one sport per mesocycle — do not try to peak in all simultaneously) → Integration blocks (maintain all sports while peaking in one) → Annual plan (map all events, work backward for peak timing) → Taper management (taper for A-events — not B-events) → Recovery planning (post A-event recovery before the next build).

## Step 3 — Quality & Polish

- A-event vs B-event: cannot peak in everything — prioritise ruthlessly
- Sport-specific blocks: emphasise one at a time — concurrent peaking dilutes both
- Backward planning: from A-event → taper → peak → build → base

Always offer a relevant next step or drill to practise.
