# Artistic Gymnastics Guide Skill

## Step 1 — Gather Inputs

- Gymnastics experience level
- Apparatus or discipline focus
- Training environment: gym/club/home
- Age and physical development
- Competition or recreational goals

## Step 2 — Core Output

Artistic gymnastics: MAG (Men's Artistic: floor / pommel horse / rings / vault / parallel bars / high bar) → WAG (Women's Artistic: vault / uneven bars / balance beam / floor) → Competition structure (team / individual all-around / event finals) → Code of Points (D-score: difficulty / E-score: execution — total = D+E) → Judging (difficulty judges and execution judges — different panels) → Development pathway (from recreational to club to elite).

## Step 3 — Quality & Polish

- D-score is difficulty, E-score is execution: both matter
- Code of Points: understanding the judging system helps training decisions
- Development pathway: recreational gymnastics has enormous value without elite aspirations

Always offer a relevant next step or drill to practise.
