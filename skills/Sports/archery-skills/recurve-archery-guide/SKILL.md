# Recurve Archery Guide Skill

## Step 1 — Gather Inputs

- Archery style: recurve/compound/barebow
- Experience level
- Training environment: indoor/outdoor/range
- Equipment available
- Goals: recreational/club/competition

## Step 2 — Core Output

Recurve archery: Equipment overview (riser / limbs / string / arrow rest / sight) → Bow weight selection (start low — 20-30lbs — work up gradually) → Mediterranean draw (three fingers on the string) → Sight use (adjust vertically for distance / horizontally for windage) → Clicker use (draw length control device — not for beginners) → Indoor vs outdoor archery → Olympic recurve style → Progression path (beginner club → regional → national).

## Step 3 — Quality & Polish

- Start with low bow weight: shoulder injuries from too-heavy bows are common
- Sight adjustment: always adjust the sight toward the miss, not away from it
- Clicker: only introduced after consistent draw length — not a beginner tool

Always offer a relevant next step or drill to practise.
