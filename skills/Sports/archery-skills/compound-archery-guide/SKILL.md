# Compound Archery Guide Skill

## Step 1 — Gather Inputs

- Archery style: recurve/compound/barebow
- Experience level
- Training environment: indoor/outdoor/range
- Equipment available
- Goals: recreational/club/competition

## Step 2 — Core Output

Compound archery: Equipment (cams / cable / let-off / sight / release aid / stabiliser) → Let-off (compound bow holds a fraction of its draw weight at full draw — enables longer aiming time) → Release aid (mechanical release replaces fingers on the string) → Back tension release (back muscles activate the release — reduces flinching) → Peep sight (rear sight element in the string) → D-loop (protects the string from the release aid) → Bow setup (timing and cam timing — professional setup recommended for beginners).

## Step 3 — Quality & Polish

- Let-off is the compound bow's greatest advantage — use the aiming time it provides
- Back tension release: eliminates punching the trigger — the most common compound accuracy fault
- Professional setup: compound bows must be set up correctly — not a DIY first step
