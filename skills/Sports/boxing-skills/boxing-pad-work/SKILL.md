# Pad Work for Boxing Skill

## Step 1 — Gather Inputs

- Boxing experience level
- Training goals: fitness/technique/competition
- Gym access and equipment
- Coach availability
- Physical fitness level

## Step 2 — Core Output

Pad work: For the holder (present pads for specific punches / call combinations / give resistance / move and reposition) → For the hitter (punch the pad, not through it / return to guard immediately / listen for the call) → Combination pad work (holder calls or pads signal) → Building up (start slow, increase speed and complexity) → Safety (holder must watch for errant punches, always wear mitts) → Purpose: develop timing, speed, and combination fluency.

## Step 3 — Quality & Polish

- Holder sets the pace: too fast too soon loses technique
- Return to guard: the most important habit — reinforce it in pad work
- Pad work is not sparring: it is structured skill development

Always offer a relevant next step or drill to practise.
