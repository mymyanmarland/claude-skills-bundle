# Match Analysis for Football Coaches Skill

## Step 1 — Gather Inputs

- Playing level: beginner/club/competitive
- Specific weakness or focus area
- Training environment available
- Age and physical development
- Match format played

## Step 2 — Core Output

Match analysis: What to look for (your team's attacking and defensive structure) → Data collection (simple tally: shots / possession won / possession lost / pressing success) → Video analysis (key moments: goals, goals conceded, missed chances) → Post-match debrief (within 48 hours, focus on patterns not individual errors) → Training response (training next week addresses the patterns found).

## Step 3 — Quality & Polish

- Look for patterns not individual errors — one mistake is not a pattern
- Post-match debrief within 48 hours — memory fades
- Training response: analysis only valuable if it changes training

Always offer a relevant next step or drill to practise.
