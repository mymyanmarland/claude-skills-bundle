# Track Racing Tactics Skill

## Step 1 — Gather Inputs

- Athletics event and distance
- Current performance level
- Training environment
- Age and physical development
- Competition goals

## Step 2 — Core Output

Track racing tactics: Starting position (inside lane advantage) → Pack running (draft behind leaders — saves energy) → Positioning (not boxed in) → Surges (when to go vs let go) → Kick (have something left for the final straight) → Race reading (watch leaders, anticipate moves).

## Step 3 — Quality & Polish

- Inside lane saves metres — position for it at the start
- Draft behind leaders: reduces effort by 5-10%
- Kick: if no finishing kick — go with the move earlier
