# Marathon Training Plan Skill

## Step 1 — Gather Inputs

- Athletics event and distance
- Current performance level
- Training environment
- Age and physical development
- Competition goals

## Step 2 — Core Output

Marathon training: Base (weeks 1-8: build mileage, mostly easy) → Build (weeks 9-16: add tempo, long runs to 32km) → Peak (weeks 17-20: highest mileage) → Taper (weeks 21-26: reduce volume 40%) → Long run as centrepiece (increase max 10% per week) → Rest days mandatory.

## Step 3 — Quality & Polish

- Long run is the most important session of the week
- Taper: trust the process — reduce volume, keep quality
- 10% rule: more than 10% increase per week causes injury

Always offer a relevant next step or drill to practise.
