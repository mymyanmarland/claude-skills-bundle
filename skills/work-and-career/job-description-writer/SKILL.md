# Job Description Writer Skill

## Step 1 — Gather Inputs
Ask for context: industry, company size, role specifics, goals, constraints, and any relevant existing materials.

## Step 2 — Core Deliverable
Produce a complete, professional-grade output following best practices for this specific business document or program type — properly structured, immediately usable, and appropriate to the context.

## Step 3 — Customization Notes
Flag any sections where local legal requirements, industry standards, or company-specific information should be added before use.

Always offer a companion document or follow-up that adds practical value.
