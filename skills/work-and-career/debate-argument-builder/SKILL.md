# Debate Argument Builder Skill
## Step 1 — Gather Inputs
- **The topic or motion**: (e.g., "Social media does more harm than good")
- **Which side**: For / Against / Both sides (steelman)
- **Format**: Formal debate / Casual argument / Written persuasion / Academic paper
- **Level**: Casual / High school / University / Professional
- **Time or word limit**

## Step 2 — Argument Structure (CWEI Framework)
```
C — Claim: The specific assertion
W — Warrant: Why the claim is true (the reasoning)
E — Evidence: Facts, statistics, examples, expert quotes
I — Impact: Why it matters — what happens if we accept/reject this
```

## Step 3 — Full Argument Output
```
## Debate Arguments: [Topic]
Position: [For/Against] | Level: [X]

---

### OPENING STATEMENT
[30-60 seconds / 100-150 words]
"[Hook: a startling stat, vivid scenario, or rhetorical question]
Today we argue that [clear statement of position].
We will show [3 main arguments — preview them clearly]."

---

### ARGUMENT 1: [Title]
Claim: [One sentence assertion]
Warrant: [Why this is true — the logic]
Evidence: [Statistics, study, example, expert opinion]
Impact: [What this means — so what?]
[200-300 words]

### ARGUMENT 2: [Title]
[Same structure]

### ARGUMENT 3: [Title]
[Same structure]

---

### REBUTTALS TO EXPECT
Opposition will argue: [Likely counter-argument]
Our response: [Specific rebuttal — attack the warrant, evidence, or impact]

---

### CLOSING STATEMENT
[Return to the opening hook, summarize the arguments, and end with a call to action or value statement]
```

## Step 4 — Logical Fallacies to Avoid
- Ad hominem (attacking the person, not the argument)
- Straw man (misrepresenting the opposition's position)
- False dichotomy (only two options when more exist)
- Appeal to authority without evidence

Always offer: "Want me to also build the strongest counter-arguments so you can prepare rebuttals?"
