# Productivity System Builder Skill

Design a personalized system that fits how the user actually works — not a generic to-do list.

## Step 1 — Gather Inputs

Ask in one message if not provided:
- **Work type**: Deep work (writing, coding, research) / Meetings-heavy / Mix / Creative
- **Schedule flexibility**: Fixed 9–5 / Flexible / Shift work / Freelance
- **Biggest productivity pain point**: Too many tasks / Hard to focus / Procrastination / No clear priorities / Always in meetings / Poor work-life boundary
- **Tools they currently use** (or are open to): Notion, Todoist, paper, Google Calendar, etc.
- **Energy pattern**: Morning person / Afternoon / Evening / Varies
- **Weekly meeting load**: Roughly how many hours per week in meetings?

---

## Step 2 — Diagnosis First

Before prescribing a system, identify what's actually wrong:

```
## 🔍 Productivity Audit

**Symptom → Root cause mapping**:

| Symptom | Likely Root Cause | System Fix |
|---------|------------------|------------|
| Always busy, no progress | No prioritization — doing urgent not important | Priority framework |
| Can't finish tasks | Tasks too vague / too large | Task decomposition |
| Constantly distracted | No protected focus time | Time blocking |
| Overwhelmed by volume | No capture system — everything in head | Trusted inbox |
| Starting but not finishing | Perfectionism / no deadlines | Time boxing |
| Good days and bad days | No routine — relying on motivation | Habit architecture |
| Can't say no | No clarity on what matters most | Quarterly goals |
```

## Step 3 — Core System Components

### 🧭 Component 1: Capture System (The Trusted Inbox)

Every task, idea, and commitment goes into ONE place immediately — not multiple apps, not your head.

```
**Your capture tool**: [One tool only — Notion inbox, Todoist inbox, physical notebook, Apple Notes]

**Rule**: If it takes < 2 minutes, do it now. If not, capture it.
**Review**: Empty your inbox every morning — don't let it become a second to-do list.
```

---

### 🎯 Component 2: Priority Framework

**The Eisenhower Matrix** (for daily/weekly triage):

```
                URGENT          NOT URGENT
IMPORTANT  | Do now (Q1)  | Schedule it (Q2) |
           |              |                  |
NOT        | Delegate (Q3)| Eliminate (Q4)   |
IMPORTANT  |              |                  |

Most people live in Q1 and Q3. High performers live in Q2.
Q2 = deep work, relationships, planning, health, learning.
```

**The MIT Method** (Most Important Tasks):
- Each day: pick 3 MITs — the 3 things that, if done, make the day a success
- Do MITs before email, before meetings, before anything reactive
- If you only finish your MITs, the day was productive

---

### ⏰ Component 3: Time Blocking

Design your ideal week before scheduling anything else:

```
## 📅 Ideal Week Template

**Morning blocks** (use peak energy for deep work):
| Time | Block Type | Purpose |
|------|-----------|---------|
| 7:00–8:00 | Morning routine | Exercise, plan, no screens |
| 8:00–10:00 | 🔴 DEEP WORK | Most important project (no meetings) |
| 10:00–12:00 | 🔴 DEEP WORK | Second priority work |

**Afternoon blocks** (lower energy = good for reactive work):
| Time | Block Type | Purpose |
|------|-----------|---------|
| 12:00–13:00 | Lunch + recharge | No work |
| 13:00–15:00 | 🟡 MEETINGS | All meetings scheduled here |
| 15:00–16:30 | 🟡 SHALLOW WORK | Email, Slack, admin |
| 16:30–17:00 | 🔵 DAILY SHUTDOWN | Review, plan tomorrow, close loops |

**Rules**:
- Protect morning deep work — no meetings before 11am if possible
- Batch meetings on 2–3 days (meeting days vs. maker days)
- Schedule email time — don't leave inbox open all day
- Color-code block types in calendar so the pattern is visible
```

### 📋 Component 4: Task Management System

```
## 📋 Task System

**Task states**:
- Inbox → Next Actions → Waiting For → Someday/Maybe → Done

**Next Actions list** (the only list you look at today):
- Tasks must be SPECIFIC and ACTIONABLE: not "work on report" but "write executive summary section of Q3 report — 400 words"
- Each task has an estimated time (15 min / 30 min / 60 min / 2 hr)
- Max 7 tasks on today's list — be realistic

**Weekly review** (every Friday, 20 min):
1. Clear inbox
2. Review all open projects — is anything stalled?
3. Check this week's calendar — what's coming up?
4. Set next week's top 3 priorities
5. Move "someday" items forward if ready

**Project vs. task distinction**:
- Task: single action, done in one sitting
- Project: requires 2+ actions → needs its own list
```

### 🔁 Component 5: Daily Routine Structure

```
## 🌅 Daily Rhythm

**Morning Routine** (15–30 min before work starts):
1. No phone for first 30 minutes — protect your brain state
2. Quick journal or intention setting (what matters today?)
3. Review your MITs for the day
4. Check calendar — any prep needed for today's meetings?

**Work Start Ritual** (signals brain it's time to focus):
- Make coffee / tea, sit at desk, open only one browser tab
- Read your MITs — start the hardest one first

**End-of-Day Shutdown Ritual** (critical — prevents work bleeding into personal time):
1. Review what you completed
2. Move any unfinished tasks
3. Write tomorrow's 3 MITs
4. Close all work tabs and apps
5. Say out loud: "Shutdown complete" (sounds silly — works)

**The shutdown ritual rule**: If you have a shutdown ritual, you don't need willpower to stop working — the ritual stops for you.
```

---

### 📊 Component 6: Weekly & Quarterly Reviews

```
## 🔄 Review Cadence

**Daily** (5 min — end of day):
- Did I complete my MITs?
- What's on tomorrow's plate?
- Any open loops to close?

**Weekly** (30 min — Friday or Sunday):
- Projects: what's in progress, what's stuck, what's done?
- Wins: what went well this week?
- Lesson: what would I do differently?
- Next week: what are the top 3 priorities?

**Quarterly** (2 hours — end of each quarter):
- Review goals — what did I achieve, what fell away?
- Was I working on the right things?
- What should I start/stop/continue?
- Set 3 goals for next quarter (no more than 3)
```

## Step 4 — Tackling Specific Problems

### Procrastination
```
## ⚡ Anti-Procrastination Tactics

**The 2-minute start**: Commit to just 2 minutes on the dreaded task.
(Starting is the hard part — you'll almost always continue past 2 minutes.)

**Time boxing**: Give the task a fixed end time. "I'll work on this for 25 minutes."
(Parkinson's Law: work expands to fill time available — give it less.)

**Reduce friction**: Open the document before bed. Put gym clothes out the night before.
(The harder it is to start, the more we avoid it.)

**Temptation bundling**: Pair the task with something you enjoy.
(Only listen to your favorite podcast while doing this task.)
```

### Focus & Deep Work
```
## 🎯 Deep Work Protocol

**Environment**:
- Phone in another room (not silent — another room)
- Website blockers: Freedom, Cold Turkey, or iOS Screen Time
- Noise: binaural beats, brown noise, or silence (not music with lyrics)
- "Do Not Disturb" mode — and tell people not to interrupt

**Session structure**:
- 90-minute focused blocks (max — brain can't sustain longer)
- 10-minute break between blocks
- No more than 3–4 hours of true deep work per day

**Re-entry ritual**: If interrupted, write down exactly where you were before dealing with it
("Return to: paragraph 3, making point about X")
```

## Step 5 — Tool Recommendations

```
## 🛠️ Recommended Tools by Style

**Minimalist** (pen + paper person):
- Daily planner: Bullet Journal or simple notebook
- Weekly review: Paper template

**Digital / cross-device**:
- Task manager: Todoist or Things 3
- Calendar time blocking: Google Calendar
- Notes + projects: Notion or Obsidian

**Visual thinker**:
- Kanban board: Trello or Notion board view
- Mind mapping: Miro or pen + paper

**Tech-heavy / developer**:
- Linear (for project management)
- Obsidian (for notes with linking)

**Rule**: The best tool is the one you'll actually use.
Don't spend more time managing your system than doing the work.
```
