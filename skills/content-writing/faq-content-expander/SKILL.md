# FAQ Content Expander Skill

## Step 1 — Gather Inputs

- Questions to expand
- Brief current answers if any
- Target keyword for each question
- Reading level
- Whether to target featured snippets

## Step 2 — Core Output

For each question: Direct answer (40-60 words, suitable for featured snippet) → Expanded explanation (150-200 words) → Practical example → Related question (for internal linking). Format the direct answer to match featured snippet format: definition box, numbered list, or table. Use the question as an H2 or H3. Each answer includes: 1 internal link opportunity, 1 potential FAQ schema markup note.

## Step 3 — Quality & Polish

- Direct answer is genuinely direct — not a preamble
- Question used naturally in the answer text
- Related questions link to real content, not placeholder

Always offer a relevant next step or companion output.
