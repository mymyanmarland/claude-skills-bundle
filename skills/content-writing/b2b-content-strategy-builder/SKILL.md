# B2B Content Strategy Builder Skill

## Step 1 — Gather Inputs

- Company type and ICP
- Sales cycle length
- Current content
- Budget range
- Primary goal: awareness/leads/retention

## Step 2 — Core Output

Strategy sections: ICP content needs by stage (awareness/consideration/decision) → Content type matrix (format vs funnel stage) → Quarterly content calendar template → Distribution channel plan → Measurement framework (metrics per goal) → 90-day quick start plan. Each recommendation includes rationale.

## Step 3 — Quality & Polish

- Recommendations matched to sales cycle length
- Every content type mapped to a specific funnel stage
- 90-day plan is executable with stated resources

Always offer a relevant next step or companion output.
