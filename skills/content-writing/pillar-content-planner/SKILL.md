# Pillar Content Planner Skill

## Step 1 — Gather Inputs

- Main topic/keyword to own
- Target audience
- Current domain authority (low/medium/high)
- Content production capacity (posts per month)
- Competitor content gaps if known

## Step 2 — Core Output

Deliver: 1 pillar page outline (2000-3000 words, covers topic broadly) + 10 cluster article titles with target keywords + internal linking map (which cluster links to pillar and vice versa) + content calendar sequence (which to publish first for fastest authority signals) + 3 quick-win articles to prioritize. Each cluster article should target a long-tail keyword with clear search intent. Include suggested word count and content type (guide, list, comparison, case study) for each.

## Step 3 — Quality & Polish

- Pillar page must answer the broadest version of the topic
- Cluster topics cover distinct subtopics — no overlap
- Each cluster links back to pillar with exact-match or partial-match anchor

Always offer a relevant next step or companion output.
