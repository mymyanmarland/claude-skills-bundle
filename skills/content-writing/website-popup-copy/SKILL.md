# Website Popup Copy Skill

## Step 1 — Gather Inputs

- Popup goal
- What's being offered
- Audience
- Trigger: exit/time/scroll
- Brand tone

## Step 2 — Core Output

3 popup versions: Exit-intent (urgency + last chance), Welcome (value + social proof), Newsletter (specific benefit promise). Each: headline (benefit), subheadline (overcome objection), CTA button text, decline text (keep it human). Include A/B test variants for headline.

## Step 3 — Quality & Polish

- Decline link doesn't shame the reader
- CTA button text is benefit not action alone
- Value offered is specific

Always offer a relevant next step or companion output.
