# Content Audit Template Skill

## Step 1 — Gather Inputs

- Approximate number of content pieces
- Content types (blog/video/social)
- Audit goals (SEO / quality / gaps / outdated)
- Evaluation criteria priorities
- Resources for remediation

## Step 2 — Core Output

Deliver: Audit spreadsheet column structure (URL, title, type, date, traffic, backlinks, word count, quality score, action) → Scoring rubric for quality (1-5 scale with definitions for each score) → Action categories: Keep / Update / Consolidate / Delete / Redirect → Priority matrix (traffic vs quality) → 30/60/90 day remediation plan template. Include instructions for each column and example entries. Explain how to gather data for each metric.

## Step 3 — Quality & Polish

- Scoring rubric has clear criteria — no subjective ratings
- Every piece gets an action — nothing in limbo
- Remediation plan is achievable with given resources

Always offer a relevant next step or companion output.
