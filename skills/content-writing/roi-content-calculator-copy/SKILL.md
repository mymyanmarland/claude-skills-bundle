# ROI Content Calculator Copy Skill

## Step 1 — Gather Inputs

- What the calculator measures
- Input fields
- Target user role
- Typical results range
- CTA after calculation

## Step 2 — Core Output

Copy sections: Calculator headline (promise the insight) + Intro paragraph (why this number matters) + Field labels and helper text (concise, jargon-free) + Results section copy (how to interpret each number) + Below-results CTA (matched to their result size) + Trust elements (data sources, methodology note). Results language templates for low/medium/high outcomes.

## Step 3 — Quality & Polish

- Helper text answers the likely question for that field
- Results copy doesn't assume the best case
- CTA appropriate to result magnitude

Always offer a relevant next step or companion output.
