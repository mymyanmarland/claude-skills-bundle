# Interactive Quiz Copy Skill

## Step 1 — Gather Inputs

- Quiz topic and goal
- Target audience
- Number of questions
- Result types (2-5 outcomes)
- Platform: website/social/email

## Step 2 — Core Output

Deliver: Quiz title (compelling, benefit-focused) + Introduction (why take this quiz, what you'll discover) + 8-10 questions with 3-4 multiple choice answers each + 3-4 result profiles (each with title, description 100 words, and recommended next step). Questions should feel conversational not clinical. Results must feel personalised and insightful. Include score ranges or result triggers. End each result with a specific CTA matching the result profile.

## Step 3 — Quality & Polish

- Each question advances the reader toward an insight
- No obviously 'right' answers — all choices plausible
- Results are specific enough to feel personalised

Always offer a relevant next step or companion output.
