# SEO Meta Tag Optimizer Skill

## Step 1 — Gather Inputs

- Page topic and primary keyword
- Secondary keywords
- Page type (article/product/landing page)
- Existing title if any
- Target audience search intent

## Step 2 — Core Output

Output 3 title tag options (50-60 chars each) and 3 meta description options (150-160 chars each). Title formulas: (1) Keyword + Benefit + Year, (2) Number + Keyword + Promise, (3) Question + Keyword. Description formulas: (1) Pain + Solution + CTA, (2) Benefit statement + Social proof + CTA, (3) Curiosity gap + What they'll learn. Score each against: keyword inclusion, click appeal, character count compliance, uniqueness. Recommend best combination with reasoning.

## Step 3 — Quality & Polish

- Primary keyword in first 30 chars of title
- Every description ends with an action phrase
- No keyword stuffing — reads naturally

Always offer a relevant next step or companion output.
