# Listicle Article Writer Skill

## Step 1 — Gather Inputs

- Topic and number
- Target keyword
- Audience level
- Depth per item
- Any must-include items

## Step 2 — Core Output

Structure: SEO headline with number → Hook intro (why this list now) → Items in order (most interesting first, strongest last) → Each item: bold title + 100-150 words + takeaway line → Conclusion with synthesis. Vary item length. Include sub-bullets for complex items. Add a comparison table if applicable.

## Step 3 — Quality & Polish

- Items don't repeat same advice in different words
- Intro does not list all items — creates curiosity
- Final item is the most memorable or surprising

Always offer a relevant next step or companion output.
