# Podcast Show Description Writer Skill

## Step 1 — Gather Inputs

- Show topic and format
- Host background
- Target listener
- 3 typical episode topics
- Show CTA

## Step 2 — Core Output

Deliver: Short description (100 words — for directory listings) + Long description (250 words — for show website) + 3 episode description templates (hook + overview + guest bio placeholder + listener takeaway) + Platform-specific notes (Apple vs Spotify character limits). Show descriptions must address: who is this for, what will they learn, why this host.

## Step 3 — Quality & Polish

- Show description doesn't start with host name
- Episode descriptions don't summarize — they intrigue
- Platform character limits respected

Always offer a relevant next step or companion output.
