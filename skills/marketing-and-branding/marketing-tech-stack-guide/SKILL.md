# Marketing Tech Stack Guide Skill

## Step 1 — Gather Inputs

- Business size and type
- Marketing team size
- Budget for tools
- Current tools used
- Key marketing challenges

## Step 2 — Core Output

Tech stack recommendation: Must-have tier (free/low cost tools every business needs) → Growth tier (tools to add as you scale) → Scale tier (enterprise tools for larger teams) → Tool-by-tool recommendation with rationale → Integration map → Total cost estimate → Implementation priority.

## Step 3 — Quality & Polish

- Recommendations matched to business size — not aspirational
- Integration map realistic — no manual work assumed
- Cost estimates current and complete (hidden costs noted)

Always offer a relevant next step.
