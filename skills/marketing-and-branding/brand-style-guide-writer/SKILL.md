# Brand Style Guide Writer Skill

## Step 1 — Gather Inputs

- Brand personality descriptors
- Current voice samples
- Audiences
- Common writing mistakes
- Format: internal/public

## Step 2 — Core Output

Style guide sections: Brand voice overview (who we sound like and why) → Tone variations by context → Word and phrase list (use/avoid) → Grammar and punctuation rules → Formatting standards → Audience-specific adjustments → Before/after examples (5 pairs) → Common mistakes section.

## Step 3 — Quality & Polish

- Examples more useful than rules
- Before/after pairs show meaningful difference
- Rules actionable — writer can apply without asking

Always offer a relevant next step.
