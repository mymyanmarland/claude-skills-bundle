# Brand Messaging Hierarchy Skill

## Step 1 — Gather Inputs

- Brand purpose and values
- Target audiences
- Key products or services
- Current messaging challenges
- Tone and personality

## Step 2 — Core Output

Hierarchy: Brand purpose (why we exist — one sentence) → Brand promise (what we commit to deliver) → Brand pillars (3-4 core messages that support the promise) → Audience-specific messages (how each pillar resonates for each audience) → Proof points (evidence for each pillar) → Tagline options. Each level explicitly connects to the level above.

## Step 3 — Quality & Polish

- Each level supports levels above — not standalone
- Proof points are real and specific
- Tagline options match purpose — not just catchy

Always offer a relevant next step.
