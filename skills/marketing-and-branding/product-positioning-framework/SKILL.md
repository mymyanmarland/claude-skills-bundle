# Product Positioning Framework Skill

## Step 1 — Gather Inputs

- Product description
- Target segment
- Key alternatives (direct and indirect)
- Primary benefit
- Proof points

## Step 2 — Core Output

Positioning framework: Category definition (what game are you playing?) → Target customer profile → Key benefit claim → Reason to believe (why this claim is credible) → Differentiation from alternatives → Emotional + functional value map → Positioning statement (formal) + everyday messaging equivalent. Test: could a competitor use this positioning? If yes, make it more specific.

## Step 3 — Quality & Polish

- Category definition considered carefully — category shapes competition
- Every claim has at least one proof point
- Differentiation specific — not just 'better quality'

Always offer a relevant next step.
