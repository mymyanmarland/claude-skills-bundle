# Product Marketing One-Pager Skill

## Step 1 — Gather Inputs

- Product name and description
- Top 3 use cases
- Key differentiators
- Target buyer and their pain
- Proof points available

## Step 2 — Core Output

One-pager layout copy: Headline (outcome-focused) → Subheadline (who it's for) → Problem statement (2 sentences) → Solution overview (3 bullet benefits) → Use case section (3 specific scenarios) → How it works (3-step visual description) → Key metrics or proof → Customer logo/quote placeholder → CTA. All copy optimized for a 30-second scan.

## Step 3 — Quality & Polish

- Scannable in 30 seconds without reading
- Every section one standalone idea
- CTA is specific and single

Always offer a relevant next step.
