# Brand Values Statement Writer Skill

## Step 1 — Gather Inputs

- What the company actually does that embodies each value
- Culture behaviors observed
- What values to avoid (overused ones)
- Number of values
- Internal vs public use

## Step 2 — Core Output

For each value: Name (1-3 words, memorable) → Meaning statement (what it looks like in action — 2 sentences) → Behaviors that demonstrate it → Behaviors that violate it. 4-6 values maximum. Each genuinely distinct. Format for poster, handbook, and onboarding use. Avoid: integrity, innovation, excellence, passion — unless specifically justified.

## Step 3 — Quality & Polish

- Each value has distinct behaviors — not overlap
- Values describe real behavior — not aspirations
- No more than 6 — each memorable

Always offer a relevant next step.
