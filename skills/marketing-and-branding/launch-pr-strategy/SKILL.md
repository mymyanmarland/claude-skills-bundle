# Launch PR Strategy Skill

## Step 1 — Gather Inputs

- What is launching
- News angle
- Target media
- Key spokesperson
- Timeline

## Step 2 — Core Output

PR strategy: News hook development (why is this newsworthy right now?) → Media list priority tiers → Pitch angles per publication type → Press release + pitch email → Spokesperson talking points → Embargo strategy → Launch day timing → Post-launch follow-up plan. Realistic coverage expectations set.

## Step 3 — Quality & Polish

- News hook genuinely newsworthy — editor perspective
- Pitch angles vary by publication type
- Expectations realistic — PR is not guaranteed coverage

Always offer a relevant next step.
