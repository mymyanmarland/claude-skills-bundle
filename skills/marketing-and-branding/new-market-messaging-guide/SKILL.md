# New Market Messaging Guide Skill

## Step 1 — Gather Inputs

- Current core messaging
- New market description
- Key cultural differences
- Product adaptations if any
- Local competitive landscape

## Step 2 — Core Output

Messaging adaptation guide: Core message audit (what translates / what doesn't) → Cultural sensitivity review → Local value proposition adjustments → Language and tone adaptations → Local proof points needed → Channel strategy for this market → Pilot campaign copy.

## Step 3 — Quality & Polish

- Cultural differences researched — not assumed
- Core brand maintained while adapting tone
- Local proof points plan realistic

Always offer a relevant next step.
