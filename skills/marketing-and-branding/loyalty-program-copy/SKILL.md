# Loyalty Program Copy Skill

## Step 1 — Gather Inputs

- Program structure
- Tier names and benefits
- Target customer
- Brand tone
- Key enrollment benefits

## Step 2 — Core Output

Copy kit: Program name pitch (3 options with rationale) → Hero enrollment pitch (50 words) → Tier benefit descriptions → Welcome email → First reward earned notification → Lapsed member reactivation email → Program FAQ. Language that makes earning feel exciting and achievable.

## Step 3 — Quality & Polish

- Benefits written as experiences — not just discount percentages
- Tier names reinforce brand identity
- Reactivation email honest about what member missed

Always offer a relevant next step.
