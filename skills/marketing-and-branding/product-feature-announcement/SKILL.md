# Product Feature Announcement Skill

## Step 1 — Gather Inputs

- Feature name and what it does
- Problem it solves
- Who uses it and when
- Release scope: beta/all users
- Tone: technical/consumer

## Step 2 — Core Output

Three versions: (1) In-app notification (under 100 words, direct, benefit-led, learn more CTA). (2) Email announcement (150-200 words, more context, how to access, feedback CTA). (3) Blog post (400 words, story of why we built it, early customer validation, how to get started). Each version appropriate to its channel.

## Step 3 — Quality & Polish

- Feature name consistent across all versions
- Problem statement relatable — not product-team language
- Access instructions specific — not 'check it out'

Always offer a relevant next step.
