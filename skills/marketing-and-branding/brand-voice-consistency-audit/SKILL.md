# Brand Voice Consistency Audit Skill

## Step 1 — Gather Inputs

- Content samples from various channels
- Brand voice guidelines if any
- Key inconsistency concerns
- Channels to audit
- Audience feedback if available

## Step 2 — Core Output

Audit report: Voice consistency score per channel → Key inconsistencies found (specific examples) → Root cause analysis (style guide gaps / multiple writers / no guidelines) → Priority corrections → Updated style guidance for problem areas → Implementation process for consistency going forward.

## Step 3 — Quality & Polish

- Inconsistencies shown with specific examples — not described abstractly
- Root cause identified so fix is systemic
- Priority corrections ranked by audience impact

Always offer a relevant next step.
