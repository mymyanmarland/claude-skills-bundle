# Product Demo Script Writer Skill

## Step 1 — Gather Inputs

- Product type
- Prospect pain points
- Demo format: live/recorded/interactive
- Key features to highlight
- Time available

## Step 2 — Core Output

Demo script: Opening hook (lead with problem — not product) → Agenda setting → Discovery questions (weave in 2-3) → Feature demonstration sequence (pain → feature → benefit → proof for each) → Handling objections mid-demo → Call to action. Timing notes throughout. Presenter notes in brackets.

## Step 3 — Quality & Polish

- Opens with prospect pain — not product overview
- Each feature tied to specific pain point
- Objection handling mid-demo prevents derailing

Always offer a relevant next step.
