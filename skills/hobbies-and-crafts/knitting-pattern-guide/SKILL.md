# Knitting Pattern Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Knitting guide: Pattern reading (abbreviations/charts/gauge) → Cast on methods → Basic stitches (knit/purl/yarn over) → Pattern structure (cast on/body/bind off) → Gauge swatch importance → Needle size guidance → Yarn weight selection → Common mistakes and fixes → Project progression from beginner to advanced.

## Step 3 — Quality & Polish

- Gauge swatch non-negotiable — skipping it ruins projects
- Abbreviation decoder for the specific pattern
- Common mistakes with visual descriptions

Always offer a relevant next step.
