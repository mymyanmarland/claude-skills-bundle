# Woodworking Beginner Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Woodworking guide: Essential tool list (start minimal) → Wood selection and grain → Measuring and marking → Hand tools vs power tools → Basic joints (butt/dado/rabbet/mortise) → Sanding sequence → Finishing options → Shop safety fundamentals → First projects with skill progression.

## Step 3 — Quality & Polish

- Safety first and throughout — power tools are dangerous
- Measuring twice cut once — the foundational rule
- Finishing sequence — sandpaper grits in order

Always offer a relevant next step.
