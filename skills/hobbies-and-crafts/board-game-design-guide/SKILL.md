# Board Game Design Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Board game design: Core mechanism selection (engine building/worker placement/deck building/area control) → Player interaction level decision → Component economy (use only what is necessary) → Playtest cadence (test early, test often) → Rules writing clarity → Graphic design basics → Prototype construction → Publishing options.

## Step 3 — Quality & Polish

- Core mechanism first — everything else serves it
- Playtest before polishing — most ideas fail early
- Rules clarity test — hand to stranger and watch

Always offer a relevant next step.
