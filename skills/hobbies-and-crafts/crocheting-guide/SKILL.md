# Crocheting Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Crochet guide: Hook and yarn selection → Foundation chain → Basic stitches (sc/dc/hdc/tc) → Counting stitches → Working in rounds vs rows → Reading crochet patterns and charts → Tension and gauge → Finishing techniques (weaving ends/blocking) → Project ideas by skill level.

## Step 3 — Quality & Polish

- Hook size matched to yarn weight
- Tension consistency — the hardest beginner skill
- Finishing techniques — what separates good from great crochet

Always offer a relevant next step.
