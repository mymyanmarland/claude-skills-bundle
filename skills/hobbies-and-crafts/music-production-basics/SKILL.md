# Music Production Basics Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Music production guide: DAW selection and setup → Signal flow understanding → MIDI vs audio → Beat programming basics → Arrangement principles → Mixing concepts (levels/panning/EQ basics) → Basic synthesis (subtractive) → Plugin essentials vs gear acquisition syndrome → Reference tracks → Finishing vs perfecting.

## Step 3 — Quality & Polish

- Signal flow understanding before any other skill
- Finishing tracks — the hardest skill in production
- Reference tracks — the professional mixing tool

Always offer a relevant next step.
