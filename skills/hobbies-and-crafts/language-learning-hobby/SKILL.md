# Language Learning Hobby Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Language learning hobby: Input-based learning (comprehensible input theory) → Spaced repetition vocabulary → Speaking early vs speaking late debate → Media immersion (shows/music/podcasts) → Finding conversation partners → Progress measurement → Enjoying the plateau → Language learning community resources.

## Step 3 — Quality & Polish

- Comprehensible input — the most evidence-based approach
- Enjoyment over efficiency — hobby learning sustainable
- Conversation partner finding — speaking practice resources

Always offer a relevant next step.
