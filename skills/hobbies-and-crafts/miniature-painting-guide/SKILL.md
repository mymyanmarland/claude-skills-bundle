# Miniature Painting Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Miniature painting guide: Assembly and priming → Base coating → Layering for smooth blends → Washing and shading techniques → Drybrushing for texture → Edge highlighting → Eye painting basics → Basing and groundwork → Varnishing for protection → Speed painting vs display quality approaches.

## Step 3 — Quality & Polish

- Primer required for paint adhesion and detail visibility
- Washing followed by highlighting — the core miniature technique
- Varnish type by use — matte for display, satin for gameplay

Always offer a relevant next step.
