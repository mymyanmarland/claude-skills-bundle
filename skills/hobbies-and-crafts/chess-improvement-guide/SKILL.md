# Chess Improvement Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Chess improvement: Tactical pattern recognition (the most important skill) → Endgame fundamentals before openings → Opening repertoire building → Game analysis technique → Puzzle solving daily practice → Time management in games → Positional understanding development → Study resources by level.

## Step 3 — Quality & Polish

- Tactics first — openings are overrated for improvement
- Endgames before openings — the counterintuitive truth
- Game analysis habit — reviewing your own games

Always offer a relevant next step.
