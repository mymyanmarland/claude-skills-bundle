# Candle Making Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Candle making guide: Wax types (soy/paraffin/beeswax/coconut) → Container selection → Wick sizing (most important variable) → Fragrance load calculation → Colorant options → Melting temperatures → Pouring temperature → Cure time → Common problems (sinkholes/frosting/poor scent throw) → Labeling for sale.

## Step 3 — Quality & Polish

- Wick sizing determines burn performance — test every combination
- Cure time for scent throw — minimum 48 hours
- Safety: working with hot wax requires care

Always offer a relevant next step.
