# Calligraphy Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Calligraphy guide: Tool selection (nib/brush/pen) → Ink selection → Paper selection (bleed and texture) → Basic strokes before letters → Letterform anatomy → Consistent angle and pressure → Practice drill structure → Modern calligraphy vs traditional styles → Connecting letters → Application to envelopes and place cards.

## Step 3 — Quality & Polish

- Basic strokes before letterforms — foundational
- Consistent angle — guide sheets help beginners
- Practice volume — calligraphy is muscle memory

Always offer a relevant next step.
