# Scale Model Building Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Model building guide: Kit selection by skill level → Parts cleanup (sprue removal/seam filling) → Sub-assembly sequence → Paint application (primer/base coat/shading/highlighting) → Decal application → Weathering techniques → Gloss and matte finishing → Display and storage.

## Step 3 — Quality & Polish

- Sub-assembly before full assembly — painting access
- Primer required — paint adhesion depends on it
- Weathering transforms realistic models

Always offer a relevant next step.
