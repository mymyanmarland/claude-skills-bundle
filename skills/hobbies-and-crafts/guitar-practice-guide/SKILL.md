# Guitar Practice Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Guitar practice guide: Practice structure (warm-up/technique/repertoire/theory) → Metronome discipline → Chord transition speed → Scale and mode practice → Song learning methodology → Music theory integration → Ear training exercises → Recording yourself → Style-specific techniques → Practice efficiency over quantity.

## Step 3 — Quality & Polish

- Metronome discipline — the hardest habit to build
- Recording yourself — the most honest feedback
- Theory integration — understanding what you play

Always offer a relevant next step.
