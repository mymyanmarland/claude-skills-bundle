# Coin Collecting Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Physical limitations or constraints

## Step 2 — Core Output

Coin collecting guide: Collecting focus selection (by country/era/type/theme) → Grading basics (circulated vs uncirculated) → Storage and handling (never clean coins) → Reference sources (Red Book/NGC) → Authentication basics → Building a collection strategy → Buying venues (dealers/shows/auctions) → Portfolio vs hobby approach.

## Step 3 — Quality & Polish

- Never clean coins — destroys value
- Handling by edges — fingerprints affect grade
- Authentication awareness — counterfeits exist

Always offer a relevant next step.
