# Embroidery Guide Skill

## Step 1 — Gather Inputs

- Skill level: beginner/intermediate/advanced
- Materials or tools available
- Project goal or specific challenge
- Time and budget
- Any physical limitations or constraints

## Step 2 — Core Output

Embroidery guide: Hoop setup and fabric selection → Thread types and strands → Essential stitches (backstitch/satin/French knot/chain) → Transferring designs → Color planning → Working order (background to foreground) → Finishing and framing → Pattern reading → Project progression.

## Step 3 — Quality & Polish

- Hoop tension matters — too tight distorts fabric
- Working order prevents covering stitches
- Finishing technique preserves the work

Always offer a relevant next step.
