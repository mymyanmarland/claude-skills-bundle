# Home Organization System Skill

## Step 1 — Gather Inputs

- Home size and type
- Biggest organization pain points
- Children and pets
- Time to invest in organizing
- Storage available

## Step 2 — Core Output

Home organization: Declutter first (keep/donate/trash decision framework) → Room priority order → Zone system (everything has a home) → Category rules (like with like) → One-in-one-out policy → Family buy-in strategy → 15-minute daily reset habit → Seasonal sort protocol → Maintenance over perfection.

## Step 3 — Quality & Polish

- Declutter before organizing — organizing clutter is wasted effort
- Zone system specific to each room
- Family buy-in essential — one person cannot maintain alone

Always offer a relevant next step.
