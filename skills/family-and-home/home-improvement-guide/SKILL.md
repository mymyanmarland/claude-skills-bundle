# Home Improvement Planning Guide Skill

## Step 1 — Gather Inputs

- Project type
- Budget available
- DIY skill level
- Timeline
- Home owned or rented

## Step 2 — Core Output

Home improvement guide: Project prioritization (maintenance first, then improvements) → Budget estimation formula (always add 20% contingency) → DIY vs contractor decision framework (when to never DIY: electrical/structural/major plumbing) → Contractor hiring guide (quotes/references/contracts) → Project sequencing (what order matters) → Permits and inspections basics.

## Step 3 — Quality & Polish

- Contingency budget non-negotiable — projects always cost more
- DIY never list specific — safety critical
- Contractor hiring process specific

Always offer a relevant next step.
