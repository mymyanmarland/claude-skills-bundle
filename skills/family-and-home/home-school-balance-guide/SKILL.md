# Home and School Balance Guide Skill

## Step 1 — Gather Inputs

- Children ages and grades
- Work schedule of parents
- Current homework battles
- Academic concerns
- After school logistics

## Step 2 — Core Output

School balance system: After-school transition time (decompression before homework) → Homework environment setup → Time estimation (most kids underestimate) → Parent support vs doing-it-for-them line → Teacher communication protocol → Long-term project system → Test preparation routine → When to seek extra help.

## Step 3 — Quality & Polish

- Decompression time first — transitions are hard for kids
- Parent involvement line clear — support not rescue
- Long-term project system prevents last-minute panic

Always offer a relevant next step.
