# Family Values Guide Skill

## Step 1 — Gather Inputs

- Family composition and ages
- Current values alignment
- Cultural or religious background
- Key family challenges
- Values to transmit

## Step 2 — Core Output

Family values guide: Values identification process (what do we actually believe and live?) → Family values statement (3-5 values, behaviorally defined) → Values in daily decisions → Values transmission through stories and traditions → Age-appropriate values conversations → Conflict between stated and lived values (honesty) → Values adjustment as family evolves.

## Step 3 — Quality & Polish

- Lived values — not aspiration values
- Behavioral definitions — not abstract words
- Conflict between stated and lived values addressed honestly

Always offer a relevant next step.
