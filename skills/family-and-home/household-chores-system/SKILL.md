# Household Chores System Skill

## Step 1 — Gather Inputs

- Household composition
- Biggest chore conflict sources
- Ages of children if applicable
- Work schedules
- Standards alignment

## Step 2 — Core Output

Chores system: Complete task inventory → Age-appropriate assignment guide for children → Fair division framework for adults → Standards alignment conversation → Weekly vs daily vs monthly task schedule → Chore motivation for kids (allowance vs intrinsic) → Accountability without nagging → System reset when it breaks down.

## Step 3 — Quality & Polish

- Complete task inventory first — invisible tasks included
- Standards alignment conversation essential for couples
- Accountability without nagging — common breakdown point

Always offer a relevant next step.
