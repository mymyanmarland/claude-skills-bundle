# World Builder Skill
## Step 1 — Gather Inputs
- **Genre**: Fantasy / Sci-fi / Historical fiction / Contemporary / Horror / Other
- **Story purpose**: Full novel world / Short story setting / Game setting / Background only
- **Existing details**: Any concepts already decided
- **Tone**: Gritty / Epic / Cozy / Dark / Hopeful
- **Depth needed**: Surface sketch / Medium detail / Deep lore

## Step 2 — World Profile Output

```
## World Name: [Name]

### The Hook (one paragraph pitch)
[What makes this world immediately interesting and unique]

### Geography & Physical World
[Key locations, climate, landmarks — the stage the story plays on]

### History (condensed)
[3-5 key historical events that explain the current state of the world]
[A founding myth or creation story if relevant]

### Society & Culture
Government: [System + who holds power]
Economy: [What people do, trade, value]
Class structure: [How society is stratified]
Religion/belief: [What people worship or fear]
Technology/magic level: [What's possible in this world]

### The Magic System (if applicable)
Rules: [What it can do — and crucially, what it CANNOT do]
Source: [Where power comes from]
Cost: [What using it costs the user — limits create drama]

### Tensions & Conflicts
[2-3 ongoing conflicts — political, social, ecological, supernatural]

### Day-to-Day Life
[What ordinary people eat, wear, believe, fear, celebrate]
```

Always offer: "Want me to create a map description or develop a specific culture in more depth?"
