# Riddle Writer Skill
## Step 1 — Gather Inputs
- **Theme**: Animals / Objects / Nature / Abstract concepts / Custom
- **Difficulty**: Easy (kids 5-8) / Medium (kids 9-12 / adults casual) / Hard (adults)
- **Style**: "What am I?" / "What has X but no Y?" / Rhyming / Story riddle
- **Number of riddles**: 5 / 10 / 20
- **Purpose**: Party game / Book / Social media / Classroom / Gift

## Step 2 — Riddle Construction Principles
- **The answer has two layers**: What it literally is + what the clues suggest obliquely
- **Red herring language**: Words that suggest the wrong answer first
- **The aha moment**: When they hear the answer, they should think "of course!"
- **Avoid riddles with multiple valid answers** — frustrating, not fun

## Step 3 — Riddle Output
```
## Riddles: [Theme] | Difficulty: [X]

1. [Riddle — phrased to mislead cleverly]
   Answer: [Answer] | Hint if needed: [Hint]

2. [Riddle]
   Answer: [Answer]

[Continue for all riddles]

---

### ANSWERS (separate section for quiz use)
1. [Answer]
2. [Answer]
[Continue]
```

## Step 4 — Riddle Types
- **Classic "What am I?"**: "I have hands but cannot clap..." → Clock
- **"The more you take, the more you leave behind"** → Footsteps (classic structure)
- **Two-line rhyming**: AABB or ABAB with the answer in the rhythm
- **Story riddle**: A paragraph with the answer hidden in the logic

Always offer: "Want these formatted as a printable riddle card game?"
