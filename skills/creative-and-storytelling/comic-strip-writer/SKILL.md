# Comic Strip Writer Skill
## Step 1 — Gather Inputs
- **Format**: Single strip (3-4 panels) / Multi-page / Ongoing series
- **Genre**: Comedy / Adventure / Slice of life / Satire / Kids / Superhero
- **Characters**: Existing characters or create new ones
- **Theme or joke premise**: (or generate)
- **Art style note**: Minimalist / Detailed / Cartoonish / Realistic (for artist reference)
- **Audience**: Kids / Teens / Adults / General

## Step 2 — Comic Script Format
```
## Comic Strip: "[Title]"
Format: [X panels] | Genre: [X] | Audience: [X]

---

### PANEL 1
**Setting**: [Where we are — described for the artist]
**Visual**: [What we see — action, expression, body language]
**Caption** (narration box, if any): "[Text]"
**Dialogue**:
- [Character A]: "[Line]"
- [Character B]: "[Line]"

### PANEL 2
**Setting**: [Any change]
**Visual**: [Key visual beat — reaction, action, reveal]
**Dialogue**:
- [Character]: "[Line]"

### PANEL 3
**Visual**: [The setup for the punchline]
**Dialogue**: "[Setup line]"

### PANEL 4 (punchline panel)
**Visual**: [The visual gag or emotional beat that lands the joke/moment]
**Dialogue**: "[Punchline]"
[Or: **Silence** — some of the best comic beats are wordless]

---

### SERIES NOTES (if ongoing)
Character bible: [Short description of each recurring character's voice/quirk]
Running theme: [The comedic or thematic throughline]
```

## Step 3 — Comic Timing Rules
- The punchline lands in the **last panel** — never before
- **Visual gag > verbal joke** whenever possible — the art should do the work
- **One beat per panel** — don't crowd panels with multiple things
- **Reactions are funnier than actions** — show the face, not just the event

Always offer: "Want me to write a 5-strip series with these characters?"
