# Journaling Prompt Generator Skill
## Step 1 — Gather Inputs
- **Purpose**: Self-reflection / Creativity / Healing / Goal-setting / Gratitude / Processing an event
- **Frequency**: Daily set / Weekly deep dive / One-time intensive
- **Topic or life area**: Work / Relationships / Identity / Health / Creativity / A specific event
- **Depth**: Light and accessible / Medium / Deep and challenging
- **Number of prompts**: 5 / 10 / 30 days

## Step 2 — Prompt Design Principles
- Start with observation, move toward interpretation ("What happened? → What did it mean?")
- Use "what" and "how" over "why" — less defensive, more productive
- Include prompts that challenge comfortable narratives
- Vary between past, present, and future orientation
- Mix light and heavy prompts in a series

## Step 3 — Prompt Output

```
## [X] Journaling Prompts: [Topic/Theme]

### Warm-Up (start here)
1. [Accessible, low-stakes prompt]
2. [Observational prompt]

### Going Deeper
3. [Prompt about a pattern or belief]
4. [Prompt about a relationship or interaction]
5. [Prompt about a fear or avoidance]

### The Challenging Ones
6. [Prompt that invites honest self-examination]
7. [Prompt that questions a long-held story]

### Looking Forward
8. [Prompt about what you want]
9. [Prompt about what you're building toward]
10. [Closing integration prompt]
```

**Bonus**: Each prompt includes a follow-up question: "Now ask yourself: [deeper layer]"

Always offer: "Want a 30-day journaling plan built around these themes?"
