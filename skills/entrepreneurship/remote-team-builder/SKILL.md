# Remote Team Builder Skill

## Step 1 — Gather Inputs

- Team size and stage
- Geographic distribution
- Time zone spread
- Communication challenges
- Tools budget

## Step 2 — Core Output

Remote team system: Communication stack (async-first tool selection) → Meeting design for remote (fewer, more purposeful) → Documentation culture (write everything important) → Remote onboarding program → Culture-building for distributed teams → Time zone management → Remote performance management → Hiring considerations for remote (self-direction, writing, async communication).

## Step 3 — Quality & Polish

- Async-first explicitly designed — not just 'use Slack'
- Documentation culture as infrastructure — not optional
- Remote hiring criteria specific — not just 'able to work remotely'

Always offer a relevant next step.
