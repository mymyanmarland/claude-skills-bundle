# CAC/LTV Optimizer Skill

## Step 1 — Gather Inputs

- Business model
- Current CAC and LTV if known
- Acquisition channels
- Churn rate
- Revenue model

## Step 2 — Core Output

CAC/LTV analysis: Current ratio calculation (LTV:CAC — target 3:1 minimum) → CAC breakdown by channel → LTV calculation (ARPU × gross margin ÷ churn rate) → CAC reduction levers → LTV expansion levers (reduce churn / increase ARPU / improve margin) → Payback period target → Which lever to pull first based on current ratio → Model sensitivity.

## Step 3 — Quality & Polish

- LTV calculation uses gross margin — not revenue
- 3:1 target explained — not just stated
- Payback period included — cash flow reality, not just ratio

Always offer a relevant next step.
