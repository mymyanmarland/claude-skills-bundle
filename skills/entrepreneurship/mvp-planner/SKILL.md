# MVP Planner Skill

## Step 1 — Gather Inputs

- Product concept
- Riskiest assumptions to test
- Target users
- Technical resources
- Timeline and budget

## Step 2 — Core Output

MVP plan: Core value hypothesis (what ONE thing must the MVP prove?) → Feature ruthlessness (what to cut — everything not testing the core hypothesis) → MVP type selection (concierge/wizard-of-oz/landing page/smoke test/prototype) → Build plan → Success metrics defined before building → User testing protocol → What you'll learn and how it informs next steps.

## Step 3 — Quality & Polish

- ONE hypothesis tested — not many
- MVP type matched to what needs to be learned
- Success metrics defined before building — not post-hoc

Always offer a relevant next step.
