# Startup Financial Model Guide Skill

## Step 1 — Gather Inputs

- Business model and revenue streams
- Unit economics if known
- Cost structure
- Growth assumptions
- Funding stage

## Step 2 — Core Output

Financial model guide: Revenue model (bottom-up: units × price, not top-down % of market) → Key metrics by model type (SaaS: MRR/churn/CAC/LTV, marketplace: GMV/take rate, e-commerce: AOV/repeat rate) → Cost build (people heavy — hire plan drives costs) → Cash flow projection → Runway calculation → Sensitivity analysis (what if growth is half of projected?) → Investor-facing summary.

## Step 3 — Quality & Polish

- Bottom-up revenue projection — not market share fantasy
- People cost is usually 60-70% — model it carefully
- Sensitivity analysis shows what breaks the model

Always offer a relevant next step.
