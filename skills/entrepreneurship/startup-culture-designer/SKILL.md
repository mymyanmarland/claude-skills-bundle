# Startup Culture Designer Skill

## Step 1 — Gather Inputs

- Founding team values
- Business type and pace
- Team size and stage
- Culture problems to prevent
- Culture to create

## Step 2 — Core Output

Culture design: Values identification (3-5 real values — behaviors, not aspirations) → Value operationalization (what does each value look like in daily action?) → Anti-values (what you explicitly reject) → Rituals (weekly/monthly touchpoints that reinforce culture) → Hiring for culture → Onboarding culture transmission → Culture check as company scales.

## Step 3 — Quality & Polish

- Values describe behavior — not aspirations like 'excellence'
- Anti-values as important as values — says what you won't tolerate
- Culture transmission in hiring and onboarding explicit

Always offer a relevant next step.
