# Data Cleaning Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Data cleaning: Audit before cleaning (understand the mess first) → Missing value strategies (delete/impute/flag) → Duplicate identification and removal → Outlier detection and treatment → Data type standardization → String cleaning (inconsistent entries) → Date format standardization → Join and merge quality checks → Documentation of all cleaning decisions → Version control for datasets.

## Step 3 — Quality & Polish

- Audit first — understand before changing
- Document all decisions — reproducibility
- Version control — never overwrite original data

Always offer a relevant next step.
