# Data Visualization for Analysis Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Analysis visualization: EDA visualization workflow → Chart type by data type (continuous/categorical/temporal/relational) → Small multiples for comparison → Distribution visualization (histogram/box plot/violin) → Correlation visualization → Time series analysis charts → Heat maps for pattern detection → Residual plots → Annotation for insight communication.

## Step 3 — Quality & Polish

- EDA visualization workflow — sequence matters
- Distribution visualization — often overlooked for descriptive stats
- Annotation turns visualization into communication

Always offer a relevant next step.
