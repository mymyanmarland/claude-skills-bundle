# Citation Management Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Citation management: Tool comparison (Zotero/Mendeley/EndNote/Paperpile) → Import methods (DOI/ISBN/browser plugin/PDF import) → Library organization (folders/tags/notes) → Citation styles (APA/MLA/Chicago/Vancouver) → In-text citation workflow → Bibliography generation → Group library for collaboration → Citation troubleshooting → Cloud sync setup.

## Step 3 — Quality & Polish

- Tool comparison honest — different tools for different workflows
- Browser plugin for capture — essential feature
- Citation style application in word processor

Always offer a relevant next step.
