# Qualitative Coding Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Qualitative coding: Coding approaches (inductive/deductive/abductive) → In vivo vs constructed codes → First cycle coding (open/descriptive/values) → Second cycle coding (pattern/focused/axial) → Code development and refinement → Codebook creation → Software options (NVivo/ATLAS.ti/Dedoose/manual) → Intercoder reliability → Moving from codes to themes → Audit trail.

## Step 3 — Quality & Polish

- First vs second cycle coding — building abstraction
- Codebook as documentation and reliability tool
- Audit trail — demonstrates rigor

Always offer a relevant next step.
