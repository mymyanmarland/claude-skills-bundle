# Data Analysis Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Data analysis: Define the question before touching the data → Data quality audit (missing values/outliers/inconsistencies) → Exploratory data analysis (EDA) → Descriptive statistics → Inferential statistics (if hypothesis testing) → Visualization for insight discovery → Insight extraction (what does the data actually say?) → Communicating findings → Limitations acknowledgment.

## Step 3 — Quality & Polish

- Question first — prevents fishing for results
- EDA before confirmatory analysis
- Limitations section — honest about what data cannot tell you

Always offer a relevant next step.
