# Predictive Analytics Basics Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Predictive analytics: Prediction vs causation distinction → Train/test split methodology → Common algorithms simplified (linear regression/decision trees/random forest) → Feature selection → Overfitting and how to detect it → Model evaluation metrics (RMSE/accuracy/AUC) → Business application examples → When prediction is ethical → Communicating predictive uncertainty → Tools (Python scikit-learn/R/SPSS).

## Step 3 — Quality & Polish

- Prediction vs causation — the critical distinction
- Overfitting — the most common beginner mistake
- Communicating uncertainty — predictions have ranges not points
