# Policy Analysis Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Policy analysis: Problem definition (what is the policy trying to solve?) → Stakeholder mapping → Policy options identification → Criteria development (efficiency/equity/feasibility/effectiveness) → Evidence review for each option → Trade-off analysis → Recommendation development → Implementation considerations → Monitoring and evaluation framework → Policy brief writing.

## Step 3 — Quality & Polish

- Problem definition before solutions — common reversal
- Criteria before evaluation — prevents post-hoc rationalization
- Policy brief writing — the communication output

Always offer a relevant next step.
