# Fact-Checking Guide Skill

## Step 1 — Gather Inputs

- Research question or objective
- Context and audience
- Existing knowledge and data available
- Methodology experience level
- Timeline and resources

## Step 2 — Core Output

Fact-checking: Claim identification and isolation → Source tracing (find the original, not the report of a report) → Primary vs secondary source distinction → Lateral reading technique (check sources about the source) → Expert consultation protocols → Statistical claim verification → Image and video verification basics → Reverse image search → Documentation and transparency → Rating scale for claims.

## Step 3 — Quality & Polish

- Lateral reading — the key professional technique
- Original source tracing — not the report of a report
- Image verification basics — critical in visual media

Always offer a relevant next step.
