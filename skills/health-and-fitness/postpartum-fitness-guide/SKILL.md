# Postpartum Fitness Guide Skill

## Step 1 — Gather Inputs

- Delivery type: vaginal/C-section
- Weeks postpartum
- Healthcare provider clearance
- Breastfeeding status
- Previous fitness level

## Step 2 — Core Output

Postpartum plan: Phase 1 (weeks 1-6: breathing and pelvic floor — before clearance) → Phase 2 (weeks 6-12: gentle return with clearance) → Phase 3 (weeks 12+: progressive loading) → Diastasis recti awareness → Pelvic floor dysfunction signs → Breastfeeding modifications → Newborn fatigue management.

## Step 3 — Quality & Polish

- Medical clearance required before Phase 2 — prominently stated
- Pelvic floor priority
- Diastasis recti awareness included

Always offer a relevant next step.
