# Nutrition Plan Builder Skill

## Step 1 — Gather Inputs

- Goal: fat loss/muscle gain/maintenance
- Current weight and target
- Activity level
- Dietary restrictions
- Food preferences

## Step 2 — Core Output

Nutrition plan: TDEE calculation → Goal-adjusted calorie target → Macro split in grams → Meal timing recommendations → 3 sample meal plan days → Food list by macro → Pre/post workout nutrition → Supplement basics → Tracking approach.

## Step 3 — Quality & Polish

- Protein target per kg bodyweight specific
- TDEE calculated before target set
- Supplement recommendations evidence-based only

Always offer a relevant next step.
