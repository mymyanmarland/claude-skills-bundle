# Running Training Plan Skill

## Step 1 — Gather Inputs

- Target race or distance
- Current weekly mileage
- Race date
- Days available to run
- Current fitness level

## Step 2 — Core Output

Race training plan: Weekly schedule with run types (easy/tempo/intervals/long run) → Mileage progression (10% rule) → Pace guidance per run type → Cross-training recommendations → Taper protocol → Race day strategy → Nutrition and hydration during training → Injury prevention.

## Step 3 — Quality & Polish

- 10% mileage increase rule enforced
- Easy run pace genuinely easy
- Taper included and justified

Always offer a relevant next step.
