# Flexibility and Mobility Program Skill

## Step 1 — Gather Inputs

- Tight areas or limitations
- Goal: performance/pain relief/posture
- Time available
- Before or after training
- Activity context

## Step 2 — Core Output

Mobility program: Dynamic warm-up (pre-workout) → Static stretching (post-workout) → Targeted mobility by area (hips/shoulders/thoracic/ankles) → Daily 10-min routine → Weekly 30-min session → PNF stretching → Foam rolling → Progress milestones.

## Step 3 — Quality & Polish

- Dynamic before training, static after
- Area-specific protocols
- Progress milestones for motivation

Always offer a relevant next step.
