# Bodyweight Strength Program Skill

## Step 1 — Gather Inputs

- Current bodyweight strength levels
- Goal: general strength/calisthenics skills/muscle
- Training days
- Space available
- Timeline

## Step 2 — Core Output

Bodyweight strength program: Skill hierarchy (push-up → pike push-up → handstand push-up / squat → pistol squat) → Horizontal and vertical push/pull balance → Core anti-movement exercises → Grip and wrist preparation → Progressive variations for each movement pattern → Testing days → Skill-specific practice (handstand/muscle-up/planche) → Training log.

## Step 3 — Quality & Polish

- Progressive variations provided for all skill levels
- Push and pull balanced — most skip pulling
- Skill practice separate from strength work

Always offer a relevant next step.
