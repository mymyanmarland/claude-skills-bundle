# Overtraining Recovery Plan Skill

## Step 1 — Gather Inputs

- Symptoms experienced
- Training volume and intensity
- Duration of overtraining
- Current vs past performance
- Willingness to rest

## Step 2 — Core Output

Overtraining recovery: Symptom checklist (vs under-recovery vs true OTS) → Complete rest prescription → Active recovery phase → Gradual return → Root cause analysis → Structural prevention (load management/deload/HRV) → Relationship with exercise reflection → Return-to-performance timeline.

## Step 3 — Quality & Polish

- True OTS vs functional overreaching distinguished
- Complete rest often required — delivered clearly
- Root cause addressed not just symptoms

Always offer a relevant next step.
