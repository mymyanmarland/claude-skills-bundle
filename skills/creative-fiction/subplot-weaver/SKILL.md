# Subplot Weaver Skill

## Step 1 — Gather Inputs

- Main plot summary
- Current subplots if any
- Theme of the story
- Character relationships
- Genre and length

## Step 2 — Core Output

Subplot design: 2-3 subplot concepts that mirror, contrast, or complicate the main theme → For each: character(s) involved, their arc, how it intersects with main plot at key moments, what it reveals about theme, when it resolves. Integration map: which chapters/scenes each subplot appears in. Rule: subplots should intersect the main plot at the midpoint and climax.

## Step 3 — Quality & Polish

- Each subplot illuminates theme from different angle
- Subplots intersect main plot at structural beats
- Subplot resolution before or at climax — not after

Always offer a relevant next step.
