# Setting & Atmosphere Writer Skill

## Step 1 — Gather Inputs

- Location type
- Time period and time of day
- Emotional atmosphere to create
- Which character is experiencing this
- What the setting should reflect about theme or character state

## Step 2 — Core Output

Setting description with: sensory layering (not just visual — sound, smell, texture, temperature), character's perceptual filter (they notice what matters to their emotional state), atmosphere created through selection (what to include/exclude), setting as character (environment reflects mood or theme). Short version (100 words) and extended version (300 words) both provided.

## Step 3 — Quality & Polish

- Setting filtered through character perception — not omniscient description
- Atmosphere created through specific details — not adjectives like 'eerie'
- At least 3 senses engaged

Always offer a relevant next step.
