# Revision Strategy Guide Skill

## Step 1 — Gather Inputs

- Draft completion stage
- Known weaknesses
- Length and genre
- Time available for revision
- Goal: polish/restructure/character/prose

## Step 2 — Core Output

Revision plan: Pass 1 — structural (does the story work? arc, pacing, plot holes — no line editing yet) → Pass 2 — character (consistent? motivated? arc completed?) → Pass 3 — scene-level (does each scene earn its place?) → Pass 4 — prose (sentence by sentence) → Pass 5 — consistency (timeline, names, details). Do not reverse the order. Never start with prose when structure is broken.

## Step 3 — Quality & Polish

- Passes done in order — structure before prose always
- Each pass has specific focus — not general 'make it better'
- Writer knows what to look for in each pass

Always offer a relevant next step.
