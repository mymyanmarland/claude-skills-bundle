# Symbolic Object Writer Skill

## Step 1 — Gather Inputs

- Story theme
- Character whose relationship to object matters
- When the object appears in the story
- What the object should mean
- Tone: subtle/overt

## Step 2 — Core Output

Symbol development: Object chosen and why (natural connection to theme) → First appearance (establish it naturally — not forced) → Subsequent appearances (each adds meaning through context) → Climactic use (payoff) → Variation strategy (same object means different things at different moments). The best symbols work on the literal level first — the reader doesn't need to see the symbolism to enjoy the story.

## Step 3 — Quality & Polish

- Object chosen for organic thematic connection — not arbitrary
- First appearance natural — not obviously symbolic
- Works on literal level — symbolism enhancement, not requirement

Always offer a relevant next step.
