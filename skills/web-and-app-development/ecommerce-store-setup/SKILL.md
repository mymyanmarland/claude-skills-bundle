# E-commerce Store Setup Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

E-commerce setup: Platform selection (Shopify vs WooCommerce vs others) → Product page optimization (images/descriptions/reviews) → Checkout optimization (friction reduction) → Payment gateway setup → Shipping configuration → Tax setup → Email automation (abandoned cart/welcome/post-purchase) → Analytics and conversion tracking → SEO fundamentals for products.

## Step 3 — Quality & Polish

- Platform choice based on product type and technical comfort
- Checkout friction the biggest conversion killer
- Abandoned cart automation — immediate revenue recovery

Always offer a relevant next step.
