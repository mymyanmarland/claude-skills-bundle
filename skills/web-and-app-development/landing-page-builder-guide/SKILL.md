# Landing Page Builder Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

Landing page building: Platform selection (Unbounce/Leadpages/Carrd/Webflow) → Above-fold design (value prop/visual/CTA) → Section structure (problem/solution/proof/offer/CTA) → Mobile optimization → Page speed optimization → A/B testing setup → Analytics and conversion tracking → Heatmap installation → Integration with email platform.

## Step 3 — Quality & Polish

- Above-fold value prop test with 5-second rule
- Mobile optimization checked before any traffic
- Conversion tracking before running ads

Always offer a relevant next step.
