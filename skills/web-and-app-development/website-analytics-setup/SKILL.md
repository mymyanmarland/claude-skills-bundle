# Website Analytics Setup Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

Analytics setup: GA4 property setup and configuration → Goal and conversion event setup → E-commerce tracking (if applicable) → Google Search Console integration → Custom dimensions and segments → Dashboard creation → Automated reports → Privacy compliance (cookie consent/GDPR) → Heat mapping tool (Hotjar/Microsoft Clarity) → Regular review cadence.

## Step 3 — Quality & Polish

- Conversion events before traffic analysis — measure what matters
- Search Console integration — free SEO data
- Privacy compliance required — not optional in many jurisdictions

Always offer a relevant next step.
