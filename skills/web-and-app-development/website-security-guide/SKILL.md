# Website Security Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

Website security: SSL/HTTPS enforcement → Regular backup automation → Software updates (CMS/plugins/themes) → Strong password policies and 2FA → Login protection (limit attempts/CAPTCHA) → Web application firewall → Malware scanning → File permission hardening → Security monitoring → Incident response plan.

## Step 3 — Quality & Polish

- Backups before any other security — recovery capability
- Updates the single most important security action
- WAF — stops most common attacks before they reach the site

Always offer a relevant next step.
