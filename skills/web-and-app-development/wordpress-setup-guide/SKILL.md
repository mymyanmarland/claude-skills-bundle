# WordPress Setup and Configuration Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

WordPress setup: Hosting selection (managed vs shared) → SSL setup → Core settings configuration → Theme selection criteria (speed/security/support) → Essential plugins (security/SEO/caching/backup) → Performance optimization → Security hardening → Automatic updates setup → Staging environment → Google Analytics and Search Console integration.

## Step 3 — Quality & Polish

- Hosting quality determines site performance ceiling
- Plugin minimalism — each plugin is a liability
- Backup automation before anything else

Always offer a relevant next step.
