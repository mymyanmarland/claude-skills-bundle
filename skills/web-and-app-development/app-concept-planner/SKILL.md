# App Concept and MVP Planner Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

App planning: Problem validation (is this worth building?) → Core feature definition (the one thing the app does) → MVP feature list (cut 50% then cut again) → Platform decision (iOS/Android/both/web first) → Build options (no-code/low-code/custom) → Technical requirements overview → Cost estimation → Monetization model → Go-to-market basics.

## Step 3 — Quality & Polish

- Problem validation before feature planning
- MVP ruthlessness — cut until uncomfortable
- Build option matched to timeline and budget

Always offer a relevant next step.
