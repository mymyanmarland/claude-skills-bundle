# Technical SEO Implementation Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

Technical SEO: Site speed (Core Web Vitals targets) → Mobile-first indexing compliance → XML sitemap creation and submission → Robots.txt configuration → Canonical tags implementation → Schema markup deployment → HTTPS and security → Internal linking structure → Crawl error fixing → Structured data testing.

## Step 3 — Quality & Polish

- Core Web Vitals specific targets — not vague speed improvement
- Schema markup by page type — article/product/FAQ
- Crawl error fixing before content optimization

Always offer a relevant next step.
