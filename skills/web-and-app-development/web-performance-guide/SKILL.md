# Web Performance Optimization Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

Web performance: LCP optimization (largest contentful paint — images and server) → FID/INP optimization (interaction delays — JavaScript) → CLS optimization (layout shifts — reserved image dimensions) → Image optimization (format/compression/lazy loading) → Caching strategy → CDN implementation → JavaScript and CSS minification → Server response time → Performance monitoring setup.

## Step 3 — Quality & Polish

- Image optimization — typically 50-70% of page weight
- LCP element identification — optimize that specific element
- Monitoring setup — performance degrades without measurement

Always offer a relevant next step.
