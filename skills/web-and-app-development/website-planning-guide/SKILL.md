# Website Planning Guide Skill

## Step 1 — Gather Inputs

- Project type and goals
- Technical skill level
- Platform or tools being used
- Timeline and budget
- Specific challenge or question

## Step 2 — Core Output

Website planning: Goals and success metrics → Target audience and user needs → Sitemap and page structure → Content inventory and gaps → Technology stack selection (WordPress/Webflow/custom) → Hosting and domain → SEO foundation planning → Performance targets → Timeline and resource planning → Launch checklist.

## Step 3 — Quality & Polish

- Goals defined before any design or build
- Sitemap before design — structure determines everything
- Technology matched to team skills and budget

Always offer a relevant next step.
