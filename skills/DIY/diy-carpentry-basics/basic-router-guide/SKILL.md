# Basic Router Guide Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Router basics: Safety (goggles mandatory / secure workpiece / climb-cutting creates dangerous kickback — always rout against the bit direction) → Bit selection (straight bits for grooves/rebates / profile bits for edges) → Depth of cut (never take full depth in one pass — maximum 6mm per pass on most materials) → Direction of feed (route left to right on an edge when facing it — into the rotation of the bit) → Templates (guide bush and template for repeatable shapes) → Router table (inverted router — safer for small pieces and repetitive cuts).

## Step 3 — Quality & Polish

- Goggles mandatory: router bits throw debris at high speed
- Multiple passes: one deep pass burns the wood and stresses the motor
- Feed direction: anti-climb — always route into the bit rotation
