# Sanding and Finishing Wood Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Sanding and finishing: Grit progression (start with the coarsest needed to remove the defect / 80-120-180-240 — each removes the scratches of the previous) → Sand with the grain (cross-grain scratches show through any finish) → Dust removal (vacuum then tack cloth before any finish) → Finish selection (paint / varnish / oil / wax — each has different application and durability) → First coat seals (raise the grain / lightly sand before second coat) → Oil finishing (wipe on, wipe off excess — build up slowly) → Paint on wood (prime first — always).

## Step 3 — Quality & Polish

- Sand with the grain: cross-grain scratches are visible through any finish
- Tack cloth before finishing: dust under varnish ruins the finish
- Prime before painting: raw wood soaks paint unevenly without primer
