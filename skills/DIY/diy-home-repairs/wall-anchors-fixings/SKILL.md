# Wall Anchors and Fixings Guide Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Wall fixings: Wall type identification (solid masonry / stud timber frame / plasterboard on dot and dab / concrete) → Masonry (rawl plug matched to drill bit matched to screw size — all must match) → Plasterboard with cavity (plasterboard anchor: toggle bolt / spring toggle / metal stud if hitting one) → Plasterboard on dot and dab (caution: gap behind the board — special fixings required) → Stud timber (find the stud with a detector, screw directly into it — strongest fixing) → Weight ratings (always check the fixing's rated weight and do not exceed it).

## Step 3 — Quality & Polish

- Match plug to drill bit to screw: all three must be the same size
- Find the stud: the strongest plasterboard fixing is a screw directly into a timber stud
- Weight ratings: never exceed the rated load — fixings that fail can cause injury
