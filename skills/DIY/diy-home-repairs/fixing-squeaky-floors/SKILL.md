# Fixing Squeaky Floors Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Squeaky floors: Diagnosis (locate the squeak — bounce on each board/step) → Cause (boards rubbing against each other / loose board moving on the nail / board rubbing the joist) → Fixing from above (screws into the joist alongside the nail — pull the board tight / talcum powder between boards for board-rubbing squeaks) → Fixing from below (timber wedge or screw-and-washer through the subfloor if accessible) → Engineered floors (different approach — consult manufacturer guidance) → Old houses with original floors (gentle approach — preserve the boards).

## Step 3 — Quality & Polish

- Talcum powder: the easiest fix for boards rubbing each other — try it first
- Screw into the joist: the most permanent fix for a loose board
- Access from below: if possible this gives the cleanest result

Always offer a relevant next step or tip to try.
