# Laminate Flooring Installation Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Laminate installation: Acclimatisation (leave packs in the room for 48 hours) → Expansion gap (10mm all around the perimeter — covered by skirting / doors may need trimming) → Underlay (foam or rubber — install perpendicular to board direction / tape joins) → Starting wall (work from left to right / start from the straightest wall) → First row (leave the expansion gap / use spacers) → Staggered joints (end joints at least 300mm from row above — use off-cuts to start each row) → Tapping block (never tap directly on the board — protect the tongue) → Last row (pull bar to click into place against the wall).

## Step 3 — Quality & Polish

- Acclimatise first: laminate expands when it warms up — let it happen before laying
- Expansion gap everywhere: skirting covers it — never omit it or the floor will buckle in summer
- Staggered joints: parallel end joints look bad and are weaker
