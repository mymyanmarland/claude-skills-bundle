# Underfloor Heating Basics Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

UFH basics: System types (electric mat: thin / easy for small areas like bathrooms / water UFH: efficient for whole house but more complex) → Electric mat installation (rolled out in a serpentine pattern / do not overlap or cross the cable / tile adhesive covers the mat) → Thermostat (floor sensor required / programmable thermostat / consult an electrician for the wiring connection) → Floor build-up (electric mat adds only 3-5mm to floor level — minimal disruption) → Suitable floor coverings (tiles / stone / some LVT — check product compatibility) → Do not cut the cable (if the mat is too long, fold the wire back more tightly — never cut).

## Step 3 — Quality & Polish

- Never cut the heating cable: cutting it destroys the mat
- Thermostat wiring by an electrician: the mains connection requires a qualified person
- Check floor covering compatibility: not all flooring works with UFH

Always offer a relevant next step or tip to try.
