# Collagraph Printmaking Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Collagraph: Plate building (thick card / mount board as base / glue textured materials: sandpaper / fabric / leaves / string / carborundum) → Sealing the plate (PVA or acrylic varnish — the plate must be sealed before inking) → Inking (relief inking: roll ink over the top surfaces / intaglio inking: push ink into recessed areas and wipe) → Printing (press by hand or through an etching press) → Layered colour (print one colour / re-ink / overprint another) → Plate longevity (sealed plates last 10-20 prints / unsealed plates deteriorate quickly).

## Step 3 — Quality & Polish

- Seal the plate thoroughly: an unsealed collagraph falls apart when wet with ink
- Relief vs intaglio inking: both can be used on the same plate for rich effects
- Collagraph textures: the most accessible intaglio — no acid required

Always offer a relevant next step or tip to try.
