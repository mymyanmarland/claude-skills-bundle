# Home Printmaking Studio Setup Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Home studio setup: Space requirements (a table you can make ink marks on / ventilation for oil-based inks / access to water for cleanup) → Essential equipment (inking slab — glass or perspex / brayers — hard rubber and foam / burnisher for hand printing / printing table) → Press alternatives (etching press: significant investment / baren for relief printing / spoon burnishing / print-making barens) → Ink storage (seal tubes tightly / store oil-based inks upright) → Paper storage (flat / away from damp) → Safety (ventilation for solvents / gloves for acid work / skin barrier cream).

## Step 3 — Quality & Polish

- Glass inking slab: easy to clean / shows ink consistency well
- Ventilation for oil-based inks: solvents in cleanup require airflow
- Baren for hand printing: enables press-quality relief prints without an etching press

Always offer a relevant next step or tip to try.
