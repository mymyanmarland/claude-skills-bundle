# Printing an Edition Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Printing an edition: Edition size (decide before printing — typical: 10-50 for handmade / artist proofs: APs) → Proofing (bon à tirer BAT proof — the approved standard for the edition / all prints must match the BAT) → Consistency (same ink mix / same paper / same pressure / same technique) → Numbering convention (1/25 means first of 25 / AP I/V means first artist proof of five) → Signing (pencil only — on the margin outside the plate mark) → Presentation (tissue between prints / stored flat / portfolio box for the edition) → Artist proofs (not for sale — the printer's reference copies).

## Step 3 — Quality & Polish

- BAT proof: the standard all prints are compared to — essential for consistency
- Pencil signatures only: ink signatures on prints are considered inappropriate
- Consistent mixing: mix all the ink for the whole edition at once — batch colour matching is difficult
