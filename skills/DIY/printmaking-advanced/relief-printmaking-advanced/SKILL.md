# Advanced Relief Printmaking Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Advanced relief printing: Reduction printing (carve and print / carve more and overprint — each layer reduces the previous / the original plate is destroyed — irreversible process) → Multi-block printing (separate block for each colour / precise registration required) → Key block (the first block / usually the darkest / all other blocks register to the key) → Registration system (corner stops or registration jig) → Paper selection (Japanese papers / hosho / kozo — absorbent and strong / take ink beautifully) → Proofing (proof before the edition / correct the block before printing the full edition).

## Step 3 — Quality & Polish

- Reduction printing is irreversible: plan every colour before starting
- Key block registration: every subsequent block must align to the key
- Japanese paper: superior ink absorption and detail resolution for relief printing
