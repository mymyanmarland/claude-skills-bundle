# Reduction Linocut Masterclass Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Reduction linocut: Planning (plan all colours before cutting — you cannot go back) → Colour order (lightest colour first / darkest last — each carve removes the option to print that area again) → Registration (corner tabs / registration board / every print must align precisely) → Paper quantity (print enough for the edition plus proofs at each stage — destroyed plate means no reprint) → Carving between colours (remove areas that should remain the current colour) → Edition numbering (reduction prints are limited by definition / number them accordingly).

## Step 3 — Quality & Polish

- Plan all colours before any cutting: the reduction process is irreversible
- Print more than you need: failed registrations and test prints reduce the final edition
- Edition numbering: reduction prints are inherently limited — number and sign them
