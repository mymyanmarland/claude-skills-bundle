# Paper Quilling Techniques Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Paper quilling: Tools (slotted quilling tool / needle tool / circle sizer / tweezers / adhesive) → Basic coils (tight coil / loose coil / teardrop / marquise / square / triangle — practise each separately) → Paper width (3mm for fine work / 5mm standard / 10mm for bold designs) → Gluing technique (tiny amount of PVA at the end of the coil — toothpick is ideal) → Composition (sketch layout first / work from background to foreground) → 3D quilling (cone / dome / box shapes — more complex assembly) → Colour gradients (ombre quilling strips).

## Step 3 — Quality & Polish

- Tiny amount of adhesive: too much glue distorts the paper edge and shows
- Circle sizer for consistency: coils without a sizer vary unpredictably
- Background before foreground: plan the composition before starting

Always offer a relevant next step or tip to try.
