# Pop-Up Card Engineering Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Pop-up card engineering: Basic mechanisms (V-fold / parallel fold / pivoting layers / rotating discs) → V-fold (the simplest mechanism — scored card glued perpendicular to the fold) → Parallel fold (rises parallel to the base fold — more complex) → Design rule (all pop-up elements must fold flat when card closes) → Paper weight selection (cover weight 240gsm for the base / lighter paper for pop-up elements) → Test in scrap first (always build in cheap paper before cutting the final version) → Layering pop-ups (multiple mechanisms in one card — sequence carefully).

## Step 3 — Quality & Polish

- Test in cheap paper first: pop-up mechanisms always need at least one test run
- Must fold flat: if any element does not collapse, the card cannot close
- V-fold first: master the simplest mechanism before attempting complex ones

Always offer a relevant next step or tip to try.
