# Goldwork Embroidery Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Goldwork: Jap gold thread / purls (smooth/rough/check/crinkle) → Couching (two threads laid / couched every 4-5mm) → Felt padding (layers build raised surface) → Chip work (purl cut into short lengths stitched over padding) → Bricking (offset purl placements) → Shading with purls → Chenille needle for passing thread.

## Step 3 — Quality & Polish

- Couching every 4-5mm: too far apart allows the thread to shift
- Padding layers for relief: progressively smaller felt shapes build a dome
- Purl lengths cut cleanly: jagged ends affect the finished surface
