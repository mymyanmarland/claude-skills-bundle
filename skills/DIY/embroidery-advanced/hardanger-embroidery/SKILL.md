# Hardanger Embroidery Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Hardanger: Hardanger fabric (22-count) → Kloster blocks (5 satin stitches over 4 threads) → Cutting (ONLY after ALL kloster blocks are complete / between kloster blocks / never adjacent) → Withdrawing threads → Needleweaving over remaining bars → Dove's eye filling → Satin stitch surface embroidery.

## Step 3 — Quality & Polish

- Complete ALL kloster blocks before cutting: incomplete blocks cause the fabric to unravel
- Cutting only between blocks: the blocks anchor the cut threads
- Dove's eye in the empty squares: the decorative filling that defines Hardanger
