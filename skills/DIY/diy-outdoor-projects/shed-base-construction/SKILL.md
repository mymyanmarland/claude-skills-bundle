# Shed Base Construction Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Shed base: Base options comparison (concrete: most permanent / slabs: easier DIY / timber frame: preservative-treated / plastic grid: fast and eco) → Concrete base (excavate 150mm / compacted hardcore 100mm / 100mm concrete / damp proof membrane if needed) → Slab base (hardcore / sand levelling bed / slabs laid level with 3mm gaps / butt-jointed mortar-free) → Size (50mm larger than shed on all sides) → Level check (critical — an out-of-level shed stresses the structure and causes doors to bind) → Anchoring (shed anchor bolts or tie-downs into base).

## Step 3 — Quality & Polish

- 50mm oversize: prevents water running off roof into the base edge
- Level is critical: even 20mm out causes door problems and structural stress
- Anchor the shed: wind can move an unanchored shed
