# Garden Path Laying Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Garden path laying: Gravel path (excavate 100mm / weed membrane / edging restraints / 50mm compacted MOT Type 1 / 50mm gravel top) → Stepping stones (lay on sand / level each stone / 500mm centre-to-centre for comfortable stride) → Block paving (150mm compacted hardcore / 50mm sharp sand screeded level / blocks laid in pattern / kiln-dried sand brushed into joints / plate compactor) → Edging (essential for block paving and gravel — prevents spread) → Gradient (fall away from the house — 1:40 minimum for hard surfaces).

## Step 3 — Quality & Polish

- Weed membrane under gravel: without it weeds push through within months
- 500mm stepping stone spacing: too close looks cramped, too far requires awkward strides
- Compacted hardcore base: without it block paving sinks and becomes uneven
