# Colour Mixing in Gouache Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Gouache colour mixing: Chalky problem (too much white desaturates — use a lighter colour in same family first) → Limited palette mixing → Mix enough for the whole painting → Clean brush between colours → Swatch test (gouache dries darker than it looks wet).

## Step 3 — Quality & Polish

- Gouache dries darker: swatch test before committing
- Clean brush between colours: dirty brushes grey everything
- Mix a full batch: enough of each colour for the whole painting
