# Layering and Overpainting in Gouache Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Gouache layering: Traditional gouache can be reactivated — wet overpainting disturbs dry layers → Dry brush technique (semi-dry brush does not activate layer below) → Isolation with spray fixative → Working light over dark (opaque whites cover dark) → Dark over light (add dark accents last over dry lighter areas) → Strategy: background/darks/midtones/lights/highlights last.

## Step 3 — Quality & Polish

- Dry brush for layering: avoids activating the layer below
- Spray fixative between layers: isolates previous layers
- Lights last: gouache opaque lights go over darks — plan the order
