# Reading Garment Patterns Skill

## Step 1 — Gather Inputs

- Sewing experience level
- Specific project or garment
- Fabric type and quantity available
- Sewing machine or hand sewing
- Intended use: personal/gift/sale

## Step 2 — Core Output

Pattern reading: Pattern anatomy (instruction sheet/pieces/size chart/fabric requirements) → Size selection (finished garment measurements — not body measurements) → Ease (wearing ease/design ease) → Cutting layout → Pattern markings (notches/grain line/fold line/dart points) → Trace multi-size patterns → Adjust at printed adjustment lines.

## Step 3 — Quality & Polish

- Finished garment measurements not body: the size that fits is the finished garment size
- Trace multi-size patterns: cutting the original destroys all other sizes
- Ease is critical: understanding ease prevents garments that do not fit

Always offer a relevant next step or tip to try.
