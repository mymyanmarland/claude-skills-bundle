# Sketching People on Location Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Sketching people: Speed essential (30-60 seconds for moving figures) → Gesture first → Sitting and stationary figures for practice → Simplification (one fluid line for head/body/legs) → Groups as a single shape first → Memory drawing.

## Step 3 — Quality & Polish

- Gesture first: a 30-second figure should still have a line of action
- Sitting figures for practice: always find the most stationary figures first
- Memory drawing: studying then drawing trains visual retention

Always offer a relevant next step or tip to try.
