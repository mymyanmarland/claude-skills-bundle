# Interfacing Guide for Home Sewing Skill

## Step 1 — Gather Inputs

- Sewing experience level
- Specific project or garment
- Fabric type and quantity available
- Sewing machine or hand sewing
- Intended use: personal/gift/sale

## Step 2 — Core Output

Interfacing guide: Adds body and stability → Types (fusible: iron-on / sew-in / woven / non-woven / knit) → Weight (lightweight: collars / medium: bags / heavy: bag bases) → Fusible application (press cloth / press not slide / 15-20 seconds / allow to cool) → Test on scrap first → Sew-in when fusible inappropriate.

## Step 3 — Quality & Polish

- Press cloth for fusible: iron should never touch the glue side
- Allow to cool before handling: moving while warm causes lifting
- Test on scrap first: fusible can mark or distort some fabrics

Always offer a relevant next step or tip to try.
