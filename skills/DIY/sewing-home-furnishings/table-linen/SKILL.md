# Sewing Table Linen Skill

## Step 1 — Gather Inputs

- Sewing experience level
- Specific project or garment
- Fabric type and quantity available
- Sewing machine or hand sewing
- Intended use: personal/gift/sale

## Step 2 — Core Output

Table linen: Pre-wash fabric (linen shrinks significantly) → Sizing (table + overhang: formal 38cm / casual 20cm) → Double-turned hem → Mitre corner technique (fold diagonally / fold each side / slip stitch) → Napkins (40-50cm square / mitre corners) → Press very flat.

## Step 3 — Quality & Polish

- Mitre corners: the mark of quality table linen
- Prewash linen: shrinks significantly — wash before cutting
- Press very flat: table linen judged as much by the press as the sewing

Always offer a relevant next step or tip to try.
