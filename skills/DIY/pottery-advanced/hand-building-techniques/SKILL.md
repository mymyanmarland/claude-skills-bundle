# Advanced Hand Building Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Advanced hand building: Coil building (rolls of clay stacked / blend the joins fully / build slowly / dry to leather-hard between sessions for tall forms) → Slab construction (rolled or extruded slabs / join at leather-hard / score and slip all joins) → Score and slip (essential for all clay joins — scratch the surface / apply slip / press firmly) → Pinch pots (begin from a ball / consistent wall thickness / elegant simplicity) → Combining methods (coil build the form / slab the base / add handles) → Texture tools (stamps / found objects / rollers).

## Step 3 — Quality & Polish

- Score and slip all joins: unscored joins crack in the kiln — no exceptions
- Build slowly for tall coil forms: building too fast collapses the walls
- Leather-hard for joining slabs: wet slabs distort / bone dry cannot be joined

Always offer a relevant next step or tip to try.
