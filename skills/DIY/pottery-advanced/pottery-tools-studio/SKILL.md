# Pottery Tools and Studio Setup Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Pottery studio setup: Essential tools (wire clay cutter / wooden ribs / metal ribs / loop tools / sponge / banding wheel / pottery bat for the wheel) → Pottery wheel options (electric: most used for throwing / kick wheel: traditional / tabletop: affordable entry) → Kiln considerations (electric kiln for most home studios / ventilation essential / size vs cost vs firing temperature) → Kiln access alternatives (community studio / hire firing / university open studios) → Clay storage (covered to prevent drying) → Reclaim bucket (fill with water / add clay trimmings / let dry then wedge).

## Step 3 — Quality & Polish

- Community studio access: the most affordable way to use a wheel and kiln before buying
- Kiln ventilation is essential: firing produces fumes that must be vented outside
- Reclaim bucket from day one: clay is too expensive to waste — recycle trimmings

Always offer a relevant next step or tip to try.
