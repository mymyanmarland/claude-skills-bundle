# Iris Folding Technique Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Iris folding: Materials (patterned paper strips / folded 1/3 / sticky tape / aperture card / pattern template) → Template (printed pattern with numbered sections / tape to a light box or window) → Working from the outside in (place folded strips along each numbered section / tape on the reverse of the card) → Rotation (each successive strip rotates the pattern — creates the iris aperture effect) → Paper selection (coordinated papers / 3-5 different patterns that work together) → Aperture shapes (square / oval / heart / shaped apertures) → Backing (a plain paper backing piece covers the back of the work).

## Step 3 — Quality & Polish

- Work outside-in: the aperture shrinks inward with each round
- Coordinated paper selection: random patterns fight each other — choose a palette
- Secure with tape not glue: tape allows repositioning if a strip is misaligned
