# Pencil Control and Mark Making Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Pencil control: Grip types (writing grip for detail / overhand for expressive / underhand for tonal) → Pencil grades (H: hard light / HB: medium / B: soft dark / 6B for deep darks) → Pressure variation → Line types (contour/hatching/cross-hatching/stippling/scribble tone) → Smooth vs textured paper → Daily practice strokes (parallel lines/circles/curves — fill a page daily).

## Step 3 — Quality & Polish

- Overhand grip for tone: arm not wrist creates smooth even tonal areas
- B grades for drawing: HB and H are too hard for expressive drawing
- Fill a page daily: pencil control is physical muscle memory

Always offer a relevant next step or tip to try.
