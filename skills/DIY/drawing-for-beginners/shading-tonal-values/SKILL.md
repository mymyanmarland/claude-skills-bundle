# Shading and Tonal Values Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Shading and tones: Value scale (white through grey to black — learn 5 distinct values) → Light source identification (one consistent source) → Form shadows vs cast shadows → Reflected light (subtle light in the dark side — lost on beginners) → Blending (tortillon/finger/blending stump — use sparingly) → Build tone in layers not pressing hard.

## Step 3 — Quality & Polish

- Build tone in layers: pressing hard cannot be undone — layer up slowly
- One light source: multiple sources confuse beginners — simplify
- Reflected light in the shadow: the subtlety that makes forms look solid
