# Drawing Still Life Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Still life drawing: Setup (3-5 objects / height variation / one light source) → Thumbnail compositions first → Block-in (overall shapes before detail) → Negative shapes → Surface texture (glass/ceramic/fabric/wood — render differently) → Shadows and reflections → Start with one geometric object.

## Step 3 — Quality & Polish

- Thumbnail composition first: test before committing to a full drawing
- Negative shapes: as important as the objects themselves
- One object first: master a single sphere before a complex arrangement

Always offer a relevant next step or tip to try.
