# Fat Over Lean Rule Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Fat over lean: Each layer must be more oily than the layer beneath → Lean layers (solvent / used for underpainting) → Fatter layers (medium added / final stages) → Practical (first layer: paint + solvent / middle: paint alone / final: paint + medium) → Cracking results from breaking this rule.

## Step 3 — Quality & Polish

- Fat over lean is a structural rule: breaking it causes cracking within years
- Solvent for lean first layers: dries fast — the lean stage
- First layer always leanest: establishes the foundation
