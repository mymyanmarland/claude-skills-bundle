# Underpainting Techniques Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Underpainting: Imprimatura (thin toned wash / sets colour temperature) → Grisaille (monochrome / establishes all values before colour) → Burnt sienna underpainting (warm drawing / glows through layers) → Drying time (must dry before fat layers / acrylic underpainting is faster).

## Step 3 — Quality & Polish

- Imprimatura sets the key: warm or cool toned ground changes everything
- Grisaille establishes values: solve value before colour
- Acrylic underpainting: dries in hours — practical lean base for oils

Always offer a relevant next step or tip to try.
