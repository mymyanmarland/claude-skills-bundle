# Mixed Media Scrapbooking Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Mixed media scrapbooking: Painted backgrounds (gesso / acrylic paint / distress inks — create the background before adding photos) → Texture (stencils and texture paste / moulding paste for raised areas) → Collage elements (torn book pages / vintage ephemera / tissue paper) → Dry embossing on pages (embossing folder through the die cutter) → Layered transparency (acetate / vellum overlays) → Stamping directly on the background → Balance (mixed media is rich — let photos remain the clear focal point).

## Step 3 — Quality & Polish

- Background before photos: create the atmosphere first then add photos and embellishments
- Vellum overlays soften: useful for vintage or dreamy styles
- Photos remain the focal point: mixed media supports the photos — it does not replace them

Always offer a relevant next step or tip to try.
