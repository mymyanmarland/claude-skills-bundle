# Traveller's Notebook Scrapbooking Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Traveller's notebook: System overview (leather cover / elastic inserts / interchangeable notebooks — Midori / Fauxdori / many brands) → Insert types (dot grid / blank / watercolour / kraft / accordion) → Compact scrapbooking (cut photos to smaller sizes / washi tape / stamps / minimal embellishments) → On-the-go journalling (lightweight system for travel recording) → Decoration techniques (washi tape / stamps / stickers / collage elements) → Creating inserts (hand-sewn signature booklets / accordion folds).

## Step 3 — Quality & Polish

- Smaller photos for compact format: 4x6 photos are too large for most traveller notebooks
- Washi tape is the essential supply: low weight, high versatility
- Create your own inserts: saves money and allows custom paper choices

Always offer a relevant next step or tip to try.
