# Scrapbooking Tools and Organisation Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Scrapbooking tools and organisation: Essential tools (cutting mat / craft knife or paper trimmer / bone folder / adhesive: tape runner / foam squares / liquid glue / scissors: straight and decorative) → Paper trimmer selection (rotary blade for long cuts / guillotine for precision) → Organisation systems (paper by colour / embellishments by type in clear drawers / stamps sorted) → Storage for albums (upright on shelves / protect from dust) → Digital organisation (folder system for digital photos before scrapping) → Budget approach (kits provide coordinated supplies — more economical and cohesive).

## Step 3 — Quality & Polish

- Paper trimmer over scissors for straight cuts: consistent straight cuts are difficult with scissors
- Foam squares for dimension: the simplest way to add depth to a layout
- Kits for beginners: pre-coordinated kits remove the colour-matching challenge

Always offer a relevant next step or tip to try.
