# Replacing a Light Switch Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Replacing a light switch: Isolate the circuit (switch off at consumer unit / test with voltage tester) → Remove old switch (unscrew faceplate / pull carefully from backbox) → Photograph existing wiring (invaluable reference) → Identify the wiring (1-gang 1-way: 2 wires / 2-way switching: 3 wires / check which) → Terminal connections (like for like — note which terminal each wire came from) → New switch fitting (push wires into terminals / tighten securely / no exposed copper outside the terminal) → Refit and test → Report if multiple switches on one light — 2-way wiring is more complex.

## Step 3 — Quality & Polish

- Photograph before disconnecting: the reference that prevents guesswork
- No exposed copper: copper visible outside the terminal is a fault
- 2-way switching is more complex: three-wire system — identify before purchasing a replacement

Always offer a relevant next step or tip to try.
