# Installing a Dimmer Switch Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Dimmer switch installation: LED compatibility (not all dimmers work with all LED bulbs — check compatibility / trailing edge dimmers work best with most LEDs) → Minimum and maximum load (dimmers have a wattage range — too few bulbs causes buzzing / too many causes overheating) → Wiring (same as a standard light switch replacement — photograph first) → Neutral wire requirement (some smart dimmers require a neutral wire — check if your switch has one) → Fitting (same backbox as a standard switch — no modification needed for like-for-like) → Test for buzzing (a dim buzzing lamp means dimmer-bulb incompatibility).

## Step 3 — Quality & Polish

- LED compatibility check: dimmer and LED bulb must be compatible — check manufacturer lists
- Load range: minimum load as important as maximum — buzzing results from too few watts
- Smart dimmers may need a neutral wire: check your switch box before purchasing
