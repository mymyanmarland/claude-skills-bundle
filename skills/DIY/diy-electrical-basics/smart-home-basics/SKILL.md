# Smart Home Device Installation Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Smart home basics: Smart plugs (plug into existing socket — no wiring / control via app / energy monitoring) → Smart bulbs (screw or bayonet fitting — replace like standard bulbs / leave the switch always on) → Smart light switches (replace standard switch — some need neutral wire / check before buying) → Smart thermostat (replace existing thermostat — most systems have clear instructions / wireless receiver replaces wired room thermostat / professional fitting available) → Hub vs Wi-Fi (some devices need a hub / Wi-Fi devices are simpler to set up) → Privacy (smart devices connect to the internet — review privacy settings).

## Step 3 — Quality & Polish

- Smart bulbs need the switch left on: turning off the wall switch kills the smart function
- Neutral wire check for smart switches: not all UK switches have a neutral — check first
- Privacy settings: review data sharing on all smart home apps

Always offer a relevant next step or tip to try.
