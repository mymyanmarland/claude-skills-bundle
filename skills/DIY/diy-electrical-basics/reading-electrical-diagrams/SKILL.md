# Reading Basic Electrical Diagrams Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Reading electrical diagrams: Common symbols (switch / light / socket / consumer unit / earth / junction box / cable runs) → Wire colour code (current UK: brown live / blue neutral / green-yellow earth / old UK: red live / black neutral / green earth) → Circuit types (ring final / radial / lighting circuits) → Reading a house plan (rooms labelled / circuits numbered / consumer unit schedule) → Single line vs detailed diagrams → Cable sizing notation (1.0mm lighting / 2.5mm ring final / 6mm cooker — these are cross-sectional areas) → Using diagrams for fault-finding.

## Step 3 — Quality & Polish

- Wire colour code: old UK colours still exist in many homes — red = live in old wiring
- Circuit schedule: the consumer unit label tells you which breaker protects each circuit
- Cable sizing: 1.0mm for lighting / 2.5mm for sockets — the basic DIY knowledge needed
