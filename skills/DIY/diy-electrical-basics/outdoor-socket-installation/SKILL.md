# Outdoor Socket Installation Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Outdoor socket: This task requires a qualified electrician for the connection to the mains — this guide covers planning and specification → Weatherproof ratings (IP44 minimum for covered outdoor use / IP65 for exposed outdoor) → RCD protection (outdoor sockets must be on an RCD-protected circuit — this is a safety-critical requirement) → Cable route (armoured SWA cable for outdoor runs / or twin-and-earth through conduit if protected route) → Socket positioning (accessible / away from water sources / at convenient height) → Specify to your electrician: IP rating / fused spur or dedicated circuit / location.

## Step 3 — Quality & Polish

- RCD protection is mandatory for outdoor sockets: this is a safety and legal requirement
- Armoured cable outdoors: standard cable is not suitable for external runs
- Hire an electrician for the connection: this is not a DIY final connection task
