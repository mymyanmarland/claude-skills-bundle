# Advanced Pattern Reading Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Pattern reading: Written vs charted instructions → Asterisks and brackets (repeat markers) → Stitch count check at end of every row → Adjusting sizing (stitch multiple awareness) → Length adjustments (rows before shaping begins) → Yarn substitution (match weight and gauge / consider fibre behaviour) → Check Ravelry errata.

## Step 3 — Quality & Polish

- Stitch count check every row: catching an error now beats finding it 20 rows later
- Ravelry errata: many published patterns have corrections — always check
- Yarn substitution: same weight does not mean same gauge

Always offer a relevant next step or tip to try.
