# Stranded Colourwork Knitting Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Stranded colourwork: Float management (carry unused colour / max 5 stitches before catching) → Tension (floats too tight pull fabric in) → Spreading stitches on right needle before picking up float → Yarn dominance (lower yarn appears more prominent — consistent position throughout) → Reading colourwork charts → Blocking essential.

## Step 3 — Quality & Polish

- Spread stitches before floating: the single most important tension technique
- Yarn dominance: consistent position for each colour throughout
- Catch floats over 5 stitches: long floats catch fingers and distort
