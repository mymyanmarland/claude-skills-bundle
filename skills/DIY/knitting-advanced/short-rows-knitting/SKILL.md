# Short Row Techniques Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Short rows: Create extra rows in part of the work → Wrap and turn (W+T) → German short rows (turn / slip purlwise / pull yarn over needle / cleaner result) → Japanese short rows → Choosing a method (German cleanest for beginners) → Uses (sock heels/bust darts/shoulder shaping/curved hems).

## Step 3 — Quality & Polish

- German short rows are cleanest: the double stitch picks up more reliably
- Pick up the wrap or double stitch on return: missing it leaves a hole
- Short rows for bust darts: the most useful garment application

Always offer a relevant next step or tip to try.
