# Furniture Finishing Guide Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Furniture finishing: Surface preparation (sand to 180 grit / remove all dust) → Grain raising (water-based finishes raise the grain — dampen / let dry / lightly sand with 220 before applying) → Primer (for paint finishes — always prime before top coat) → Staining (apply evenly, wipe off excess, let dry before finishing coat) → Oil finishes (Osmo / Danish oil — wipe on thin coats / multiple coats build sheen) → Varnish (brush on thin coats / sand between coats with 320 grit) → Wax (final finish over paint or oil — builds patina over time).

## Step 3 — Quality & Polish

- Grain raising: skip it and the first coat raises the grain — do it deliberately before finishing
- Thin coats of varnish: thick coats run and sag — thin coats cure flatter
- Sand between varnish coats: each coat needs mechanical key for the next
