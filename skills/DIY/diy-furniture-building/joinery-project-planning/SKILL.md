# Joinery Project Planning Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Joinery project planning: Define the brief (exact dimensions / function / aesthetic) → Reference images (find inspiration photos — communicate style intent) → Detail drawings (elevation and plan views / key dimensions labelled) → Cut list (every component: material / thickness / width / length / quantity) → Timber order (cut list plus 15% for waste and selection) → Tool list (what is needed that is not owned) → Construction sequence (what gets made and assembled in what order — critical for complex projects) → Dry assembly (assemble without glue to check everything fits before final glue-up).

## Step 3 — Quality & Polish

- Detail drawings save cutting errors: sketch every component before cutting
- Dry assembly is mandatory for complex projects: discovering a fitting error during glue-up is a disaster
- Tool list before starting: borrow or hire before buying for one-off use

Always offer a relevant next step or tip to try.

📌 Safety Disclaimer: Always follow safety guidelines when undertaking DIY projects. Wear appropriate protective equipment at all times. For electrical, structural, or gas-related work, consult a licensed professional. When in doubt, seek professional advice before proceeding.
