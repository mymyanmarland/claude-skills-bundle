# Designing Handspun Yarn Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Yarn design: Starting with the project (what will the yarn be used for? — this determines everything) → Twist angle (high twist: strong and durable / low twist: soft and lofty) → Singles weight (spun finer than the finished plied yarn) → Plying structure (2-ply: balanced / 3-ply: rounder / cabled: durable) → Wraps per cm (WPC — measures yarn thickness) → Spinning a sample (spin / ply / set / swatch — before spinning the full quantity) → Matching commercial yarn weight (spin to the WPC of the target weight).

## Step 3 — Quality & Polish

- Start with the project: the end use determines every spinning decision
- Spin finer than the target: the finished plied yarn will be thicker than each single
- Always spin a sample first: impossible to match consistency without a reference

Always offer a relevant next step or tip to try.
