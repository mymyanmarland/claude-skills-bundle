# Plying Techniques Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Plying techniques: Why ply (balances twist / creates stronger yarn / more even than singles) → 2-ply (two bobbins plied together in the opposite direction from spinning) → 3-ply (three bobbins / rounder and fuller yarn) → Navajo ply / chain ply (one bobbin / three-ply result / preserves colour sequence) → Andean plying (wrap singles around the hand / ply from both ends) → Balanced ply test (let the yarn double back on itself — a balanced ply hangs without twisting) → Setting the twist (wet / dry weighted).

## Step 3 — Quality & Polish

- Ply in the opposite direction from spinning: plying in the same direction adds more twist
- Balanced ply test: the yarn tells you if it is balanced — trust the test
- Navajo ply preserves colour: the sequence from a variegated top stays together
