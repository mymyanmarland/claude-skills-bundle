# Spinning Yarn for Knitting Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Spinning for knitting: Yarn weight matching (wrap yarn around a ruler — compare WPC to commercial standards) → Twist for knitting (medium twist — too soft falls apart / too hard is scratchy) → 2-ply or 3-ply for knitting (2-ply: drape / 3-ply: stitch definition) → Consistency (knitting requires more consistent yarn than weaving) → Sample swatching (spin / ply / set / wash / knit a swatch before spinning the full project) → Quantity estimation (spin more than you think you need — matching a handspun batch is nearly impossible).

## Step 3 — Quality & Polish

- Spin more than you need: matching a handspun batch is nearly impossible
- Sample swatch always: set / washed yarn behaves completely differently from fresh-spun
- Consistency matters for knitting: weaving is more forgiving of lumpy yarn

Always offer a relevant next step or tip to try.
