# Drop Spindle Spinning Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Drop spindle spinning: Spindle types (top whorl: more stable / bottom whorl: faster spin) → Fibre preparation (combed top or carded rolag — different preparations produce different yarns) → Park and draft method (spin the spindle / park it between knees / draft the fibre / repeat) → Continuous spinning (spin the spindle / draft simultaneously — harder but faster) → Singles yarn (one ply spun from the fibre) → Plying (two singles twisted together in the opposite direction) → Setting the twist (wet the yarn / hang to dry — sets the twist permanently).

## Step 3 — Quality & Polish

- Park and draft for beginners: two separate actions before combining them
- Set the twist after plying: unset yarn untwists in the wash
- Fibre preparation matters: combed top spins a smooth yarn / carded rolag spins a lofty one
