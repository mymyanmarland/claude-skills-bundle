# Advanced Quilt Design Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Advanced quilt design: Design software (EQ8 / Quiltster / or graph paper) → Block repeat (how a single block looks when repeated — rotation and reflection create variety) → Setting options (straight / on-point / medallion / modern asymmetric) → Colour value (light/medium/dark placement determines the visual design — not just hue) → Negative space (plain areas that allow the eye to rest and the pattern to read) → Scale variation (different-sized blocks in one quilt adds interest) → Original block design (start from a grid — 4-patch / 9-patch / 16-patch).

## Step 3 — Quality & Polish

- Colour value over hue: a quilt where all fabrics have the same value looks flat regardless of colour
- Negative space: plain areas make a busy pattern more legible
- Original blocks from a grid: all traditional blocks can be analysed as grid divisions

Always offer a relevant next step or tip to try.
