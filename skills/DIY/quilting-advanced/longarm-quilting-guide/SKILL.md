# Longarm Quilting Guide Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Longarm quilting: What a longarm is (a large frame-mounted quilting machine / the quilt top and backing are loaded separately / the head moves across the quilt) → Hiring a longarm quilter (find via guilds / Instagram / local shops) → Preparing the quilt for a longarm (square top / pressed flat / no stitching in the seam allowances / backing 10cm larger all round) → Design options (pantograph: a repeating pattern / custom: freehand over the quilt design) → Cost (charged per square inch / custom work costs more) → Home longarm (machines available for domestic use — a significant investment).

## Step 3 — Quality & Polish

- Prepare the top impeccably: longarmers cannot fix puckered seams or unpressed blocks
- Backing 10cm larger all round: same rule as for domestic machine quilting
- Pantograph vs custom: pantograph is more affordable / custom enhances the quilt design

Always offer a relevant next step or tip to try.
