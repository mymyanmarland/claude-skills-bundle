# Basic Reupholstering Skill

## Step 1 — Gather Inputs

- Skill level: beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Basic reupholstering: Tools (staple gun / fabric scissors / tack lifter / pliers) → Remove old fabric (tack lifter under staples / note how it was assembled — take photos) → Assess and replace foam (if compressed or crumbling — new foam cut to shape) → Fabric selection (upholstery fabric for durability / plain first for beginners — patterns must be matched) → Cutting fabric (50mm larger than the pad on all sides) → Stapling (start at centre of each side / pull taut and staple every 50mm / corners folded neatly) → Underneath finish (cambric or dust cover).

## Step 3 — Quality & Polish

- Photos before disassembly: invaluable reference for reassembly
- Start at centre of each side: corners done last — working outward prevents puckering
- Pull taut but not distorted: over-stretching distorts patterns and weakens fabric

Always offer a relevant next step or tip to try.
