# Bookbinding Tools and Materials Guide Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Bookbinding tools: Essential tools (bone folder / microspatula / awl / bookbinding needles curved and straight / pressing boards / book press or heavy weights / cutting mat / metal ruler) → Adhesives (PVA — flexible and permanent / methylcellulose — reversible / paste — traditional) → Thread (waxed linen: most durable / waxed cotton: more flexible / silk for fine work) → Paper (text weight for pages / cover weight for covers / Japanese tissue for repair) → Board (bookboard / greyboard / strawboard — different weights for different applications) → Sources (specialist bookbinding suppliers / some materials from art shops).

## Step 3 — Quality & Polish

- Waxed linen thread: the standard for durability in bookbinding
- Bookboard quality: cheap card warps — proper bookboard stays flat
- Bone folder for every fold: crisp folds are the mark of quality bookbinding

Always offer a relevant next step or tip to try.
