# Wire Armature Sculpture Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Wire armature: Wire selection (aluminium armature wire: flexible and stable / jewellery wire for fine details) → Figure armature (spine / ribcage / pelvis / limbs — build the skeleton before adding clay) → Wrapping (wrap wire with tin foil to build bulk — reduces clay required) → Fixing to a base (drilling into wood / epoxy the wire in) → Proportions (7-8 heads tall for realistic figure / shorter for stylised) → Paper clay over armature (dries hard / lightweight / takes detail) → Polymer clay over armature (bake in stages / supporting the armature during baking).

## Step 3 — Quality & Polish

- Tin foil bulk before clay: reduces clay use and weight — essential for large figures
- Fix to a base before adding clay: moving a clay-covered armature breaks it
- 7-8 heads tall for realism: proportion check before adding any clay

Always offer a relevant next step or tip to try.
