# Warp Calculation and Planning Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Warp calculations: Sett (warps per cm — determines whether the weave is warp-faced / balanced / weft-faced) → Width calculation (weaving width + draw-in % = warp width) → Warp length (project length + loom waste + fringe + sampling) → Total ends (warp width in cm × sett = number of warp ends) → Yarn quantity (total ends × warp length = total warp length in cm) → Online warp calculators (useful for checking manual calculations) → Sample before a long warp.

## Step 3 — Quality & Polish

- Always add loom waste: the part of the warp that cannot be woven — typically 60-90cm
- Sett determines cloth structure: too open = weft-faced / too dense = warp-faced
- Sample at the start of every warp: check sett and colour before weaving the project
