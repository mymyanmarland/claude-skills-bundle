# Pattern Weaving and Colour Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Pattern weaving and colour: Warp stripes (colour changes in the warp create vertical stripes) → Weft stripes (colour changes in the weft create horizontal stripes) → Checks and plaids (warp and weft stripes combined) → Block weave patterns (groups of warps threaded differently / 4-shaft loom required) → Colour interaction (warp and weft colours mix optically in balanced weaves) → Colour gamp (a sample that shows all combinations of a colour palette woven together) → Threading patterns (twill / broken twill / houndstooth).

## Step 3 — Quality & Polish

- Colour gamp: the most educational weaving sample — shows all warp-weft combinations
- Warp and weft mix optically: test all your colour combinations in a gamp before a large project
- Threading patterns on 4-shaft: twill and houndstooth require a 4-shaft loom

Always offer a relevant next step or tip to try.
