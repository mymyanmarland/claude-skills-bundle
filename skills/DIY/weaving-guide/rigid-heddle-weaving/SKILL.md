# Rigid Heddle Loom Weaving Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Rigid heddle weaving: Warping (direct warping method — wrap around the back beam via the heddle) → Rigid heddle function (holes hold fixed warps / slots hold floating warps / lifting and lowering creates the shed) → Plain weave on rigid heddle (lift the heddle / pass the shuttle / lower / pass back) → Width management (avoid draw-in: angle the weft before beating) → Sampling (weave a sample to check sett before a full project) → Finishing (wet finishing changes the hand of the cloth — always wet finish).

## Step 3 — Quality & Polish

- Angle the weft before beating: straight weft always draws in the edges
- Sett sampling: the number of warps per cm determines the fabric structure
- Wet finish all woven cloth: transforms the hand and sets the weave
