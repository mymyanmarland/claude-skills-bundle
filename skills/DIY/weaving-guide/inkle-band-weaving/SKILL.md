# Inkle Band Weaving Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Inkle band weaving: Loom setup (warp threaded alternately through heddles and around pegs) → Plain weave band (lift the heddle / pass the weft / lower / pass back — two rows form one pick) → Pattern bands (colour-patterned warps create geometric designs in the woven band) → Selvedge management (consistent edges — weft tension is critical) → Finishing (fringe / hemmed) → Uses (belts / bag straps / bookmarks / trims / guitar straps).

## Step 3 — Quality & Polish

- Weft tension determines selvedge quality: too tight pulls in / too loose makes loops
- Colour pattern comes from the warp: inkle patterns are warp-dominant
- Multiple projects per warp: inkle loom holds a long warp — use all of it
