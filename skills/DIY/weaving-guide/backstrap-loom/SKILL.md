# Backstrap Loom Weaving Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Backstrap loom: Components (back strap / backbeam / heddle rod / shed rod / shuttle / temple) → Body tension (leaning back tightens the warp / leaning forward loosens) → Plain weave (raise the heddle rod / pass weft / lower and raise the shed rod / pass back) → Temple (stretcher device that maintains weaving width) → Traditional origins (South American / Central American / SE Asian traditions) → Starting small (simple bands before attempting full-width fabric).

## Step 3 — Quality & Polish

- Body tension controls the warp: the weaver is part of the loom
- Temple prevents draw-in: essential for maintaining consistent width
- Start with bands: full-width backstrap weaving requires significant practice

Always offer a relevant next step or tip to try.
