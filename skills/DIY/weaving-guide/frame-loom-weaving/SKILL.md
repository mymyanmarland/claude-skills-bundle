# Frame Loom Weaving Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal / gift / sale

## Step 2 — Core Output

Frame loom weaving: Setting up the warp (wrap yarn around the frame / evenly spaced / consistent tension) → Plain weave (over-under alternating / each row reverses the sequence) → Shed stick (flat stick inserted through alternate warps / speeds up weaving) → Weft packing (push each weft row down firmly for a solid weave) → Colour changes (new yarn tied to the side or woven in ends) → Texture techniques (rya knots for fringe / soumak for texture) → Finishing (removing from the loom / hemstitch to secure the weave).

## Step 3 — Quality & Polish

- Consistent warp tension: uneven tension creates a wavy distorted weave
- Pack the weft firmly: loose unpacked rows create open gaps
- Hemstitch before removing: secures the weave and prevents unravelling
