# Character Design Basics Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Character design: Silhouette test (reads clearly in black silhouette) → Personality in proportions (exaggeration communicates character type) → Colour as character language → Consistency (all elements serve the personality) → Turnaround (front/side/back/three-quarter) → Expression sheet (6-8 key expressions) → Reference research.

## Step 3 — Quality & Polish

- Silhouette test: if it does not read as silhouette it needs redesigning
- Exaggeration communicates: push further than feels comfortable
- Expression sheet: character lives in the expressions — design them early

Always offer a relevant next step or tip to try.
