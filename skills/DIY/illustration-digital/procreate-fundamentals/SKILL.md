# Procreate Fundamentals Skill

## Step 1 — Gather Inputs

- Art experience level
- Specific technique or project
- Materials and tools available
- Intended use: personal/exhibition/sale
- Any particular style or reference

## Step 2 — Core Output

Procreate fundamentals: Interface (canvas/layers/brushes/colour panels) → Layers (non-destructive / clipping masks) → Brushes (default library / settings: size/opacity/flow) → Gestures (two-finger tap undo / pinch to zoom) → Colour (wheel/palettes/eyedropper/colour drop) → Transform tools → Export (PNG/PSD/PDF/animated GIF).

## Step 3 — Quality & Polish

- Layers from the start: everything on its own layer — the foundation of non-destructive work
- Gesture shortcuts: undo with two-finger tap — the most-used Procreate gesture
- Brush opacity vs flow: opacity affects final value / flow affects how quickly it builds

Always offer a relevant next step or tip to try.
