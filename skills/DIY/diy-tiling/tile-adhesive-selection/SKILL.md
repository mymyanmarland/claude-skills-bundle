# Tile Adhesive and Grout Selection Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Adhesive and grout selection: Tile adhesive types (standard — light wall tiles on stable surfaces / flexible — large tiles, floor tiles, wet rooms / rapid set — minimises wait time / epoxy — chemical resistance, heavy duty) → Grout types (unsanded — joints up to 3mm / sanded — joints 3mm+ / epoxy grout — waterproof, stain resistant, hard to work with) → Grout colour selection (match the tile for a clean look / contrast for a design statement / light grout stains more easily on floors) → Coverage (check coverage on the bag — underestimating causes mid-job trips to the shop).

## Step 3 — Quality & Polish

- Flexible adhesive for floors and large tiles: standard adhesive cracks under movement
- Epoxy grout: most durable but least forgiving to apply — use on surfaces that justify the effort
- Calculate coverage before starting: running out mid-job causes inconsistent results
