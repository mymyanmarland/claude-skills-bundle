# Floor Tiling Basics Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Floor tiling: Subfloor check (must be solid and level — flexible floors cause tiles to crack / use flexible tile adhesive if any flex) → Layout planning (find the centre of the room, set out so cut tiles are equal at opposite walls) → Adhesive (floor tile adhesive — thicker consistency than wall tile adhesive) → Large trowel with deep notches → Check level constantly → Movement joints (expansion gap at perimeter and every 4-5m — do not tile wall-to-wall solid) → Grouting (only when adhesive is fully cured — usually 24 hours).

## Step 3 — Quality & Polish

- Subfloor flex causes tiles to crack: solid subfloor is essential
- Movement joints at perimeter: tiles expand and contract — space needed
- Adhesive fully cured before grouting: grout in wet adhesive causes failures
