# Painting Ceilings Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Ceiling painting: Preparation (clean and prime if new plaster / repair cracks with flexible filler) → Order (ceiling before walls — drips on unpainted walls are easier to fix) → Cut in first (around the perimeter with an angled brush) → Roller technique (extension handle / W pattern / work toward the window / wet edge maintained) → Avoiding drips (not overloading the roller / slow controlled passes) → Number of coats (new plaster usually needs mist coat plus two topcoats) → Ceiling paint (formulated for ceilings — thicker and slow-dripping).

## Step 3 — Quality & Polish

- Ceiling before walls: drips on unpainted walls do not matter
- Mist coat on new plaster: neat emulsion soaks into new plaster — always mist coat first
- Extension handle: neck strain from looking up is real — use one
