# Roller Technique for Walls Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Roller technique: Roller selection (medium pile for smooth walls / thicker pile for textured surfaces) → Loading (roll in the tray, back and forth until evenly loaded — not dripping) → Application (W or M pattern to distribute paint, then blend with vertical strokes) → Wet edge (work quickly enough that each section meets the previous while still wet — prevents lap marks) → Ceiling work (extend handle, use the same W pattern — work toward the light source) → Second coat (180 degrees from the first — reveals missed areas).

## Step 3 — Quality & Polish

- Wet edge: lap marks form when painting onto dry — keep moving
- W pattern first: distributes paint evenly before blending
- Work toward the light: shows missed spots on ceilings
