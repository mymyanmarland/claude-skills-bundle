# Painting Woodwork and Trim Skill

## Step 1 — Gather Inputs

- Skill level: complete beginner / some experience / confident DIYer
- Specific task or project
- Materials and tools available
- Budget
- Any safety or structural concerns

## Step 2 — Core Output

Painting woodwork: Preparation (light sand with 120 grit, clean, fill nail holes) → Prime bare wood (knotting solution on knots first — prevents resin bleed) → Undercoat (builds thickness, provides base for gloss / satinwood) → Top coat application (brush along the grain, work in sections, lay off with light strokes the length of the piece) → Common faults (runs from overloading / brush marks from pressing too hard) → New wood (prime / undercoat / two top coats minimum) → Repainting existing (light sand / clean / one or two top coats if well-adhered).

## Step 3 — Quality & Polish

- Knotting solution on knots: resin bleeds through paint for years without it
- Work along the grain: cross-grain strokes leave visible marks
- Light laying-off strokes: removes brush marks at the end of each section
