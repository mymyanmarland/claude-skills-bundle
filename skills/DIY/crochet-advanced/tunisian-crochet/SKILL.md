# Tunisian Crochet Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Tunisian crochet: Stitches picked up on forward pass / worked off on return → Tunisian hook required (longer with stopper) → Tunisian simple stitch → Common stitches (simple/full/smock/entrelac) → Bias prevention (Tunisian full stitch biases less) → Colourwork easy in Tunisian.

## Step 3 — Quality & Polish

- Tunisian full stitch reduces bias: simple stitch biases significantly
- Longer hook required: regular hooks too short for Tunisian
- Return pass as important as forward: even tension on both affects the fabric
