# Designing Crochet Patterns Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Crochet design: Gauge as foundation → Wash and block swatch before measuring → Calculation (cm × stitches per cm = chain count) → Sample crocheting (note every decision) → Pattern writing (abbreviations/stitch counts in parentheses/abbreviation key) → Test crocheter → Publish on Ravelry.

## Step 3 — Quality & Polish

- Wash and block the swatch: unwashed gauge is not finished gauge
- Stitch count after each row: the most useful error-catching tool
- Test crocheter: patterns need someone else to test

Always offer a relevant next step or tip to try.
