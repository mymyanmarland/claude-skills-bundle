# Crochet Motifs and Joining Skill

## Step 1 — Gather Inputs

- Craft experience level
- Specific project or technique
- Materials and tools available
- Budget
- Intended use: personal/gift/sale

## Step 2 — Core Output

Crochet motifs: Circles/hexagons/squares/flowers → Join as you go → Fill motifs for irregular shapes → Colour design before crocheting → Block all motifs to the same size before joining.

## Step 3 — Quality & Polish

- Block motifs before joining: size differences make joining extremely difficult
- Fill motifs for hexagons: triangular gaps are inevitable — plan for them
- Colour arrangement before crocheting: random placement rarely achieves the intended effect
