# Newsletter Writer Skill

Write newsletters people actually open, read, and click.

## Step 1 — Gather Inputs
Ask if not provided:
- **Newsletter name/brand** (if any)
- **Topic or content for this issue**
- **Audience**: Who subscribes? What do they care about?
- **Frequency & tone**: Weekly / Monthly — Professional / Casual / Personal
- **Goal**: Inform / Entertain / Drive traffic / Sell / Build community
- **Length**: Short (300 words) / Medium (500-700) / Long (1000+)
- **Any links or CTAs** to include

## Step 2 — Subject Line & Preview Text

The subject line determines whether it gets opened. Write 5 options:
```
## Subject Line Options
1. [Curiosity gap: "The mistake 90% of [audience] makes with [topic]"]
2. [Direct value: "3 ways to [benefit] this week"]
3. [Personal/story: "I almost [relatable failure] — here's what saved me"]
4. [News hook: "What [recent event] means for [audience]"]
5. [Question: "Are you still doing [outdated thing]?"]

Best pick: Option [X] — [reason]

Preview text (90 chars): [Expands on subject line without repeating it]
```

## Step 3 — Newsletter Structure

```
## [NEWSLETTER NAME] — [Issue #/Date]

**Subject**: [Chosen subject line]
**Preview**: [Preview text]

---

Hey [First name / friends / community name],

[OPENING — 2-3 sentences. Personal, warm, current. What's on your mind this week?
Reference something timely, seasonal, or relatable.]

---

## [MAIN STORY / BIG IDEA HEADLINE]

[The meaty content — the one thing this issue is really about.
Structure: Problem → Insight → Application. 200-400 words.]

[Include: one concrete example, one surprising detail, one actionable takeaway]

---

## Quick [Hits / Reads / Tips] 🔗

- **[Title]**: [1-sentence description] → [Link]
- **[Title]**: [Description] → [Link]
- **[Title]**: [Description] → [Link]

---

## [OPTIONAL SECTION: Ask / Poll / Recommendation / Behind the scenes]

[Short section — 50-100 words. Variety keeps readers engaged issue to issue.]

---

That's it for this week. If this was useful, forward it to one person who'd appreciate it.

[Sign-off name]
[P.S. — optional: one more thing, usually a soft CTA or personal note]

---
*[Unsubscribe link] · [View in browser]*
```

## Step 4 — Newsletter Quality Check
- [ ] Subject line under 50 characters (mobile preview)
- [ ] Opening line is personal, not corporate
- [ ] One main idea — not 6 topics crammed in
- [ ] At least one concrete, actionable insight
- [ ] CTA is clear and single (not 4 different things to click)
- [ ] Sign-off sounds human

Always offer: "Want a subject line A/B test variant?" or "Want me to write next week's issue too?"
