# YouTube Script Writer Skill

Write scripts that keep viewers watching from hook to end screen.

## Step 1 — Gather Inputs
Ask if not provided:
- **Video topic**
- **Channel niche and audience**
- **Video length target**: 5 min / 10 min / 15-20 min
- **Style**: Talking head / Educational / Story-driven / List / Tutorial
- **Tone**: Casual / Authoritative / Entertaining / Inspirational
- **CTA goal**: Subscribe / Click link / Watch next video / Comment

## Step 2 — YouTube Script Structure

```
## VIDEO TITLE OPTIONS
1. [Title with number: "7 Ways to..."]
2. [Title with curiosity gap: "Why [common thing] is actually..."]
3. [Title with transformation: "How I [result] in [timeframe]"]

Thumbnail concept: [Visual description of what the thumbnail should show]

---

## SCRIPT: [Video Title]
[Target length: X minutes | ~X words at natural speaking pace: 130 words/min]

---

### [0:00-0:30] HOOK
[Do NOT start with "Hey guys welcome back." Start mid-action or mid-thought.]

"[Bold statement / shocking fact / relatable problem that makes them stop scrolling]

[Tease what they'll learn — but don't give it away yet]

[Pattern interrupt — transition into the body]"

---

### [0:30-1:00] CREDIBILITY + SETUP
"[Who you are / why you know this — brief, earned, not bragging]
[What this video covers — set expectations]
[Optional: open loop — 'And at [timestamp] I'll show you the thing that changed everything']"

---

### [1:00-X:XX] MAIN CONTENT

**Section 1: [Title]** [Timestamp]
"[Content — conversational, not lecture. Short sentences. Vary pace.]
[Concrete example or story — makes abstract ideas stick]
[Transition to next section — 'Now here's where it gets interesting...']"

**Section 2: [Title]** [Timestamp]
"[Content]
[Pattern interrupt if video is long: change camera angle cue, B-roll note, on-screen graphic]"

**Section 3: [Title]** [Timestamp]
"[Content]"

---

### [X:XX-END] CTA + OUTRO
"[Summary — one sentence per main point]

[Soft CTA: 'If this helped you, the subscribe button is right there — I post every [day]']

[Hard CTA: 'Link in description for [resource/offer]']

[Next video tease: 'Next week I'm covering [topic] — you won't want to miss it']

[Sign-off — consistent with channel personality]"

---

## PRODUCTION NOTES
- B-roll suggestions: [List 3-5 visual moments]
- On-screen text moments: [Key stats or terms to show]
- Chapter timestamps: [List for YouTube chapters]
```

## Step 3 — Retention Tactics Built In
- Open loop in intro (promise something specific, deliver it)
- Pattern interrupt every 2-3 minutes (question, stat, story shift)
- "But wait" or "Here's the thing" transitions to re-engage
- Never summarize before the end — kills watch time

Always offer: "Want me to write the video description and tags too?"
