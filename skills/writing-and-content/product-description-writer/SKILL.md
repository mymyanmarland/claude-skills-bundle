# Product Description Writer Skill

Write product descriptions that make people want to buy.

## Step 1 — Gather Inputs
Ask if not provided:
- **Product name and what it is**
- **Key features** (materials, dimensions, specs)
- **Target buyer**: Who buys this? What problem does it solve?
- **Platform**: Amazon / Etsy / Shopify / Print catalog / Instagram
- **Tone**: Premium / Playful / Functional / Luxurious / Eco-conscious
- **Word count**: Short (50-100) / Medium (150-200) / Long (300+)

## Step 2 — The Features → Benefits Translation

Before writing, map every feature to a benefit:
```
Feature → "So what?" → Benefit → Emotional payoff
"Stainless steel" → "Won't rust" → "Lasts for years" → "Never replace it again"
"Handmade" → "One of a kind" → "No one else has this" → "Feels special to give"
```

## Step 3 — Description Structure

### Short (50-100 words — Etsy, Instagram)
```
[Evocative opening line — paint a picture or name the feeling]
[Top 2-3 benefits woven into natural sentences]
[One sensory detail — how it looks, feels, smells]
[Closing line — who it's for or when to use it]
```

### Medium (150-200 words — Shopify, standard e-commerce)
```
[Headline — benefit-focused, not just product name]

[Opening paragraph — the "dream" or problem this solves. 2-3 sentences.]

[Body — 3-5 benefit bullets, each starting with a verb]
• [Benefit 1 — feature in parentheses if needed]
• [Benefit 2]
• [Benefit 3]

[Closing — who this is perfect for / occasion / gift note]

[Specs paragraph — dimensions, materials, care instructions]
```

### Long (300+ words — Amazon, detailed pages)
```
[Headline]
[Opening hook paragraph]
[Benefits section with subheadings]
[Use cases — when/where/who]
[Technical specs]
[What's included]
[Guarantee or trust signal]
```

## Step 4 — Power Words by Tone
- **Premium**: Crafted, curated, artisan, heirloom, refined, elevated
- **Playful**: Delightful, whimsical, charming, irresistible, fun
- **Eco**: Sustainable, natural, earth-friendly, consciously made
- **Functional**: Effortless, durable, reliable, built to last, hassle-free

Always offer: "Want descriptions for multiple variants of this product?"
