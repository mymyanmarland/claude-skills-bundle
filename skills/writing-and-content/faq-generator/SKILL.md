# FAQ Generator Skill

Build FAQs that answer real questions and convert skeptics into buyers.

## Step 1 — Gather Inputs
- **Subject**: What is the FAQ for? (product, service, course, website, event)
- **Audience**: Who is asking these questions?
- **Known questions**: Any questions you already get repeatedly?
- **Purpose**: Reduce support tickets / Handle sales objections / SEO / Onboarding
- **Format**: Website section / Standalone page / Email / Printed document

## Step 2 — FAQ Categories

Organize questions into logical groups:

```
## FAQ: [Product/Service/Topic Name]

---

### General Questions

**Q: [What is X / What does X do?]**
A: [Clear, jargon-free answer. 2-4 sentences. Lead with the direct answer, then elaborate.]

**Q: [Who is X for?]**
A: [X is ideal for [specific audience] who [situation/goal]. It's especially useful if [specific trigger].]

**Q: [How is X different from [common alternative]?]**
A: [Honest comparison. Acknowledge what alternatives do well, then explain your differentiator.]

---

### Getting Started / How It Works

**Q: [How do I get started?]**
A: [Simple steps: 1. [Action] 2. [Action] 3. [Outcome]]

**Q: [How long does it take to [see results / set up / complete]?]**
A: [Specific timeframe + qualifier if needed]

**Q: [Do I need [technical skill / tool / experience] to use this?]**
A: [Reassuring answer. Define the actual requirement clearly.]

---

### Pricing & Payment

**Q: [How much does it cost?]**
A: [Direct answer. Link to pricing page if complex.]

**Q: [Is there a free trial / free version?]**
A: [Yes/No + details]

**Q: [What payment methods do you accept?]**
A: [List]

**Q: [Can I get a refund?]**
A: [Refund policy stated clearly — builds trust]

---

### Common Concerns / Objections

**Q: [What if it doesn't work for me?]**
A: [Risk-reversal answer — guarantee, refund, or support offered]

**Q: [Is my [data / payment / information] safe?]**
A: [Specific security measures, not generic reassurance]

**Q: [What happens if I need help?]**
A: [Support channels + response time]

---

### Advanced / Edge Cases

**Q: [Specific scenario question]**
A: [Specific answer]

**Q: [Another common edge case]**
A: [Answer]
```

## Step 3 — FAQ SEO Tips
- Question format matches how people search ("How do I..." "What is...")
- Include keywords naturally in both Q and A
- Add FAQ schema markup to website for Google rich results
- Update quarterly — stale FAQs signal neglected sites

## Step 4 — Objection-Handling FAQs
For sales contexts, identify the top 5 reasons people don't buy and address each directly:
1. Price objection → Value/ROI framing
2. Trust objection → Social proof + guarantee
3. Fit objection → "This is for you if..." clarification
4. Urgency objection → "Why now" answer
5. Complexity objection → "It's easier than you think" answer

Always offer: "Want me to add schema markup code for these FAQs?"
