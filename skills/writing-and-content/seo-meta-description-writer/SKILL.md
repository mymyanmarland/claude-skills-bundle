# SEO Meta Description Writer Skill

Write metadata that earns the click from search results.

## Step 1 — Gather Inputs
- **Page URL or topic**
- **Primary keyword** (what should this page rank for?)
- **Page type**: Blog post / Product page / Homepage / Service page / Category page
- **Target audience**: Who is searching for this?
- **Unique value**: What makes this page better than competitors?

## Step 2 — Meta Title Formula

```
## Meta Title Options
[Hard limit: 60 characters including spaces]

Formula: [Primary Keyword] + [Value/Benefit] + [Brand Name (optional)]

1. "[Keyword] — [Benefit or differentiator] | [Brand]" (XX chars)
2. "[Number/Power word] [Keyword]: [Promise]" (XX chars)
3. "[Question format matching search intent]" (XX chars)

✅ Recommended: Option [X] — [reason]
```

**Power words for titles**: Ultimate, Complete, Proven, Free, Best, Easy, Fast, Step-by-step

## Step 3 — Meta Description Formula

```
## Meta Description Options
[Hard limit: 155-160 characters including spaces]

Formula: [Include keyword] + [What they get] + [CTA]

1. "[Keyword naturally used]. [What the page delivers in one sentence]. [CTA verb] now."
   (XXX chars) ✅/❌

2. "[Pain point or question]. [Your page answers it with specific value]. [CTA]."
   (XXX chars) ✅/❌

3. "[Compelling stat or claim]. [How your page helps]. [CTA]."
   (XXX chars) ✅/❌

✅ Recommended: Option [X]
```

**CTA words**: Discover, Learn, Get, Find out, See, Explore, Download, Start

## Step 4 — Full Package Output

```
## SEO Metadata Package: [Page Name]

**Primary keyword**: [Keyword]
**Search intent**: [Informational / Navigational / Transactional / Commercial]

Meta Title: [Final title] ([XX] chars)
Meta Description: [Final description] ([XXX] chars)
URL Slug: /[keyword-slug]
Alt text for featured image: [Descriptive alt text with keyword]

Open Graph Title: [Can differ from meta title — optimized for social shares]
Open Graph Description: [130 chars max — punchy for social]
```

## Step 5 — Bulk Mode
If user needs metadata for multiple pages, output as a table:
| Page | Meta Title | Meta Description | Chars |
|------|-----------|-----------------|-------|
| [Page] | [Title] | [Description] | [#] |

Always offer: "Want me to audit your existing meta descriptions and rewrite the weak ones?"
