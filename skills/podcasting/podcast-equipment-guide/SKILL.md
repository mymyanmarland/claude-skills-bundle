# Podcast Equipment Guide Skill

## Step 1 — Gather Inputs

- Podcast topic and format
- Target audience
- Current stage: planning/launched/growing
- Budget and technical level
- Primary goal: audience/revenue/authority

## Step 2 — Core Output

Podcast equipment: Microphone types (dynamic vs condenser — dynamic for untreated rooms) → Budget tiers ($50/$150/$300/professional) → Interface vs USB decision → Headphones for monitoring → Acoustic treatment basics (cheap wins: rugs/curtains/closet recording) → Recording software → Remote recording tools (Riverside/SquadCast/Zencastr) → Mobile recording setup.

## Step 3 — Quality & Polish

- Dynamic mic for untreated rooms — most important recommendation
- Acoustic treatment before expensive mic upgrade
- Remote recording platform selection by use case

Always offer a relevant next step.
