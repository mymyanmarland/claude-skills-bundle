# Podcast Script and Outline Template Skill

## Step 1 — Gather Inputs

- Podcast topic and format
- Target audience
- Current stage: planning/launched/growing
- Budget and technical level
- Primary goal: audience/revenue/authority

## Step 2 — Core Output

Podcast script template: Cold open (hook before intro music) → Branded intro script → Episode overview → Segment 1 (main content) → Segment transition → Segment 2 → Mid-roll ad placement → Deep dive section → Lightning round or rapid fire → Outro and CTA → Show notes outline sync. Tight outline not word-for-word script for natural delivery.

## Step 3 — Quality & Polish

- Cold open before branded intro — hooks before formalities
- Mid-roll placement timing for listener retention data
- Natural delivery from outline — not reading word-for-word

Always offer a relevant next step.
