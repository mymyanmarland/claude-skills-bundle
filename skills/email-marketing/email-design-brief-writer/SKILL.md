# Email Design Brief Writer Skill

## Step 1 — Gather Inputs

- Email purpose
- Brand guidelines
- Layout preference
- Key elements
- Mobile considerations

## Step 2 — Core Output

Design brief: Subject and preview text → Layout structure (header, hero, body sections, footer) → Visual hierarchy (what the eye should hit first, second, third) → CTA button specifications → Image directions → Color and typography notes → Mobile first considerations → Plain text version notes. Wireframe description included.

## Step 3 — Quality & Polish

- Mobile behavior specified for each section
- Visual hierarchy serves conversion goal
- CTA button specs specific — not just 'make it stand out'

Always offer a relevant next step.
