# Transactional Email Copywriter Skill

## Step 1 — Gather Inputs

- Transaction type
- Brand tone
- Secondary goal (upsell/referral/review)
- Customer profile
- Legal requirements

## Step 2 — Core Output

Templates: Order confirmation (confirmation + what to expect + secondary CTA) → Shipping notification (excitement + tracking + related product) → Delivery confirmation (celebrate + review ask) → Password reset (clear + secure + trust signals) → Receipt (clear + friendly + loyalty mention). Each maintains brand voice in functional context.

## Step 3 — Quality & Polish

- Primary function clear before any secondary CTA
- Brand voice present without obscuring information
- Legal requirements met in each applicable template

Always offer a relevant next step.
