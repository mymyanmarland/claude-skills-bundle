# Promotional Email Writer Skill

## Step 1 — Gather Inputs

- Offer details
- Audience
- Deadline
- Product description
- Tone preference

## Step 2 — Core Output

Email: Subject (benefit + urgency — not 'SALE') + Preview text → Opening (context before offer) → Offer presentation → Key benefits (3 max) → Social proof element → Objection handler → CTA → P.S. (urgency reinforcement). Promotional without feeling promotional.

## Step 3 — Quality & Polish

- Offer context set before price reveal
- CTA appears twice minimum
- P.S. strongest urgency element

Always offer a relevant next step.
