# Email Split Test Framework Skill

## Step 1 — Gather Inputs

- What to test
- List size
- Current benchmarks
- Testing cadence
- Success metrics

## Step 2 — Core Output

Testing framework: Variables ranked by impact (subject line → from name → preview text → CTA → content length → send time) → Test design per variable (control, variant, sample size, duration) → Statistical significance guide (for given list size) → Documentation template → Learning library structure. 6-month testing roadmap.

## Step 3 — Quality & Polish

- Tests one variable at a time
- Sample sizes statistically valid
- Learning library prevents retesting same things

Always offer a relevant next step.
