# Email List Hygiene Guide Skill

## Step 1 — Gather Inputs

- List size
- Current engagement metrics
- Platform capabilities
- How list was built
- Compliance requirements

## Step 2 — Core Output

Hygiene process: Engagement scoring setup (active/at-risk/inactive/zombie criteria) → Suppression workflow → Re-permission campaign template → Hard bounce handling → Spam complaint threshold actions → List verification service recommendation → Ongoing hygiene calendar. Deliverability impact estimates.

## Step 3 — Quality & Polish

- Engagement criteria specific and measurable
- Re-permission campaign template honest about removal
- Ongoing calendar achievable — not daily work

Always offer a relevant next step.
