# Email Product Education Series Skill

## Step 1 — Gather Inputs

- Product features to highlight
- User adoption gaps
- Current churn reasons
- Onboarding stage
- Customer type

## Step 2 — Core Output

Education series: Feature spotlight sequence (1 email per key feature, 2-week cadence) → Each email: feature name + the problem it solves + how to use it (3 steps) + success example + activation CTA. Milestone celebration emails when feature is used. Feedback request at series end.

## Step 3 — Quality & Polish

- Each email solves a problem — not just announces a feature
- Activation CTA takes under 2 minutes
- Milestone celebration immediate when triggered

Always offer a relevant next step.
