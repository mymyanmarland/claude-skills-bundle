# Automated Email Workflow Planner Skill

## Step 1 — Gather Inputs

- Customer lifecycle stages
- Key trigger events
- Automation platform
- Team resources
- Business goals per stage

## Step 2 — Core Output

Workflow map: Lifecycle stages → Trigger events per stage → Email sequence per trigger → Branch logic → Time delays → Exit conditions → KPIs per workflow. Priority order for building. Estimated setup time per workflow. Integration requirements.

## Step 3 — Quality & Polish

- Every workflow has clear exit condition
- Branch logic handles key behavioral signals
- Priority order based on revenue impact

Always offer a relevant next step.
