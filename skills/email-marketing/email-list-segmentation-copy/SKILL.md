# Email List Segmentation Copy Skill

## Step 1 — Gather Inputs

- Segments defined
- Product or campaign
- Difference between segments
- Personalization depth
- Brand voice

## Step 2 — Core Output

For each segment: Segment-specific subject line + Personalized opening paragraph + Tailored body copy (what changes for this segment) + Segment-appropriate CTA. Plus: shared copy blocks (what stays the same) + Personalization token guide. Explain the strategic rationale for each variation.

## Step 3 — Quality & Polish

- Personalization meaningful — not just first name
- Each segment version speaks to distinct need or behavior
- Shared copy blocks keep production efficient

Always offer a relevant next step.
