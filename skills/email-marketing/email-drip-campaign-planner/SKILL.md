# Email Drip Campaign Planner Skill

## Step 1 — Gather Inputs

- Product or service
- Buyer journey stages
- Trigger events
- Sales cycle length
- Content assets available

## Step 2 — Core Output

Drip plan: Trigger map (what event starts each sequence) → Sequence per trigger: emails, timing, goal, content type → Branch logic (if they click X → send Y) → Exit conditions → Frequency caps. For each email in each sequence: subject line, angle, CTA. Visual flow description.

## Step 3 — Quality & Polish

- Each sequence has clear exit condition
- Content matches buyer stage — educational early, persuasive late
- Frequency cap prevents list fatigue

Always offer a relevant next step.
