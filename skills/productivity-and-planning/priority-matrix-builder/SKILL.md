# Priority Matrix Builder Skill

## Step 1 — Gather Inputs

- Full task/project list
- Urgency and importance signals
- Role and what you're responsible for
- Current bottlenecks
- Decision-making context

## Step 2 — Core Output

Priority analysis: Task list mapped to matrix (urgent+important/important only/urgent only/neither) → Elimination candidates identified → Delegation opportunities flagged → Scheduling recommendation (when to do each quadrant) → Weekly review protocol to re-prioritize → Red flags (everything in urgent+important = system problem) → Quadrant 2 protection strategy.

## Step 3 — Quality & Polish

- Everything in Q1 is a systems failure — identified and addressed
- Q2 activities explicitly scheduled — or they never happen
- Delegation candidates specific — not 'delegate more'

Always offer a relevant next step.
