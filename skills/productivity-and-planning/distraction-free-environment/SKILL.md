# Distraction-Free Environment Designer Skill

## Step 1 — Gather Inputs

- Work environment (home/office/hybrid)
- Work type (solo deep work/collaborative/calls)
- Biggest distraction sources
- Budget for changes
- Tech stack

## Step 2 — Core Output

Environment design: Physical space optimization (desk position, light, noise, temperature) → Digital environment (browser extensions, app blockers, notification settings) → Signal system for others (do not disturb protocol) → Distraction object removal → Focus artifacts (objects that signal work mode) → Environment audit → Per-task environment variations.

## Step 3 — Quality & Polish

- Changes ranked by impact vs effort
- Signal system communicated to others — not just hoped for
- Focus artifacts consistent — trains environmental cue

Always offer a relevant next step.
