# Procrastination Buster Skill

## Step 1 — Gather Inputs

- What they're procrastinating on
- How long and how severe
- Suspected reason (fear/boredom/overwhelm/perfectionism)
- What happens when they finally do it
- Context of procrastination

## Step 2 — Core Output

Procrastination diagnosis: Root cause identification (fear of failure/perfectionism/unclear next action/aversion/task too large) → Intervention per cause → The 2-minute rule → Task decomposition (make next action so small it's embarrassing not to do) → Environment design for the task → Commitment device → Reward structure → The 'just 15 minutes' technique. Addresses root cause — not just willpower.

## Step 3 — Quality & Polish

- Root cause identified before intervention
- Intervention matched to cause — not generic 'just do it'
- Next action specific enough to start without thinking

Always offer a relevant next step.
