# Weekly Planning Ritual Skill

## Step 1 — Gather Inputs

- Schedule structure
- Work type
- Tools used (digital/paper)
- Current planning pain
- Time available for planning

## Step 2 — Core Output

Weekly ritual: Review phase (capture open loops, review last week, clear inbox) → Preview phase (review calendar, identify constraints) → Planning phase (identify MITs for the week, block deep work, schedule important but not urgent) → Prep phase (what do I need ready for Monday?). Total time: 30-60 minutes. Day and time recommendation. Template included.

## Step 3 — Quality & Polish

- Review before planning — can't plan without knowing current state
- MITs identified for the week — not just daily
- Prep phase prevents Monday morning chaos

Always offer a relevant next step.
