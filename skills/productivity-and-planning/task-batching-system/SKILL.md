# Task Batching System Skill

## Step 1 — Gather Inputs

- Task types performed regularly
- Current context switching frequency
- Schedule flexibility
- Tools used
- Biggest efficiency pain

## Step 2 — Core Output

Batching system: Task audit and categorization (communication/creation/admin/meetings/planning) → Batch windows by task type → Communication batch protocol (email/Slack at set times) → Creation batch best practices (same output type together) → Meeting consolidation strategy → Batch size optimization → Transition time between batches. Context switching cost quantified.

## Step 3 — Quality & Polish

- Batches matched to energy level (creative work when high energy)
- Communication batches specific times — not random checks
- Context switching cost made explicit — motivates the system

Always offer a relevant next step.
