# Deep Work Scheduler Skill

## Step 1 — Gather Inputs

- Job type and deep work requirements
- Current schedule and meeting load
- Biological prime time (morning/afternoon person)
- Interruption sources
- Weekly hour target for deep work

## Step 2 — Core Output

Deep work schedule: Time block identification (prime hours protected) → Meeting compression strategy (batch meetings to 2-3 days) → Communication protocols (email/Slack check times) → Deep work environment setup → Transition ritual into deep work → Interruption response scripts → Weekly deep work hour tracking → Quarterly schedule review. Cal Newport principles applied.

## Step 3 — Quality & Polish

- Prime hours protected before meetings fill them
- Communication protocols prevent interruption during blocks
- Transition ritual consistent — trains the brain

Always offer a relevant next step.
