# Focus Block Designer Skill

## Step 1 — Gather Inputs

- Work type and complexity
- Biological rhythms
- Current focus duration
- Environment control level
- Recovery preferences

## Step 2 — Core Output

Focus block design: Optimal session length (based on work type and biology — not one-size) → Pre-session ritual (2-3 minutes) → Session structure (focus → note capture → decision) → Break protocol (duration, activity) → Recovery between sessions → End-of-day focus log → Weekly focus time target → Environment checklist per session type.

## Step 3 — Quality & Polish

- Session length matched to work type — writing vs coding vs analysis differ
- Break activity specific — passive rest vs active rest
- Pre-session ritual consistent — trains focus response

Always offer a relevant next step.
