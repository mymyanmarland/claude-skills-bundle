# Output Quality System Skill

## Step 1 — Gather Inputs

- Work type
- Current quality issues
- Perfectionism level
- Deadlines and throughput needs
- Quality standards required

## Step 2 — Core Output

Quality system: Quality standard definition (what 'done' looks like — specific criteria) → The 80% threshold (when to stop refining) → Quality checklist per output type → Peer review protocol → Error log (track mistakes, prevent recurrence) → Feedback loop → Perfectionism intervention (when refining is avoiding delivery).

## Step 3 — Quality & Polish

- Quality standard explicit — prevents moving goalposts
- 80% threshold defined for each output type
- Perfectionism intervention honest — sometimes it's fear, not quality

Always offer a relevant next step.
