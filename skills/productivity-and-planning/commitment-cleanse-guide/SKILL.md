# Commitment Cleanse Guide Skill

## Step 1 — Gather Inputs

- Current commitments inventory
- Energy and satisfaction per commitment
- Core responsibilities that can't change
- What you're protecting time for
- Exit timeline constraints

## Step 2 — Core Output

Commitment cleanse: Inventory (list every recurring commitment) → Assessment (energy cost vs value returned) → Keep/reduce/exit classification → Exit scripts per relationship type (work/volunteer/social) → Reduction negotiation (same commitment, less time) → Protected list (non-negotiables that make the cut) → New commitment filter (what standards to apply going forward).

## Step 3 — Quality & Polish

- Every commitment inventoried — including small recurring ones
- Exit scripts for different relationship types
- New commitment filter prevents immediate refilling

Always offer a relevant next step.
