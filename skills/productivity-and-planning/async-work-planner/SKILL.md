# Async Work Planner Skill

## Step 1 — Gather Inputs

- Team distribution and time zones
- Work types requiring sync vs async
- Current async tool stack
- Communication norms
- Decision-making speed requirements

## Step 2 — Core Output

Async work design: Async vs sync decision framework (what requires real-time) → Documentation-first culture → Async communication standards (write once, read many) → Tool-by-tool async protocol → Decision-making async processes → Async update rhythms → Overlap hours optimization → Async onboarding for new team members.

## Step 3 — Quality & Polish

- Async vs sync decision framework explicit — not case-by-case
- Documentation standards specific enough to implement
- Overlap hours used strategically — not randomly

Always offer a relevant next step.
