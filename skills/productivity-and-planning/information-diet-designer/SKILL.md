# Information Diet Designer Skill

## Step 1 — Gather Inputs

- Current information sources
- Information goals
- Biggest noise sources
- Time spent consuming
- Professional information requirements

## Step 2 — Core Output

Information diet: Audit (what you consume + time spent + value returned) → Signal-to-noise assessment per source → Essential vs optional classification → Elimination protocol (cancel/unsubscribe/delete) → Curation approach (RSS/newsletters vs social scroll) → Consumption windows (scheduled, not always-on) → Information fasting → Weekly signal check (did information lead to action?).

## Step 3 — Quality & Polish

- Value of each source assessed honestly
- Scheduled consumption windows specific
- Information fasting option included — not assumed bad

Always offer a relevant next step.
