# Batch Creation Guide Skill

## Step 1 — Gather Inputs

- Output type (content/reports/proposals)
- Creation frequency
- Production capacity
- Tools used
- Current creation inefficiency

## Step 2 — Core Output

Batch creation guide: Batch size optimization (how much per session) → Preparation phase (research/outline/gather before creating) → Creation-only sessions (no research during creation) → Review/edit as separate batch → Distribution as separate batch → Template development → Asset library building → Batch calendar (when to create for the month ahead).

## Step 3 — Quality & Polish

- Phases separated — no switching between research and creation
- Templates built during batching — reduce future batch time
- Batch calendar planned in advance — not reactive

Always offer a relevant next step.
