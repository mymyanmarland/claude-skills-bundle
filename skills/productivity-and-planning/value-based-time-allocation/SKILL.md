# Value-Based Time Allocation Skill

## Step 1 — Gather Inputs

- Stated values and priorities
- Current time allocation
- Gap between values and time
- Constraints
- Non-negotiable commitments

## Step 2 — Core Output

Value-based allocation: Values → Priority ranking → Minimum time per priority (floor to honor each value) → Current vs desired allocation (the gap) → Reallocation plan (what to reduce to create space) → Time tithe (percentage of time pre-committed to highest values) → Monthly allocation review → Calendar audit.

## Step 3 — Quality & Polish

- Gap between stated values and actual time allocation made explicit
- Minimum time floors prevent value neglect
- Monthly review catches drift before it compounds

Always offer a relevant next step.
