# Time Audit Guide Skill

## Step 1 — Gather Inputs

- Work type and responsibilities
- Audit duration (1 day/week/2 weeks)
- Tracking method preference
- Key hypotheses about time
- Goals after audit

## Step 2 — Core Output

Time audit guide: Tracking methodology (simple categories, 30-min intervals) → Category definitions (meeting/deep work/shallow work/email/admin/personal) → Data collection template → Analysis questions (what surprises you? what's missing? what's excessive?) → Alignment check (does time match stated priorities?) → Redesign recommendations → Before/after comparison template.

## Step 3 — Quality & Polish

- Categories specific enough to be meaningful — not too granular
- Surprise identification structured — not just listing data
- Redesign recommendations actionable from audit findings

Always offer a relevant next step.
