# Habit Stacking Planner Skill

## Step 1 — Gather Inputs

- Habits to build
- Existing strong routines (anchors)
- Habit difficulty level
- Time available per habit
- Sequence preferences

## Step 2 — Core Output

Habit stack design: Anchor habit identification (strong existing habits as triggers) → New habit attached to each anchor → If-then implementation intentions ('After I pour my morning coffee, I will...') → Stack complexity (1-3 habits max per anchor) → Morning/evening stack examples → Troubleshooting weak habits → Habit stack calendar → Progress tracking method.

## Step 3 — Quality & Polish

- Anchor habits strong and consistent — not aspirational
- Stack size conservative — 1-2 new habits per anchor
- If-then formulation specific — location and time included

Always offer a relevant next step.
