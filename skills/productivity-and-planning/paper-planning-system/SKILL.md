# Paper Planning System Skill

## Step 1 — Gather Inputs

- Paper tool preference (planner/notebook/index cards)
- Planning scope (daily/weekly/monthly)
- Portability needs
- Review cadence
- Current paper planning pain

## Step 2 — Core Output

Paper system design: Tool selection guide (dated planner vs blank notebook vs index cards) → Page layout templates (daily/weekly/monthly) → Rapid logging shorthand → Migration protocol (moving unfinished items forward) → Index and collection pages → Review ritual for paper system → Digital + paper hybrid approach (if needed) → Archive protocol.

## Step 3 — Quality & Polish

- System matched to chosen tool — not generic
- Migration protocol prevents lost items
- Hybrid approach acknowledged — not either/or

Always offer a relevant next step.
