# Scope Creep Preventer Skill

## Step 1 — Gather Inputs

- Project types prone to scope creep
- Common scope addition patterns
- Decision-making authority
- Client or stakeholder dynamics
- Current scope management approach

## Step 2 — Core Output

Scope creep prevention: Definition phase (what IS and IS NOT in scope — written) → Change request protocol (how to handle new asks formally) → The 'yes, and' vs 'yes, but first' distinction → Client communication templates for scope additions → Internal scope protection (team adds without asking) → Weekly scope check → Scope creep warning signs.

## Step 3 — Quality & Polish

- Scope exclusions as explicit as inclusions
- Change request protocol specific — not just 'say no'
- Warning signs identified before it's too late

Always offer a relevant next step.
