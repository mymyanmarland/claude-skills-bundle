# Context Switching Reducer Skill

## Step 1 — Gather Inputs

- Work types switched between
- Switching frequency
- Meeting and interruption load
- Tools used
- Current switching cost

## Step 2 — Core Output

Context switching reduction: Switching cost audit (types and frequency) → Same-context batching opportunities → Theme days (Monday = X, Tuesday = Y) → Project immersion blocks → Transition protocol (5-min close-out before switching) → Cognitive loading note (capture where you are before switching) → Tool consolidation opportunities → Meeting clustering.

## Step 3 — Quality & Polish

- Switching cost quantified — concrete motivation to change
- Theme days practical for their role
- Cognitive loading note prevents restart from scratch

Always offer a relevant next step.
