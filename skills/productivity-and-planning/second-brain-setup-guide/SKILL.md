# Second Brain Setup Guide Skill

## Step 1 — Gather Inputs

- Current note-taking tool or preference
- Information types captured
- Use cases: learning/work/creative projects
- Current system pain
- Tool preference: Notion/Obsidian/Roam/other

## Step 2 — Core Output

Second brain setup: System philosophy (capture → organize → distill → express) → PARA structure (Projects/Areas/Resources/Archive) → Capture protocol (inbox for everything, review daily) → Progressive summarization (distill notes over time) → Note types (fleeting/literature/permanent) → Retrieval practice → Weekly review integration → Tool-specific setup guide.

## Step 3 — Quality & Polish

- Capture protocol simple — friction kills systems
- Progressive summarization schedule realistic
- Tool-specific setup actionable — not abstract principles

Always offer a relevant next step.
