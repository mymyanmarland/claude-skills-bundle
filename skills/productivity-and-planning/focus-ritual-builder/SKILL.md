# Focus Ritual Builder Skill

## Step 1 — Gather Inputs

- Work type requiring focus
- Time of day for focus work
- Ritual preferences
- Current start-of-work friction
- Available ritual elements

## Step 2 — Core Output

Focus ritual design: Physiological primer (movement/light/temperature) → Environmental signal (specific workspace setup) → Cognitive primer (review priorities) → Focus object or symbol → The start signal (specific action that triggers work mode) → Duration (5-10 minutes maximum) → Ritual consistency (same every time). Pavlovian response building.

## Step 3 — Quality & Polish

- Ritual under 10 minutes — consistency more important than length
- Start signal specific and consistent
- Physiological component included — body before brain

Always offer a relevant next step.
