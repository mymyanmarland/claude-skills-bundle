# Project Timeline Builder Skill

## Step 1 — Gather Inputs

- Project scope and deliverables
- Team size and capacity
- Dependencies and constraints
- Deadline if fixed
- Risk factors

## Step 2 — Core Output

Project timeline: Work breakdown structure (deliverables → tasks → subtasks) → Dependency mapping → Duration estimation with buffer (tasks take 1.5-2x estimated time) → Critical path identification → Milestone checkpoints → Risk buffer allocation → Gantt chart description → Weekly check-in cadence → Timeline communication template.

## Step 3 — Quality & Polish

- Buffer time explicitly included — not hoped for
- Critical path identified — where delays cascade
- Timeline communicated to stakeholders with assumptions stated

Always offer a relevant next step.
