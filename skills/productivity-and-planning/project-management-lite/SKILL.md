# Project Management Lite Skill

## Step 1 — Gather Inputs

- Number of concurrent projects
- Team size
- Tool preferences (Notion/Trello/spreadsheet/paper)
- Project types
- Current tracking pain

## Step 2 — Core Output

Lite PM system: Project inventory (one place to see everything) → Project status protocol (RAG: red/amber/green) → Weekly project review (5 min per project) → Next action per project always identified → Communication cadence per project type → Stakeholder update template → Project closure checklist → Archive system. Overhead under 30 minutes/week.

## Step 3 — Quality & Polish

- Next action always defined — project never 'in progress' without a next step
- Weekly review under 30 minutes total
- System matches tool already used — not added complexity

Always offer a relevant next step.
