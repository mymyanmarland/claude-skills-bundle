# Financial Independence Number Calculator Skill

## Step 1 — Gather Inputs

- Current financial situation and income
- Specific challenge or goal
- Existing accounts and debts
- Risk tolerance and timeline
- Previous financial approaches tried

## Step 2 — Core Output

FI number calculation: Annual expense baseline → Lifestyle adjustment (current vs desired retirement lifestyle) → The 25x rule application → 4% withdrawal rate with context and limitations → Inflation adjustment → Healthcare cost factor (pre-Medicare gap) → Scenario planning (lean/base/fat FI) → Years to FI at current savings rate → Sensitivity analysis (what if market returns lower?).

## Step 3 — Quality & Polish

- Expense baseline — the most important and most variable input
- Healthcare gap — often underestimated pre-Medicare
- Scenario planning — lean/base/fat provides range not false precision

Always offer a relevant next step.
