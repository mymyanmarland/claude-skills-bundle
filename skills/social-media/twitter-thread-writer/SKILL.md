# Twitter Thread Writer Skill

## Step 1 — Gather Inputs

- Topic
- Key insights (5-10)
- Audience
- Thread length
- End goal: followers/clicks/engagement

## Step 2 — Core Output

Thread structure: Tweet 1 (hook — bold claim or surprising insight that makes them want more) → Tweets 2-9 (one insight per tweet, each self-contained) → Tweet 10 (synthesis or call to action). Use numbered format (1/10). Each tweet under 280 chars. Thread must work if read non-linearly.

## Step 3 — Quality & Polish

- Hook tweet works as standalone viral tweet
- Each numbered tweet advances the thread — no filler
- Final tweet memorable enough to quote-tweet

Always offer a relevant next step.
