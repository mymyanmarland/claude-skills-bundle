# Social Media Metrics Dashboard Skill

## Step 1 — Gather Inputs

- Platforms
- Business goals
- Reporting audience
- Current metrics tracked
- Reporting frequency

## Step 2 — Core Output

Dashboard framework: Goal hierarchy (business goal → platform goal → post goal) → Metric set per goal (primary + secondary) → Benchmarking methodology → Weekly vs monthly reporting templates → Red/yellow/green status thresholds → Optimization triggers (when metrics indicate a change). Translate every metric to business language.

## Step 3 — Quality & Polish

- Metrics connect to business goals — not vanity metrics
- Benchmarks platform-specific
- Red flags define actionable thresholds

Always offer a relevant next step.
