# Instagram Story Script Skill

## Step 1 — Gather Inputs

- Story topic/goal
- Number of frames
- Brand tone
- Desired action
- Any polls or questions to include

## Step 2 — Core Output

Frame-by-frame script: Each frame: visual description + text overlay copy + engagement element (poll/question/slider). Frame 1: hook. Frames 2-7: value delivery. Final frame: CTA. Include swipe-up text if applicable. Each frame designed to keep viewer tapping forward.

## Step 3 — Quality & Polish

- Frame 1 creates a reason to continue
- Each frame is complete if viewed standalone
- CTA frame specific and low-friction

Always offer a relevant next step.
