# Social Media Ad Creative Brief Skill

## Step 1 — Gather Inputs

- Campaign goal
- Target audience
- Platform
- Budget range
- Creative assets available

## Step 2 — Core Output

Creative brief: Campaign objective → Target audience profile → Key message (one sentence) → Tone and feel → Format requirements per platform → Headline options (5) → Body copy options (3) → CTA options (3) → Visual direction notes → Do/don't list → Success metrics. Designed so a designer can execute without a briefing call.

## Step 3 — Quality & Polish

- Key message is one sentence — no compound messages
- Visual direction specific enough to be actionable
- Do/don't list based on brand guidelines

Always offer a relevant next step.
