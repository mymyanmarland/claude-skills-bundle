# Social Media Analytics Interpreter Skill

## Step 1 — Gather Inputs

- Metrics data provided
- Platform
- Goals
- Content types run
- Time period

## Step 2 — Core Output

Analytics report: What's working (3 specific findings with evidence) → What's not working → Recommended changes → Content types to double down on → Best posting times from data → Audience growth analysis → Next month content recommendations. Plain language — no jargon.

## Step 3 — Quality & Polish

- Every recommendation tied to specific data
- 'Do more of this' specific about what 'this' is
- Timeframe context provided for all metrics

Always offer a relevant next step.
