# Social Media Posting Schedule Skill

## Step 1 — Gather Inputs

- Platforms
- Audience time zones
- Current posting patterns
- Engagement data if available
- Content production capacity

## Step 2 — Core Output

Posting schedule: Platform-by-platform optimal times (with reasoning) → Weekly posting frequency per platform → Content type per time slot → Batch creation schedule (when to create for the week) → Scheduling tool recommendations → Schedule adjustment triggers (when to change based on data).

## Step 3 — Quality & Polish

- Times specific — not just 'mornings'
- Frequency matched to content production capacity
- Adjustment triggers data-based

Always offer a relevant next step.
