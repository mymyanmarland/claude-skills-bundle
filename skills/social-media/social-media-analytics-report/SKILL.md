# Social Media Analytics Report Skill

## Step 1 — Gather Inputs

- Platforms
- KPIs tracked
- Reporting audience
- Time period
- Current performance baseline

## Step 2 — Core Output

Report template: Executive summary (3 wins + 1 concern) → Platform-by-platform performance → Content type performance breakdown → Audience growth analysis → Engagement rate trends → Best/worst performing content → Competitor benchmarks → Next period recommendations. Business language throughout.

## Step 3 — Quality & Polish

- Every metric translated to business outcome
- Best content analysis identifies repeatable pattern
- Recommendations specific and actioned in next period

Always offer a relevant next step.
