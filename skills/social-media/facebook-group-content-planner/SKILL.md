# Facebook Group Content Planner Skill

## Step 1 — Gather Inputs

- Group topic
- Member profile
- Posting frequency
- Group size
- Engagement goal

## Step 2 — Core Output

Weekly posting schedule: Monday (weekly theme post) → Tuesday (question/poll) → Wednesday (value post) → Thursday (member spotlight format) → Friday (reflection/discussion) → Weekend (lighter engagement). 4-week rotating themes. Includes pinned post copy, group rules copy, welcome message.

## Step 3 — Quality & Polish

- Content invites participation — not just consumption
- Questions open-ended and easy to answer
- Welcome message sets community tone immediately

Always offer a relevant next step.
