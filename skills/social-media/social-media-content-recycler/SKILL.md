# Social Media Content Recycler Skill

## Step 1 — Gather Inputs

- Content library size
- Posting frequency
- How long ago content was posted
- Platform
- Freshness requirements

## Step 2 — Core Output

Recycling system: Evergreen content identification criteria → Refresh requirements per content age (6mo: update hook / 12mo: update data / 18mo+: full rewrite) → Rotation schedule → Content tagging system for tracking → Platform-specific recycling norms (LinkedIn tolerates more than TikTok) → Recycling workflow.

## Step 3 — Quality & Polish

- Recycling norms platform-specific
- Refresh requirements prevent stale content
- Tagging system practical to implement

Always offer a relevant next step.
