# Social Media Launch Countdown Skill

## Step 1 — Gather Inputs

- What is launching
- Launch date
- Platforms
- Target audience
- Key benefit to tease

## Step 2 — Core Output

Countdown sequence: T-14 days (first tease — curiosity post) → T-7 days (reveal more — problem post) → T-3 days (behind the scenes) → T-1 day (final countdown — list building CTA) → Launch day (announcement + first purchaser CTA) → T+3 days (social proof from early buyers). Each post: hook + copy + image brief.

## Step 3 — Quality & Polish

- Each post reveals something new — no repetition
- CTA escalates through sequence
- Launch day post has urgency element

Always offer a relevant next step.
