# Story Highlight Copy Skill

## Step 1 — Gather Inputs

- Account type
- Highlights to create
- Brand tone
- Audience profile
- Number of highlights

## Step 2 — Core Output

For each highlight: Name (under 10 chars, keyword-aware) + First story frame copy (introduces what's in this highlight) + Organizing principle (what should go in vs. out). Plus: highlight organization strategy (recommended order on profile), archive strategy, refresh schedule.

## Step 3 — Quality & Polish

- Highlight names scannable — no abbreviations
- First frame clearly sets expectation
- Organization strategy logical from visitor perspective

Always offer a relevant next step.
