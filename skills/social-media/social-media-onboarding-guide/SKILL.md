# Social Media Onboarding Guide Skill

## Step 1 — Gather Inputs

- Platforms
- Brand overview
- Existing content strategy
- Account credentials and tools
- Performance history

## Step 2 — Core Output

Onboarding document: Brand overview (2 pages) → Platform-by-platform account status → Content strategy summary → Voice and tone guide → Content creation workflow → Approval process → Crisis protocol → Key contacts → Performance baselines → First 30-day priorities.

## Step 3 — Quality & Polish

- New manager can operate independently after reading
- Crisis protocol specific — not vague
- Approval process covers all content types

Always offer a relevant next step.
