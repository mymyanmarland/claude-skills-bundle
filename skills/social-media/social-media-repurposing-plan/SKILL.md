# Social Media Repurposing Plan Skill

## Step 1 — Gather Inputs

- Source content
- Target platforms
- Time investment
- Brand consistency needs
- Primary platform vs secondary

## Step 2 — Core Output

Repurposing map: Source → Platform-specific adaptations. For each platform: content type, adaptation needed, native format, copy approach, posting sequence. Identify which elements transfer directly vs. need adaptation. Batching schedule. Quality check per platform.

## Step 3 — Quality & Polish

- Each platform version feels native — not repurposed
- Primary platform version strongest
- Adaptation notes specific — not 'adjust tone'

Always offer a relevant next step.
