# Social Media Copywriting Swipe File Skill

## Step 1 — Gather Inputs

- Platforms
- Industries or niches
- Copy goals
- Tone preferences
- Number of examples

## Step 2 — Core Output

Swipe file organized by: Platform → Goal (engagement/awareness/conversion) → Format (post/story/ad). 5 examples per category with: the copy, why it works, key technique used, how to adapt it. Include a 'remix this' prompt for each example. Total 50-100 examples.

## Step 3 — Quality & Polish

- Each example has a teachable principle
- Remix prompts practical and specific
- Examples from diverse niches — not all one industry

Always offer a relevant next step.
