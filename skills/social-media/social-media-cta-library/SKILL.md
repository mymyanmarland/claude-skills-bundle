# Social Media CTA Library Skill

## Step 1 — Gather Inputs

- Goals: saves/comments/shares/follows/clicks
- Platforms
- Brand tone
- Current CTAs used
- Audience responsiveness

## Step 2 — Core Output

CTA library organized by goal: Save CTAs (10 options) → Comment CTAs (10 options) → Share CTAs (8 options) → Follow CTAs (8 options) → Link click CTAs (10 options) → DM CTAs (6 options). Each CTA: platform fit, tone, placement recommendation. A/B test pairs included.

## Step 3 — Quality & Polish

- CTAs feel natural — not desperate or demanding
- Platform norms respected (LinkedIn vs TikTok very different)
- A/B pairs test genuinely different approaches

Always offer a relevant next step.
