# Content Engagement Booster Skill

## Step 1 — Gather Inputs

- Current post copy
- Platform
- Current performance
- Goal: comments/shares/saves
- Audience

## Step 2 — Core Output

Analysis: what's weakest (hook/body/CTA/format) → Rewritten version → Explanation of changes → 2 alternative rewrites with different approaches → Performance prediction. Show before/after clearly. Include quick format tips specific to the platform.

## Step 3 — Quality & Polish

- Diagnosis specific — not 'it needs a better hook'
- Each rewrite genuinely different approach
- Predicted improvement realistic

Always offer a relevant next step.
