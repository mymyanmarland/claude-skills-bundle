# Pinterest Pin Copy Skill

## Step 1 — Gather Inputs

- Pin topic
- Target keyword
- Board theme
- Link destination
- Ideal pinner profile

## Step 2 — Core Output

For each pin: Title (100 chars, keyword-first, benefit-clear) + Description (500 chars, keyword-rich, conversational, ends with CTA or question). Deliver 5 pin variations on the same topic. Identify 10 keyword variations to use across the set. Include rich pin note if applicable.

## Step 3 — Quality & Polish

- Primary keyword in first 3 words of title
- Description reads naturally — not keyword stuffed
- Each pin variation targets slightly different search intent

Always offer a relevant next step.
