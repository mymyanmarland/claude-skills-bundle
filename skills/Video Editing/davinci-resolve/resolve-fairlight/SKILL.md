# DaVinci Resolve Fairlight Audio Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Fairlight audio: Fairlight page overview (professional DAW within Resolve) → Track types (Mono / Stereo / 5.1 / Dolby Atmos) → Normalise (right-click clip / Normalise Audio Levels) → EQ (channel EQ in the mixer / 6-band parametric) → Dynamics (compressor / limiter / noise gate — in the FX chain) → Bus routing (send all dialogue to a Bus / mix the Bus) → ADR and Foley (record new audio from within Fairlight) → SoundCloud Connect (Resolve can export directly to SoundCloud) → Deliver audio stems (export separate dialogue / music / SFX tracks).

## Step 3 — Quality & Polish

- Bus routing: group similar tracks (all dialogue to one bus) for efficient mixing
- Normalise to -12dBFS: standard broadcast dialogue level before mixing
- Deliver stems: separate dialogue/music/SFX mixes are required for broadcast delivery
