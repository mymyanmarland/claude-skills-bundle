# DaVinci Resolve Fusion Basics Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Fusion basics: Node-based workflow (every operation is a node / nodes connect with lines) → MediaIn and MediaOut (automatically created / source footage enters through MediaIn) → Transform node (position / size / rotate a layer) → Merge node (composite two layers: Background and Foreground inputs) → Mask node (create a shape to limit an effect) → Text+ node (full-featured text with animation) → Tracking (the Tracker node — tracks a point in the footage) → Key node (Chroma Keyer or Luma Keyer for green screen) → Render (the result always ends at a MediaOut node).

## Step 3 — Quality & Polish

- Merge node is the compositor: every composite uses a Merge node with Background and Foreground
- MediaIn connects automatically: it links to the timeline clip below in the Edit page
- Tracker first then attach effects: always track before connecting dependent nodes
