## Step 2 — Core Output

Speed Editor workflow: Resolve keyboard shortcuts differ from Premiere → Playback (J-K-L: reverse/stop/forward) → In/Out points (I and O in source viewer) → Mark selection (X marks In/Out around the current clip) → Append to End (Shift-F12) → Insert (F9) → Overwrite (F10) → Replace (F11) → Trim (T activates trim mode) → Ripple trim (comma/period keys: trim frame by frame) → Smart Tool (hover near cut point for context-sensitive tool selection) → Keyboard customisation (DaVinci Resolve / Keyboard Customisation).

## Step 3 — Quality & Polish

- J-K-L transport: the universal editing shortcut — same in all major NLEs
- Mark selection with X: fastest way to mark the current clip In/Out simultaneously
- Smart Tool hover: Resolve's most efficient trim behaviour — no tool switching required
