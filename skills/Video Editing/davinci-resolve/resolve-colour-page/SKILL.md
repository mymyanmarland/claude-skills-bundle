# DaVinci Resolve Colour Page Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Colour page: Node editor (each node is a separate colour operation — non-destructive) → Serial nodes (flow left to right / most common: CST > Grade > Creative) → Colour Space Transform CST (convert log or raw footage to a working colour space first) → Primaries wheels (Lift/Gamma/Gain — shadows/midtones/highlights) → Scopes (Waveform / Parade / Vectorscope — in the Scopes tab) → Qualifier (select a colour range for secondary correction) → Power Windows (masks for spatial corrections) → Group grade (grade multiple clips with a shared node applied to all — pre-clip group).

## Step 3 — Quality & Polish

- CST node first for log footage: grading log footage without converting it looks flat and dull
- Serial nodes: one node per operation — keeps the grade organised and adjustable
- Group grade: the most efficient way to grade a whole scene consistently
