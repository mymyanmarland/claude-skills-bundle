# DaVinci Resolve Cut Page Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Cut page workflow: Dual timeline (top: full timeline / bottom: zoomed in — both always visible) → Source Tape (all media displayed as a continuous tape — scrub to find footage) → Smart Indicators (yellow markers show where the clip already exists in the timeline) → Quick Export (top right of the page — fastest route to an export) → Sync Bin (sync multi-camera clips from the Source Tape view) → Razor Blade (B key) → Split and delete (remove a section: mark In/Out in the timeline then delete) → Trim mode (hover near an edit point and it auto-activates).

## Step 3 — Quality & Polish

- Dual timeline: the Cut page's unique advantage — always see both context and detail
- Smart Indicators prevent duplicate clips: yellow = already used
- Quick Export for fast deliverables: single click H.264 export without opening Deliver page
