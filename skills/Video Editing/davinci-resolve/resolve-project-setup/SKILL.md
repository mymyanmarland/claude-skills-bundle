# DaVinci Resolve Project Setup Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Resolve project setup: Project Manager (create a new project / name clearly) → Project Settings (Master Settings: timeline resolution / frame rate — match camera) → Optimised Media (create optimised copies for smooth playback of high-res footage) → Proxy Mode (on the Playback menu — reduce resolution during editing) → Media Pool organisation (bins: Source / Audio / VFX / Music / Exports) → Backup (File / Project Manager / Export Project Archive) → Database location (local vs network — local for speed).

## Step 3 — Quality & Polish

- Match frame rate to camera: mismatched frame rates cause audio sync drift
- Optimised media for 4K: Resolve can struggle with raw 4K without optimised media
- Project Archive: the only way to move a Resolve project between systems safely
