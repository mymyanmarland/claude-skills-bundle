# DaVinci Resolve Edit Page Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Edit page workflow: Three-panel layout (Media Pool / Source Viewer / Timeline Viewer) → Timeline tracks (add video / audio tracks: right-click track header) → Editing tools (Selection A / Trim T / Blade B / Slip S) → Track locking (lock audio or video tracks to prevent accidental edits) → Compound Clips (equivalent of Premiere's nested sequences) → Multicam Clips (sync and cut multicam) → Flags and markers (add notes / colour-code clips for logging) → Speed change (right-click clip / Change Clip Speed) → Inspector panel (equivalent of Effect Controls — all clip properties).

## Step 3 — Quality & Polish

- Compound Clips for grouping: the Edit page's equivalent of Premiere's nested sequence
- Lock tracks during grade: prevents accidental timeline edits in the colour page
- Flags for logging: colour-code clips during selects to speed up the assembly
