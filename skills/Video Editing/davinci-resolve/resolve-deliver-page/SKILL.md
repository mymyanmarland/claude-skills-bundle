# DaVinci Resolve Deliver Page Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Deliver page: Add to Render Queue (set settings then Add to Render Queue) → Format presets (YouTube 4K / Vimeo / H.264 / ProRes / DNxHR) → Custom export (Format: MP4 / Video: H.264 / Resolution: match source / Bitrate: 20Mbps 1080p) → Audio (AAC for web / PCM for broadcast) → Individual clips vs single clip export (choose which clips to export) → Render In Place (Export the current timeline clip as rendered media) → Batch export (add multiple jobs to the queue / Render All).

## Step 3 — Quality & Polish

- Add to Render Queue before rendering: review all settings before committing
- Render In Place for pre-rendered effects: flatten complex Fusion effects before delivering
- Batch multiple deliverables: add YouTube and broadcast presets to the same queue
