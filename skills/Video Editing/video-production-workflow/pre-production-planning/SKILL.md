# Pre-Production Planning Skill

## Step 1 — Gather Inputs

- Software and platform
- Experience level
- Project type
- Specific task
- Output format

## Step 2 — Core Output

Pre-production planning: Script or outline (what will be said and shown — even a loose outline improves the edit) → Shot list (every shot needed / angle / duration / equipment) → Location scouting (check light at the shooting time of day / listen for noise / check power access) → Equipment checklist (camera / lenses / audio / lighting / batteries / cards / backup) → Talent briefing (what to wear / key messages / approx duration) → Shooting schedule (order of shots / time per location) → Release forms (model release / location release — required for commercial use) → Budget (equipment hire / talent / location / post-production).

## Step 3 — Quality & Polish

- Shot list before shooting: improvising on location is expensive and inefficient
- Scout at the same time of day as the shoot: light changes dramatically throughout the day
- Release forms before shooting: impossible to get after the fact if talent becomes uncooperative
