# Video Production Tools and Apps Skill

## Step 1 — Gather Inputs

- Software and platform
- Experience level
- Project type
- Specific task
- Output format

## Step 2 — Core Output

Video production tools: Pre-production (Shot Lister / Celtx / Google Sheets for shot lists / Notion for project management) → On-set (Timecode Systems / Movie Slate for clapper / Luts.cafe for on-set LUT monitoring) → Post-production (DaVinci Resolve / Premiere Pro / Frame.io for review) → Audio (Adobe Audition / iZotope RX for repair / Fairlight in Resolve) → Asset management (CatDV / IconIK / DaVinci Media Management) → Delivery (Vimeo / WeTransfer for client delivery / Aspera for large broadcast files) → Cloud storage (Frame.io / Google Drive / Dropbox for project assets).

## Step 3 — Quality & Polish

- Frame.io: the industry standard for review and delivery — widely adopted in professional production
- iZotope RX: the professional standard for audio repair — worth the investment for regular work
- Consistent asset management from day one: disorganised projects cost more in post than they save in pre-production
