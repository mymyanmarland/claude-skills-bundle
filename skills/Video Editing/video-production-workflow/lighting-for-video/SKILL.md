# Lighting for Video Skill

## Step 1 — Gather Inputs

- Software and platform
- Experience level
- Project type
- Specific task
- Output format

## Step 2 — Core Output

Lighting for video: Three-point lighting (Key: main light at 45 degrees / Fill: opposite side softer / Back: separates subject from background) → Key light quality (hard light: bare LED / direct sun — creates sharp shadows / soft light: diffused — flatters subjects) → Colour temperature (daylight: 5600K / tungsten: 3200K / mix: set white balance to dominant source or gel the lights to match) → Exposure check (false colour on the monitor shows clipped highlights in red / underexposure in blue) → Natural light (window light is beautiful — use a reflector to fill the shadows) → Interview setup (key from the side of the interview angle / not the camera axis).

## Step 3 — Quality & Polish

- Key light at 45 degrees: straight-on lighting is flat — angle creates dimension
- Soft light for interviews: hard light is unflattering for talking heads
- Match colour temperature: mixed sources create unnatural colour casts
