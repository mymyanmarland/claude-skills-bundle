# Video Review and Approval Process Skill

## Step 1 — Gather Inputs

- Software and platform
- Experience level
- Project type
- Specific task
- Output format

## Step 2 — Core Output

Video review and approval: Review platforms (Frame.io / Vimeo Review / Wipster — share a link / client leaves timestamped comments) → Review stages (rough cut → fine cut → picture lock → audio mix → colour grade — approve each before the next) → Feedback brief (give clients specific questions: does this convey X? / not 'what do you think?') → Revision rounds (define the number of revision rounds in the contract: typically 2-3) → Picture lock (nothing changes after picture lock — audio and colour work to the locked edit) → File naming (ProjectName_RoughCut_v01 / maintain version history) → Delivery confirmation (client signs off in writing before final export).

## Step 3 — Quality & Polish

- Timestamped comments: Frame.io makes this standard — clients click to leave a note at the exact moment
- Define revision rounds in the contract: unlimited revisions are unlimited costs
- Picture lock before audio and colour: changes after lock are expensive and disruptive
