# Video Project Archiving Skill

## Step 1 — Gather Inputs

- Software and platform
- Experience level
- Project type
- Specific task
- Output format

## Step 2 — Core Output

Video project archiving: What to archive (source footage / project file / exports / audio / graphics) → Archive format (ProRes or DNxHD for master files — H.264 degrades on re-encode) → File structure (ProjectName / Source / Project_File / Exports / Audio / Graphics — consistent across all projects) → Storage medium (LTO tape for long-term archive: decades reliable / RAID for working archive / cloud for off-site backup) → 3-2-1 rule (3 copies / 2 different media / 1 off-site) → Naming convention (consistent date-first naming: YYYYMMDD_ProjectName_v01) → Verify before deleting originals (restore test from the archive before removing source drives).

## Step 3 — Quality & Polish

- 3-2-1 backup rule: 3 copies / 2 media types / 1 off-site — the professional standard
- Verify the archive before deleting: the archive that cannot be restored is not an archive
- LTO tape for long-term: hard drives fail within 5-7 years / LTO tape lasts 30+ years
