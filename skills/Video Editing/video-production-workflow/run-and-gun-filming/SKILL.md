# Run and Gun Filming Skill

## Step 1 — Gather Inputs

- Software and platform
- Experience level
- Project type
- Specific task
- Output format

## Step 2 — Core Output

Run and gun filming: Equipment minimalism (camera / one lens / on-camera mic / ND filter / spare batteries — less is faster) → Natural light priority (find good light rather than creating it) → Stabilisation (gimbal / image stabilisation / high shutter for sharp handheld) → Audio compromise (lavalier wireless for best audio / or directional on-camera mic) → Autofocus (modern cameras: eye-tracking AF is reliable for run-and-gun) → Shoot more coverage (compensates for missed shots) → Press record before raising the camera (miss fewer moments) → Card management (carry 4+ cards / offload each evening).

## Step 3 — Quality & Polish

- Press record before raising: by the time you frame up the moment may have passed
- Natural light first: finding good light is faster than creating it
- Eye-tracking autofocus for solo work: frees attention from focus to composition
