# B-Roll Shooting Guide Skill

## Step 1 — Gather Inputs

- Software and platform
- Experience level
- Project type
- Specific task
- Output format

## Step 2 — Core Output

B-roll shooting: What B-roll does (covers the A-roll / adds context / hides edit cuts / tells the visual story) → B-roll types (establishing: wide / cutaway: detail / reaction: emotion / insert: product/object) → Shot variety (wide / medium / close / extreme close-up — cover every subject at all scales) → Movement (static shots / slow pans / push-ins / reveal shots) → Duration (shoot longer than you need — minimum 10 seconds each / edit in post) → Coverage ratio (shoot 5-10× more B-roll than you expect to use) → Continuity (shoot matching B-roll: if A-roll is day exterior shoot B-roll day exterior).

## Step 3 — Quality & Polish

- Shoot at all scales: wide medium close — the editor needs all three for every subject
- 10 seconds minimum: short clips that are too short to use are wasted time
- Coverage ratio 5-10x: the more B-roll shot the more choices in the edit

Always offer a relevant next step or tip to try.
