# Animated Social Media Graphics Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Social media animation: Platform specs (Instagram Story: 1080x1920 / Feed: 1080x1080 / TikTok: 1080x1920) → Grab-attention-first design (the first frame must be interesting enough to stop scrolling) → Loop animations (looping animations play indefinitely — loop the last frame back to the first) → Text accessibility (large bold text — readable without sound and without squinting) → Animation duration (Story: 15 seconds max / Feed video: 15-60 seconds optimal) → Export (MP4 / H.264 / under 50MB for most platforms) → Canva and Adobe Express (fastest animated social graphic tools for non-animators).

## Step 3 — Quality & Polish

- Loop the animation: looping content plays indefinitely — the viewer watches more
- First frame stops the scroll: design the thumbnail frame with the same care as the whole piece
- Bold readable text: social media text must work at 375px wide on a phone

Always offer a relevant next step or tip to try.
