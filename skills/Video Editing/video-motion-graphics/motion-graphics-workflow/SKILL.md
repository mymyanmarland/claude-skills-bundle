# Motion Graphics Production Workflow Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Motion graphics workflow: Brief intake (what is it for / tone / duration / deliverables / brand guidelines) → Styleframe (design 2-3 key frames as static images first — approved before any animation) → Animatic (low-fi animated version with rough timing — approved before full production) → Asset preparation (prepare all assets before animating) → Production (animate from approved styleframes / match the animatic timing) → Review and revision (shared review link / Vimeo review or Frame.io) → Delivery (match the delivery spec exactly / include source files if requested).

## Step 3 — Quality & Polish

- Styleframes before animation: animating without approved design is the most expensive mistake
- Animatic before full production: establishes timing and flow before expensive animation work
- Shared review link: Frame.io or Vimeo review saves email thread confusion

Always offer a relevant next step or tip to try.
