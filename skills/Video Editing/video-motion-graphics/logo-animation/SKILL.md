# Logo Animation Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Logo animation: Import the logo (SVG or AI file / import into AE as a composition — preserves layers) → Trim Paths reveal (if the logo has stroke paths / Trim Paths animates the drawing on) → Layer-by-layer reveal (animate each logo element separately with staggered timing) → Scale up with overshoot (Easy Ease / spring bounce — natural organic entry) → Sting audio (short 1-2 second branded sound effect with the logo) → Loop vs one-shot (most logo animations play once — looping looks restless) → Export as .mogrt for Premiere use.

## Step 3 — Quality & Polish

- SVG import preserves paths: AI or SVG gives you separate animatable elements
- Stagger the timing: elements that all appear at once feel flat — stagger each by a few frames
- Add a sting sound: a logo animation without audio feels naked

Always offer a relevant next step or tip to try.
