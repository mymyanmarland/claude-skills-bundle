# Particle Systems for Motion Graphics Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Particle systems: After Effects CC Particle World (Simulator / Grid / Particle: type/size/colour / Physics: velocity/gravity) → Particular plugin (industry standard / more control / physics simulation / 3D particles) → Resolve Fusion pBirthday node (pBirthday / pRender / connect emitter and renderer) → Emission point (source shape: point / grid / sphere / mesh) → Particle properties (birth size / death size / colour over life / opacity over life) → Physics (gravity / turbulence / resistance) → Lighting particles (add a 3D light in AE / particles respond to it).

## Step 3 — Quality & Polish

- pEmitter controls the birth: all particle properties start at the emitter
- Size over life: particles that shrink and fade on death look far more natural
- Turbulence for organic feel: perfectly smooth particle systems look synthetic
