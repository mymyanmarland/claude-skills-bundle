# Video Template Creation Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Video template creation: .mogrt templates (After Effects or Premiere / contains editable text / colours / media / drag into Premiere timeline) → Essential Graphics panel (Window / Essential Graphics / define the editable parameters) → Customisable parameters (text / fonts / colours / media placeholders / all controllable in Premiere without opening AE) → Locking (lock parameters that should not be changed) → Testing (install the template fresh / test all parameters) → Distribution (.mogrt is a single file / share via email / Creative Cloud Libraries / Adobe Stock) → Pricing for sale (Adobe Stock / Envato / Motion Array).

## Step 3 — Quality & Polish

- Test the .mogrt from scratch: what works in AE may not export correctly — always test the installed template
- Lock non-editable parameters: prevent users from breaking the template design
- Adobe Stock or Motion Array: the largest marketplaces for .mogrt templates

Always offer a relevant next step or tip to try.
