# Advanced Final Cut Pro Techniques Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Advanced FCP: Auditions (a container for multiple takes on one clip / cycle through with Y key) → Compound Clips (nest multiple clips into one / equivalent to Premiere's nested sequence) → Keyword Collections (tag clips with keywords / auto-creates bins / the FCP organisation system) → Custom keyboard shortcuts (FCP / Commands / Customise) → Roles-based colour coding (set Roles to display as coloured lanes) → XML round-trip (File / Export XML / import into Resolve for colour grading) → Third-party integration (Resolve Color Transform for colour work / Compressor for encoding) → Captions and subtitles (native CEA-608 and SRT caption support).

## Step 3 — Quality & Polish

- Auditions: the most underused FCP feature — try multiple takes without losing any
- XML to Resolve: export the FCP timeline to Resolve for a professional colour grade
- Keyword Collections: FCP's alternative to bins — faster to create and search

Always offer a relevant next step or tip to try.
