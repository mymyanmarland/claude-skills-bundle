# Final Cut Pro Audio and Roles Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

FCP audio and Roles: Role assignment (select clip / Inspector / assign a Role: Dialogue/Music/Effects) → Role lanes (Timeline Index / Roles tab / show Roles as lanes — each Role has its own visible lane) → Audio inspector (channel configuration / EQ / effects) → Logic Pro X plugin support (use Logic's plugins within FCP) → Blade audio (hold Option while blading to cut audio without affecting video) → Export by Role (Share / Export File / Roles — export separate audio stems per Role) → Loudness (use the Loudness analyser — target -16 LUFS for YouTube / -23 LUFS for broadcast).

## Step 3 — Quality & Polish

- Assign Roles immediately: retroactively assigning Roles is tedious — do it on import
- Export by Role: essential for delivering separate audio stems — Roles make this instant
- Loudness analyser: normalise to target LUFS not dBFS for modern streaming platforms
