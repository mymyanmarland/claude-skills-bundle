# Final Cut Pro Effects and Transitions Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

FCP effects and transitions: Effects browser (Cmd-5 / drag effect to clip) → Transitions (Cmd-4 / drag to cut point / double-click to customise) → Precision Editor (double-click a cut point — shows the handles and transition handles) → Effect presets (save an effect configuration as a preset / share across projects) → Motion template effects (.moef / .motr files from Motion — add to Effects browser) → Built-in titles (drag from Titles browser) → Adjustment layers (a clip above all others with effects applied to it — FCP workaround: use a white generator set to 0% opacity with effects).

## Step 3 — Quality & Polish

- Precision Editor: the most powerful trim tool in FCP — double-click any cut
- Motion templates: extend FCP's capabilities significantly — the App Store has many
- Adjustment layer workaround: FCP lacks native adjustment layers — use the generator method
