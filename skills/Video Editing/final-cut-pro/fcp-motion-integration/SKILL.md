# Final Cut Pro and Motion Integration Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

FCP and Motion: Template types (Titles / Effects / Transitions / Generators — each published differently in Motion) → Publishing parameters (in Motion: select a parameter / Object / Publish — makes it editable in FCP) → Title template workflow (Motion: File / New / Title / design and publish) → Rig controls (sliders and checkboxes that control multiple parameters at once) → Final Cut Generator (animated backgrounds and textures) → Saving and sharing templates (.motr / .moef files in Motion Templates folder) → Template update (edit in Motion / save — FCP reflects the update immediately).

## Step 3 — Quality & Polish

- Publish parameters: anything not published cannot be edited in FCP — publish what the editor needs
- Rig controls simplify complex templates: one slider controls multiple parameters simultaneously
- Motion Templates folder: ~/Movies/Motion Templates — the location FCP reads from
