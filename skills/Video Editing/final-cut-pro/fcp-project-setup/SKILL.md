# Final Cut Pro Project Setup Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

FCP project setup: Library (the top-level container — one per project or client) → Event (a container within the library — store footage by date or subject) → Project (the timeline — one or more per event) → Library storage (store media inside or outside the library — external preferred for large projects) → Optimised media (transcode for smooth playback) → Proxy media (lower-resolution copy for laptop editing) → Background rendering (FCP renders automatically — disable if it slows the system) → Roles (FCP's track equivalent — assign Dialogue / Music / Effects for organised export).

## Step 3 — Quality & Polish

- Library per client: keeps projects completely separate and easy to archive
- External media storage: media inside the library creates a large unmanageable file
- Roles instead of tracks: assign roles to every clip from the start — export relies on them
