# Final Cut Pro Performance Optimisation Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

FCP optimisation: Background rendering (turn off during editing / on during breaks) → Optimised and proxy media (create at import for high-res footage) → Render Selection (select clips / Control-R — renders only selected clips) → Cache management (FCP Preferences / Advanced / clearing the render cache) → Libraries on fast storage (NVMe drive for media — not network or slow HDD) → Playback Quality (Viewer / Playback Quality — reduce to Better Performance during editing) → GPU usage (FCP is highly optimised for Apple Silicon — M-series Macs are dramatically faster).

## Step 3 — Quality & Polish

- Turn off background rendering while editing: it competes for resources
- Proxy media for laptops: editing raw 4K on a MacBook Air requires proxies
- Apple Silicon advantage: FCP on M-series Macs is significantly faster than any other platform
