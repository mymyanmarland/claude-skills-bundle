# Transitions and Effects in Premiere Pro Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Transitions and effects: Transitions (drag from Effects panel to cut point / default duration 1 second / adjust in Effect Controls) → Default transition shortcut (Ctrl/Cmd D applies default transition) → Cross Dissolve (the most appropriate general transition) → Transition principles (most cuts need no transition / use transitions sparingly and purposefully) → Video Effects (drag to clip or adjustment layer / adjust in Effect Controls) → Masking effects (oval / 4-point polygon / free draw masks in Effect Controls) → Preset effects (save frequently used effect settings as presets).

## Step 3 — Quality & Polish

- Most cuts need no transition: cuts are more powerful than dissolves in most contexts
- Ctrl/Cmd D for default transition: fastest way to add a transition
- Save effect presets: reuse complex effect settings across projects
