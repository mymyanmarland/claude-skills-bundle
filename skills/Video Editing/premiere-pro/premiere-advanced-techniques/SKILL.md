# Advanced Premiere Pro Techniques Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Advanced techniques: Nested sequences (group clips into a sub-sequence / apply effects to the whole group / edit inside by double-clicking) → Dynamic Link (send a sequence to After Effects without rendering / changes reflect immediately) → Replace with After Effects Composition (right-click clip / Replace with After Effects Comp) → Track Mattes (Luma or Alpha Matte key — reveal one clip through the shape of another) → Speed Ramp (right-click clip / Show Clip Keyframes / Time Remapping / Speed) → Warp Stabiliser (drag to a shaky clip — but does not fix extremely shaky footage) → Stacked Adjustments (multiple adjustment layers for a complex grade).

## Step 3 — Quality & Polish

- Nest before applying effects to a group: effects on nested sequences apply to all clips inside
- Dynamic Link: the most powerful Premiere-After Effects workflow — no render needed
- Speed Ramp handles: the yellow handle in the timeline controls the ramp speed
