# Premiere Pro Project Setup Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Project setup: New project (name / location on fast drive — not C: for media) → Sequence settings (match camera settings: frame rate / resolution / codec — use 'New Sequence from Clip' for auto-match) → Scratch disks (set previews and cache to a separate fast drive) → Ingest settings (proxy workflow: enable proxies for smoother editing of 4K) → Bin structure (create bins: footage / audio / graphics / exports / sequences) → Auto-save (set to every 5 minutes minimum) → Sequence naming (descriptive names with version numbers: ProjectName_v01).

## Step 3 — Quality & Polish

- New Sequence from Clip: the most reliable way to match sequence to camera settings
- Scratch disks on a separate fast drive: reduces system drive load significantly
- Auto-save every 5 minutes: Premiere crashes — do not rely on manual saves
