# Multicam Editing in Premiere Pro Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Multicam editing: Create Multicam Sequence (select clips / right-click / Create Multi-Camera Source Sequence / sync by audio) → Enable Multicam (right-click sequence in timeline / Multi-Camera / Enable) → Cut with numpad (1/2/3 keys switch cameras while playing / J/K/L control playback) → Refine multicam cuts (trim the cuts after the live switch session) → Audio follows video (by default: uncheck in settings if using a dedicated audio track) → 8+ cameras (Premiere handles up to unlimited cameras in a multicam sequence).

## Step 3 — Quality & Polish

- Sync by audio: the most reliable sync method when timecode is absent
- Live switching first then refine: do not be precise during the switch session
- Audio follows video: usually disable this if using a dedicated microphone track
