# Premiere Pro Editing Workflow Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Editing workflow: Import (drag to Project panel / or Media Browser for networked drives) → Logging (mark In/Out points in Source monitor / rate clips) → Assembling (drag clips to timeline / or use Insert and Overwrite shortcuts) → Three-point editing (set In/Out in Source / set In on timeline / Insert or Overwrite) → Rough cut (get all footage in order / do not refine yet) → Sync audio (multi-camera or separate recorder: use Merge Clips or Synchronise) → Refine (trim with Ripple Edit / Rolling Edit tools).

## Step 3 — Quality & Polish

- Three-point editing: the fastest and most precise way to assemble a timeline
- Rough cut first: place everything before refining anything
- Ripple Edit tool (B): trims and closes the gap — the most-used trim tool
