# Proxy Workflow in Premiere Pro Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Proxy workflow: Why proxies (lower-resolution copies for smooth editing / link back to full-res for export) → Ingest proxies (project settings / ingest / create proxies during import — H.264 1/4 size recommended) → Manual proxy creation (right-click clip / Proxy / Create Proxies) → Toggle proxies (Proxy button in Program Monitor / or in Timeline settings) → Export with full-res (Premiere automatically reconnects full-res for export regardless of proxy toggle) → GoPro CineForm or Apple ProRes proxies (highest quality proxies for colour work).

## Step 3 — Quality & Polish

- Toggle proxy button in the Program Monitor: add it to the button bar if not visible
- Export always uses full-res: the proxy toggle does not affect the export quality
- ProRes or CineForm proxies for colour work: H.264 proxies are fine for cutting only
