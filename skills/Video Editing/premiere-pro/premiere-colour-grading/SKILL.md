# Colour Grading in Premiere Pro Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Colour grading: Lumetri Colour panel → Basic Correction (exposure / contrast / highlights / shadows / whites / blacks / saturation — fix technical issues first) → Scopes (Waveform for exposure / Vectorscope for saturation / Parade for colour balance — use scopes not your eyes) → White balance (temperature and tint — fix the grey card or skin tones) → Tone curve (S-curve for contrast / individual RGB curves for creative grade) → HSL Secondary (isolate and adjust a specific colour) → Creative LUT (apply a Look for style) → Adjustment layer (apply grade to all clips via one adjustment layer).

## Step 3 — Quality & Polish

- Fix before grade: correct the technical issues before applying any creative grade
- Use scopes not your eyes: monitors are not calibrated — scopes tell the truth
- Adjustment layer for grading: one grade applied to all clips / change once and it updates everywhere
