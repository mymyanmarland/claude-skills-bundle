# Premiere Pro Export Settings Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Export settings: Export media (Ctrl/Cmd M) → Format selection (H.264 for most deliverables / ProRes for archive and broadcast / DNxHR for Avid workflows) → Match Sequence preset (starts with correct resolution and frame rate) → YouTube preset (H.264 / High Bitrate / match sequence settings) → Bitrate settings (VBR 2-pass / Target: 20 Mbps for 1080p / 40 Mbps for 4K) → Audio (AAC 320kbps for most / PCM for broadcast) → Queue to Adobe Media Encoder (export in background while editing continues) → Send multiple sequences to the queue at once.

## Step 3 — Quality & Polish

- Queue to Media Encoder: continue editing while the export runs in the background
- VBR 2-pass: takes longer but produces better quality at smaller file sizes
- H.264 for delivery / ProRes for archive: always keep an uncompressed master
