# After Effects 3D Layers Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

AE 3D layers: Enable 3D (click the 3D switch on any layer — adds Z depth) → Null object (create a null / enable 3D / parent layers to it — move all together) → Camera (Layer / New / Camera — One-Node for orbiting / Two-Node for pan-and-tilt) → Camera types (One Node: orbits the anchor point / Two Node: point of interest always in view) → Lights (Ambient / Directional / Spot / Point — illuminate 3D layers) → Z-space (push layers back on Z to create parallax) → Cinema 4D Lite (included with AE — import 3D objects).

## Step 3 — Quality & Polish

- Parent 3D layers to a null: control multiple layers with one camera rig
- Two-Node camera for orbital shots: the point of interest stays locked while the camera moves
- Z-space parallax: push background layers further back on Z for the parallax effect
