# After Effects Keyframe Animation Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Keyframe animation: Position / Scale / Rotation / Opacity (P / S / R / T shortcuts) → Creating keyframes (click the stopwatch icon to enable / create keyframe at the current time) → Easy Ease (select keyframes / F9 — smooths the motion curve) → Graph Editor (G key — shows the speed or value graph / drag handles to adjust easing) → Motion Path (the dotted line in the Comp panel — edit by dragging handles) → Hold keyframe (right-click / Toggle Hold Keyframe — value snaps instantly) → Time offset expressions (valueAtTime() expression for offset animation).

## Step 3 — Quality & Polish

- Easy Ease all keyframes: linear keyframes always look mechanical
- Graph Editor for polish: Easy Ease is a starting point — the graph is where animation is perfected
- Motion path dots represent speed: crowded dots = slow / spread dots = fast
