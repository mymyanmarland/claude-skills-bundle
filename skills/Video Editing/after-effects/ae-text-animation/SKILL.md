# After Effects Text Animation Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Text animation: Text layers (Horizontal Type tool / T key) → Character and Paragraph panels → Text Animators (the most powerful AE text tool: Add Animator / Range Selector / Offset / Amount) → Animate opacity per character (Animator / Add / Opacity / Range Selector Offset) → Animation presets (Browse Presets / drag onto text layer) → Type-on effect (Opacity Animator / Range Selector Start and End / keyframe End from 0 to 100%) → Animate along a mask path (Text / Path Options / Path) → Animated typeface (Google Fonts in AE via Creative Cloud).

## Step 3 — Quality & Polish

- Text Animators: the most powerful text animation tool — far more flexible than manual keyframing
- Range Selector Offset: animates the property character by character across the text
- Type-on with Opacity Animator: cleaner than masking — the standard type-on technique
