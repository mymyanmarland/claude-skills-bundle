# After Effects Motion Graphics Workflow Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Motion graphics workflow: Essential Graphics panel (create .mogrt template files for Premiere / FCP) → Master Properties (expose composition properties to Premiere without Essential Graphics) → Shared Asset Libraries (Creative Cloud Libraries — share colours and assets) → Reusable compositions (design one element / use across multiple comps) → Colour control rig (a single colour control composition that all other comps reference) → Grid and guide system (View / Show Guides / Title-Action Safe zones) → Null controller layers (expose controls for the client on a single null / hide the complexity).

## Step 3 — Quality & Polish

- Essential Graphics for .mogrt: the bridge between AE motion graphics and Premiere editing
- Colour control composition: change the brand colour in one place and it updates everywhere
- Null controller: a single layer the client can adjust — hide the complex rig behind it
