# After Effects Project Setup Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

AE project setup: New Composition (Ctrl/Cmd-N / match the delivery format: 1920x1080 / 25fps / 1:00 duration) → Composition settings (pixel aspect ratio: square pixels for digital / frame rate match delivery) → Folder structure (Project panel: Comps / Footage / Pre-comps / Renders) → Footage import (Ctrl/Cmd-I / import as footage or composition) → Frame rate (File / Project Settings / match the frame rate) → Colour settings (working space: Rec.709 for broadcast / sRGB for web) → RAM Preview (Spacebar — renders to RAM / preview plays in real time after rendering).

## Step 3 — Quality & Polish

- Match comp settings to delivery: wrong frame rate is the most common AE project error
- Folder structure in the Project panel: unorganised projects become unmanageable quickly
- RAM Preview: press Spacebar to preview — play without rendering uses the already-rendered cache
