# After Effects Shape Layers Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Shape layers: Create shapes (Rectangle / Ellipse / Polygon / Star tools — draw on empty area for shape layer) → Shape layer contents (Group / Path / Fill / Stroke / Transform per group) → Path animations (animate the Path property directly: keyframe two different shapes / AE morphs between them) → Repeater (shape modifier: duplicates the shape and applies a transform offset each time) → Trim Paths (draws on and off a path: add Trim Paths / animate Start and End) → Shape stroke animations (dashes / dash animations) → Convert masks to shapes (right-click mask / Create Shape from Mask).

## Step 3 — Quality & Polish

- Repeater: the most powerful shape layer modifier — creates complex grids and patterns from one shape
- Trim Paths: the standard technique for animated line and path reveals
- Animate Path directly: morph one shape to another by keyframing the Path property
