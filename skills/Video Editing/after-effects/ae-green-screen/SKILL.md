# After Effects Green Screen Keying Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Green screen keying: Keylight (the industry-standard AE keyer: Effect / Keying / Keylight) → Screen Colour (eyedropper on the green background) → Screen Balance (adjust until the key is clean) → View: Screen Matte (shows the matte — white = keep / black = remove / grey = problem) → Matte cleaning (Screen Gain / Screen Softness / Clip White and Black to remove grey fringe) → Edge treatment (Keylight + Key Cleaner + Advanced Spill Suppressor — the recommended three-effect stack) → Background integration (match colour temperature and lighting of the new background).

## Step 3 — Quality & Polish

- Screen Matte view first: fix the matte before compositing — work with feedback
- Three-effect stack: Keylight + Key Cleaner + Advanced Spill Suppressor for clean results
- Match the background lighting: the key is technically clean but looks wrong if the light direction differs
