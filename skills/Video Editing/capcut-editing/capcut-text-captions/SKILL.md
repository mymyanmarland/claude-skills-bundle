# CapCut Text and Auto-Captions Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

CapCut text and captions: Text tool (tap Text in toolbar / type / style / position / animate) → Auto Captions (Text / Auto Captions / language / generate — AI transcribes speech to captions) → Caption editing (tap any caption / edit the text or timing) → Caption style (select all captions / apply a style: font / size / colour / background) → Animated text (Text / Animations / choose an animation) → Text templates (ready-made animated text styles in the Effects tab) → Multi-language captions (generate captions in a different language from the spoken audio).

## Step 3 — Quality & Polish

- Auto Captions saves hours: the AI transcription is very accurate for clear speech
- Edit captions individually: auto-captions always have a few errors — review each one
- Caption style applied to all: select all captions before styling for consistency
