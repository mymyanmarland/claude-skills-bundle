# CapCut Colour Grading Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

CapCut colour grading: Adjustments (select clip / Adjust / sliders: Brightness / Contrast / Saturation / Warmth / Tint / Sharpen / Highlight / Shadow) → LUTs (Filters / Custom / import a .cube LUT file) → HSL (Adjust / HSL / adjust individual colour hues, saturation, and luminance) → Curves (Adjust / Curves / RGB and individual colour curves) → Vignette (Adjust / Vignette / add a dark edge for a cinematic feel) → Apply to all clips (select adjustment / tap Apply to All) → Comparison (tap and hold the viewer to see the before state).

## Step 3 — Quality & Polish

- Adjust before filter: correct the exposure before applying a stylistic filter
- Apply to All for consistency: grade one clip perfectly then apply to every clip
- Tap and hold to compare: the most intuitive before/after comparison in mobile editing
