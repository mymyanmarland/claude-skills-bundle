# CapCut Advanced Features Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

CapCut advanced: CapCut Desktop (more powerful than mobile / multi-track timeline / more precision) → Keyframe animation (select element / add a keyframe at the start / move forward / change the property / second keyframe created automatically) → AI tools (AI text to video / AI image generation / AI video effects) → Multi-layer overlay (build up complex composites with multiple overlay tracks) → Mask overlay (draw a mask on an overlay layer to reveal it through a shape) → Collaboration (share a project link / collaborator edits in CapCut Web).

## Step 3 — Quality & Polish

- CapCut Desktop for complex edits: the desktop version is significantly more capable
- Keyframe any property: position / scale / rotation / opacity all support keyframes
- AI tools are genuinely useful: text-to-video and AI effects save significant production time
