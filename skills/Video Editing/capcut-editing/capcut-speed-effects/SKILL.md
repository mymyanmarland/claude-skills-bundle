# CapCut Speed Effects Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

CapCut speed effects: Constant speed (select clip / Speed / Normal / drag slider) → Curve speed (Speed / Curve / choose a preset: Montage / Hero / Bullet / Flash) → Custom curve (Speed / Curve / Custom / add handles and drag) → Freeze frame (at the playhead / Speed / Freeze Frame — holds one frame) → Reverse (Speed / Reverse — plays the clip backward) → AI slow motion (120fps clips slow down better than 30fps / CapCut can interpolate frames for slow motion) → Beat-sync with speed ramp (combine Auto Beat Sync with curve speed for viral edits).

## Step 3 — Quality & Polish

- Curve speed for cinematic ramps: the Hero and Bullet presets are the most popular for social media
- Freeze frame at the peak action: the most effective dramatic speed technique
- 60fps minimum for slow motion: 30fps slow motion looks choppy — shoot higher frame rates
