# CapCut Basics Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

CapCut basics: Interface (Projects / Edit / Timeline / Toolbar) → Import media (tap the + button / select from gallery or stock) → Timeline editing (tap clip to select / drag handles to trim / tap and hold to reorder) → Split (split at playhead / or tap Split in the toolbar) → Delete (select clip / delete) → Undo (two-finger tap or back arrow) → Preview (tap the play button) → Save / Export (export button top right / select resolution and frame rate) → Projects are auto-saved to the app.

## Step 3 — Quality & Polish

- Two-finger tap to undo: the fastest undo method on mobile
- Trim by dragging handles: the most intuitive mobile editing method
- Export at 1080p 30fps for most social media: the universal delivery standard
