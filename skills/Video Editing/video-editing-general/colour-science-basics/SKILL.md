# Colour Science for Video Editors Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Colour science: Colour spaces (Rec.709 is standard HD / Rec.2020 is HDR / P3 is cinema) → Log footage (camera records log to retain dynamic range — S-Log / Log C / BRAW) → LUTs (Look Up Tables: technical LUTs convert log to Rec.709 / creative LUTs apply a grade) → Creative LUT vs Technical LUT (always apply technical first) → ACES (Academy Colour Encoding System — universal colour management pipeline) → HDR delivery (HLG / HDR10 / Dolby Vision — different formats) → Why log footage looks grey (it is not corrected yet — do not panic).

## Step 3 — Quality & Polish

- Technical LUT first: a creative LUT on log footage looks completely wrong
- Log footage always looks grey: it has not been converted — this is correct
- LUTs are starting points: never deliver a LUT-only grade — tweak for each clip
