# Video Compression and Codecs Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Video compression and codecs: Container vs codec (container: .mp4 .mov .mxf — the wrapper / codec: H.264 / ProRes / HEVC — the compression algorithm inside) → Acquisition codecs (ProRes / BRAW / ARRI RAW — high quality / large files for editing) → Delivery codecs (H.264 / H.265 HEVC — compressed for delivery) → Bitrate (Mbps: higher = better quality / larger file size) → Variable vs constant bitrate (VBR: more efficient / CBR: more consistent) → Lossless vs lossy (ProRes is visually lossless / H.264 is lossy) → 10-bit vs 8-bit (10-bit has more colour information — better for grading).

## Step 3 — Quality & Polish

- Container vs codec: the .mp4 is the box / H.264 is the actual compression — they are different things
- 10-bit for grading: 8-bit footage banding is visible in heavy grades
- ProRes for editing / H.264 for delivery: never edit in H.264 if you can avoid it
