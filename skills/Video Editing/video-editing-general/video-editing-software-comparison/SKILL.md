# Video Editing Software Comparison Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Software comparison: DaVinci Resolve (free version / best colour grading / Windows Mac Linux / one-time Studio purchase) → Premiere Pro (subscription / best integration with Adobe CC / industry standard for broadcast and film) → Final Cut Pro (Mac only / one-time purchase / best performance on Mac / no subscription) → CapCut (free / mobile and desktop / best for social media) → iMovie (free with Mac/iPhone / beginner-friendly / limited features) → Shotcut (free / open source / all platforms) → Choosing by workflow (YouTube: FCP or Resolve / Social media: CapCut / Broadcast: Premiere / Colourist: Resolve / Beginner: CapCut or iMovie).

## Step 3 — Quality & Polish

- DaVinci Resolve free for beginners: professional-grade and free — no reason not to start here
- Final Cut for Mac users: the fastest export and playback on Apple Silicon
- CapCut for social media: purpose-built for the formats and features social media requires

Always offer a relevant next step or tip to try.
