# HDR Video Grading Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

HDR grading: HDR formats (HDR10: static metadata / HLG: broadcast compatible / Dolby Vision: dynamic metadata / HDR10+: dynamic) → Nits and stops (HDR displays up to 1000-4000 nits / SDR: 100 nits) → Grading for HDR (do not clip highlights — HDR can retain them) → HDR monitoring (requires an HDR-capable display to grade HDR accurately) → Trim passes (grade SDR first / create an HDR trim pass to adjust for the HDR range) → Resolve Studio for Dolby Vision (only Resolve Studio can deliver Dolby Vision) → Cross-grade checking (verify the SDR down-conversion looks correct on SDR displays).

## Step 3 — Quality & Polish

- Do not clip HDR highlights: the extra dynamic range is the entire point of HDR
- HDR monitor required for accurate HDR grading: grading HDR on SDR display is guesswork
- Dolby Vision needs Resolve Studio: the free version cannot deliver Dolby Vision
