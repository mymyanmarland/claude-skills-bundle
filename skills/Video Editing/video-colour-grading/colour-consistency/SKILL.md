# Maintaining Colour Consistency Skill

## Step 1 — Gather Inputs

- Software version and platform (Windows/Mac)
- Experience level: beginner/intermediate/advanced
- Type of project: social media/film/documentary/YouTube/corporate
- Specific task or technique
- Output format or delivery requirement

## Step 2 — Core Output

Colour consistency: Remote Grades (Resolve: one grade node applied to multiple clips / change one and all update) → Shared Nodes / Group Grade (apply a grade to all clips in a group / the pre-clip group node) → Reference stills (save a still from the graded reference clip / compare any clip to the reference) → Versions (save alternative grades as versions — non-destructive) → Power Bins (share grade presets across projects in Resolve) → Scene-by-scene reference (watch every scene back-to-back / adjust anything that breaks the consistency) → Client approval before delivery (agree on one reference clip / match everything to it).

## Step 3 — Quality & Polish

- Group pre-clip grade: the most efficient consistency tool — one change updates every clip
- Reference stills: the colour correction safety net — compare everything to the approved reference
- Client approval before delivering: discovering a colour issue after delivery is very expensive
