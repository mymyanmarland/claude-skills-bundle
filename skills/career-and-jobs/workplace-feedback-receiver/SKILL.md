# Workplace Feedback Receiver Skill

## Step 1 — Gather Inputs

- Type of feedback received
- Source (manager/peer/360)
- Emotional reaction
- What to do with it
- Context of feedback

## Step 2 — Core Output

Feedback reception guide: In-the-moment script (how to respond when feedback lands) → Processing framework (separate the sting from the signal) → Clarification questions (what to ask to get actionable specifics) → Decision framework (what to act on vs what to weigh differently) → Response to manager → Action plan from feedback → Follow-up to close the loop.

## Step 3 — Quality & Polish

- In-the-moment script keeps professional composure
- Processing separates emotion from information
- Action plan closes the loop — not just 'thanks for the feedback'

Always offer a relevant next step.
