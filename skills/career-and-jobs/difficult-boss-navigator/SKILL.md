# Difficult Boss Navigator Skill

## Step 1 — Gather Inputs

- Specific manager behavior
- Impact on work
- Options available (transfer/stay/leave)
- Duration of the situation
- What's been tried

## Step 2 — Core Output

Navigation guide: Diagnosis (difficult type: micromanager/credit-stealer/checked-out/volatile) → Strategies specific to type → Managing up tactics → Documentation protocol (when and how) → Escalation decision tree → Building a protection network → The stay/go decision framework → Exit strategy if needed. Realistic — not all situations are fixable.

## Step 3 — Quality & Polish

- Strategies specific to manager type — not generic
- Documentation protocol included — protects the employee
- Stay/go decision framework honest about when leaving is right

Always offer a relevant next step.
