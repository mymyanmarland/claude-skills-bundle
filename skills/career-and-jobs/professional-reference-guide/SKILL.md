# Professional Reference Guide Skill

## Step 1 — Gather Inputs

- Work history and relationships
- Target roles
- Reference availability
- Sensitive situations (fired, gap, pivot)
- Number of references needed

## Step 2 — Core Output

Reference strategy: Who to ask (hierarchy: manager > peer > report > client > vendor) → How to ask (email template) → How to prepare them (brief them fully) → Reference preparation guide (what to tell each reference about the role) → Reference list format → What to do if a reference might be negative → Managing the 'call your current employer' risk.

## Step 3 — Quality & Polish

- Reference brief specific to each role applied for
- Negative reference risk addressed explicitly
- Ask-email professional and makes it easy for them to say yes

Always offer a relevant next step.
