# Networking Event Script Skill

## Step 1 — Gather Inputs

- Event type (industry conference/mixer/alumni)
- Networking goal
- Current comfort level
- Target connections
- Follow-up plan

## Step 2 — Core Output

Networking toolkit: Pre-event preparation (research attendees, set 3 connection goal, prepare talking points) → Opening lines (5 openers that aren't 'so what do you do') → Conversation deepeners → Graceful exit lines → Business card/LinkedIn exchange scripts → Same-day follow-up message → 48-hour follow-up email. Introvert-friendly strategies emphasized.

## Step 3 — Quality & Polish

- Openers create genuine conversation — not transactional
- Exit lines graceful — not awkward
- Follow-up specific to the actual conversation

Always offer a relevant next step.
