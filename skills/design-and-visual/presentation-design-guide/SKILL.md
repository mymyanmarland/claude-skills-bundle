# Presentation Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Presentation design: One idea per slide rule → Visual hierarchy through size and contrast → The 10/20/30 rule (10 slides/20 min/30pt font minimum) → Photography vs illustrations vs icons → Data visualization in slides → Color psychology for presentations → Animation: when to use and when to avoid → Slide templates vs custom design → The deck without the presenter test.

## Step 3 — Quality & Polish

- One idea per slide — foundational principle
- 30pt font minimum — forces simplicity
- The deck without presenter test — standalone value

Always offer a relevant next step.
