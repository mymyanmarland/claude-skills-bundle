# Icon Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Icon design: Icon style selection (line/filled/duotone/flat) → Size and weight consistency → Optical weight balancing → Negative space use → Grid system for icons → Pixel-perfect at small sizes → Meaning clarity (icon should be understood without label) → Icon family coherence → Export sizes (16/24/32/48px and SVG) → Icon libraries and when to use existing vs custom.

## Step 3 — Quality & Polish

- Optical weight balancing — makes set feel coherent
- Meaning clarity test — show to someone unfamiliar
- SVG export — scalable without quality loss

Always offer a relevant next step.
