# Email Template Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Email design: Email-safe fonts (limited set that renders everywhere) → Single column vs multi-column (mobile consideration) → Image-to-text ratio → Alt text for images (emails often load images off) → CTA button design and placement → Header and footer design → Brand color application in email → Preview text as design element → Dark mode compatibility → A/B testing email design elements.

## Step 3 — Quality & Polish

- Single column for mobile — most emails read on phone
- Alt text required — images often blocked
- Dark mode compatibility — growing audience

Always offer a relevant next step.
