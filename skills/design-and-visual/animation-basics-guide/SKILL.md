# Animation and Motion Design Basics Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Animation basics: The 12 principles of animation (Disney) applied to UI and social → Timing and easing (the difference between mechanical and natural) → When animation adds value vs distracts → After Effects vs Canva vs CSS animation → Micro-animation in UI → Social media animation formats (GIF/MP4/Lottie) → Loop design → File size optimization for animated content.

## Step 3 — Quality & Polish

- Timing and easing — the most impactful principle
- When to use — purposeful animation only
- Loop design — most social animation is looped

Always offer a relevant next step.
