# Newsletter Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Newsletter design: Single column layout default (works everywhere) → Header design (brand recognition in first scroll) → Section hierarchy (clear visual breaks between topics) → CTA placement and design → Image use in email (accessibility and loading) → Footer design (required elements) → Plain text version design → Mobile preview priority → Testing across email clients.

## Step 3 — Quality & Polish

- Single column layout — renders correctly across clients
- Image loading consideration — design without images test
- Mobile preview — majority of readers on phone

Always offer a relevant next step.
