# Logo Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Logo design: Logo types (wordmark/lettermark/icon/combination/emblem) → Design principles for logos (simple/memorable/versatile/timeless/appropriate) → Sketch and concept phase → Color and monochrome versions → Scalability testing → File format requirements (SVG/PNG/EPS) → Logo misuse guidelines → Competitor differentiation → When to hire a designer vs DIY tools.

## Step 3 — Quality & Polish

- Five good logo principles with specific examples
- Monochrome version requirement — versatility test
- File formats specific — SVG for scalability

Always offer a relevant next step.
