# Design Tools Comparison Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Design tools comparison: By task type (UI design/print/social/illustration/photo editing) → Figma (UI/UX, collaboration) → Adobe Creative Suite (industry standard, complex) → Canva (accessibility, speed) → Sketch (Mac-only UI) → Affinity (one-time purchase Adobe alternative) → Procreate (iPad illustration) → Free vs paid decision → Learning curve investment → Team collaboration needs.

## Step 3 — Quality & Polish

- Task-type matching — no single tool wins all categories
- Learning curve vs feature trade-off honest
- Free alternatives highlighted — Canva and Affinity

Always offer a relevant next step.
