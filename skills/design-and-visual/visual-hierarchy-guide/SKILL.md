# Visual Hierarchy Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Visual hierarchy: Size contrast (largest element gets attention first) → Color contrast for emphasis → Weight and boldness → Proximity and grouping → White space as hierarchy tool → F-pattern and Z-pattern reading behavior → The three-level hierarchy (primary/secondary/tertiary) → Breaking hierarchy intentionally (when to create surprise) → Hierarchy audit checklist.

## Step 3 — Quality & Polish

- Three-level hierarchy applied to actual work
- White space as active element — not just empty space
- F-pattern reading behavior — eye tracking research applied

Always offer a relevant next step.
