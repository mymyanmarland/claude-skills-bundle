# Design System Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Design system: What it includes (tokens/components/patterns/guidelines) → Design tokens (colors/spacing/typography as variables) → Component library structure → Documentation standards → Version control for design systems → Handoff to developers → Governance (who owns what) → When to build vs use an existing system → Figma component organization.

## Step 3 — Quality & Polish

- Design tokens as foundation — enables global updates
- Documentation makes it usable not just existing
- Governance prevents system fragmentation

Always offer a relevant next step.
