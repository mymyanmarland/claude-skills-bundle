# Mood Board Creation Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Mood board guide: Purpose definition (what decision does this inform?) → Image curation (20-30 images, curate down to 10-15) → Color extraction from mood board → Texture and material direction → Typography mood signals → Sources (Pinterest/Unsplash/Dribbble/physical magazine) → Client presentation mood board vs internal reference → Mood board as brief translation → Iterating based on feedback.

## Step 3 — Quality & Polish

- Purpose definition first — mood board serves a decision
- Curate down — too many images dilutes direction
- Color extraction — mood board informs palette

Always offer a relevant next step.
