# Color Theory Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Color theory: Color wheel and relationships (complementary/analogous/triadic/split-complementary) → Color psychology (what each color communicates) → Warm vs cool color dynamics → Tint, shade, tone → Saturation and value → Creating harmony vs contrast → Brand color selection framework → Accessibility (contrast ratios for readability) → Building a 5-color palette.

## Step 3 — Quality & Polish

- Color psychology specific — not just listing colors
- Accessibility contrast ratios — often overlooked
- 5-color palette framework practical for any project

Always offer a relevant next step.
