# Dark Mode Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Dark mode design: Not just inverting colors (common mistake) → Elevation through light (dark UI uses lighter colors for higher layers) → Color palette adaptation (vibrant colors on dark backgrounds) → Image adaptation (avoid pure black backgrounds with photos) → Icon and illustration for dark → Text contrast on dark → Testing dark mode designs → CSS custom properties for theming → User preference detection.

## Step 3 — Quality & Polish

- Not inverting colors — the fundamental error to avoid
- Elevation principle — explains dark mode hierarchy
- Testing both modes — do not design for one only

Always offer a relevant next step.
