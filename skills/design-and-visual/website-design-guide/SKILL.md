# Website Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Website design: Above-the-fold design (what visitors see first) → Visual hierarchy for conversion → Navigation design (7 items or fewer) → Call-to-action button design and placement → White space as design element → Mobile responsiveness priorities → Page speed visual considerations → Trust signals placement → Hero section formula → Form design best practices.

## Step 3 — Quality & Polish

- Above-the-fold — most valuable real estate
- Navigation under 7 items — cognitive load principle
- Mobile-first actual application

Always offer a relevant next step.
