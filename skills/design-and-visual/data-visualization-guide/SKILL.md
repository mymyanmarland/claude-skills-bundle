# Data Visualization Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Data visualization: Chart type selection guide (bar/line/pie/scatter/heatmap — when each works) → Lie factor avoidance (how charts deceive) → Color in data viz (sequential/diverging/categorical palettes) → Annotation and labeling → Reducing chart junk → The message-first approach (what do you want the viewer to conclude?) → Accessibility in charts → Interactive vs static decision → Story with data principles.

## Step 3 — Quality & Polish

- Chart type selection — the most common confusion
- Lie factor — how to not deceive and how to spot deception
- Message-first approach — conclusion before chart

Always offer a relevant next step.
