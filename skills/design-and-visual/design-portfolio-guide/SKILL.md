# Design Portfolio Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Design portfolio: Case study format (problem/process/solution/result) → Work selection (5-8 pieces, quality over quantity) → Process documentation (show thinking not just output) → Portfolio platform options (Behance/Dribbble/personal site) → About page for designers → Password protection for NDA work → Tailoring portfolio to opportunity → Presentation portfolio vs online portfolio → Keeping it updated.

## Step 3 — Quality & Polish

- Case study format — shows thinking process
- 5-8 pieces max — fewer stronger pieces
- Process documentation — differentiates from junior designers

Always offer a relevant next step.
