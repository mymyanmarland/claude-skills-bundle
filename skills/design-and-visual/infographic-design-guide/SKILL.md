# Infographic Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Infographic design: Information hierarchy (most important visually dominant) → Layout types (vertical/horizontal/comparison/timeline/process) → Icon selection and consistency → Data visualization types (when to use bar/line/pie/bubble) → Color coding for clarity → Typography in infographics (limited, large, scannable) → The 30-second test (can key message be absorbed in 30 seconds?) → Dimensions and export for different platforms.

## Step 3 — Quality & Polish

- 30-second test — the most important quality check
- Information hierarchy visualized not just listed
- Data visualization type selection guide

Always offer a relevant next step.
