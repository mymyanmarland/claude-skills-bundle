# Pattern and Texture Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Pattern design: Pattern types (seamless repeat/half-drop/brick/diamond) → Motif design and refinement → Scale and color variations → Creating seamless repeat in design software → Pattern as brand element → Digital vs physical applications → Pattern licensing and selling basics → Trend awareness vs timeless design → Testing at different scales.

## Step 3 — Quality & Polish

- Seamless repeat technical process
- Scale testing — patterns often designed too large or small
- Brand pattern as recognition element

Always offer a relevant next step.
