# Responsive Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Responsive design: Mobile-first philosophy (design smallest first) → Breakpoints (common: 320/768/1024/1440px) → Fluid grids and flexible images → Typography scaling → Navigation patterns for mobile (hamburger vs bottom nav) → Touch target sizes (minimum 44x44px) → Content prioritization by screen size → Testing responsive designs → Common responsive design failures.

## Step 3 — Quality & Polish

- Mobile-first — not afterthought adaptation
- 44px touch target — specific and testable
- Content prioritization — what to show/hide at each breakpoint

Always offer a relevant next step.
