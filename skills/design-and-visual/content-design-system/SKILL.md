# Content Design System Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Content design system: Content inventory (all content types produced) → Template creation per type → Brand element library (logos/colors/fonts ready to use) → Template governance (who can edit what) → Naming and organization system → Version control for templates → Content batching efficiency → Onboarding new creators to the system → System refresh cadence.

## Step 3 — Quality & Polish

- Template per content type — not one template for all
- Governance prevents drift from brand
- Batching efficiency — the business case for the system

Always offer a relevant next step.
