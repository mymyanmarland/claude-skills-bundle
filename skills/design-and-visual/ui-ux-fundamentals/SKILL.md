# UI/UX Fundamentals Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

UI/UX fundamentals: UX vs UI distinction (experience vs interface) → User-centered design process → Information architecture basics → Wireframing and prototyping → Visual hierarchy in UI → Gestalt principles applied to interface design → Common UI patterns and why they work → Accessibility in UI (WCAG basics) → Usability testing basics → Mobile-first design approach.

## Step 3 — Quality & Polish

- UX vs UI distinction — commonly confused
- Gestalt principles applied practically
- Accessibility WCAG basics — legal and ethical requirement

Always offer a relevant next step.
