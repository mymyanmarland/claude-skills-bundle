# Design for Accessibility Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Accessibility design: WCAG 2.1 AA overview (legal and ethical standard) → Color contrast ratios (4.5:1 text, 3:1 large text) → Alt text principles → Focus state design → Form design accessibility → Motion and animation accessibility → Touch target sizing → Screen reader compatible design → Keyboard navigation design → Testing with users who have disabilities.

## Step 3 — Quality & Polish

- WCAG levels specific — AA is the target
- Color contrast tool usage specific
- Testing with actual users — not just automated tools

Always offer a relevant next step.
