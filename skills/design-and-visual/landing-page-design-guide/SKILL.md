# Landing Page Design Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Landing page design: Hero section formula (headline + subheadline + CTA + visual) → Visual flow toward conversion → Benefit visualization (show the transformation) → Social proof placement → Objection-addressing visual elements → CTA button best practices (color/size/copy/placement) → Mobile landing page considerations → Page length decision (short vs long) → Loading speed visual impact.

## Step 3 — Quality & Polish

- Hero section formula specific
- Social proof placement — where in the visual flow
- CTA button — every element supported by research

Always offer a relevant next step.
