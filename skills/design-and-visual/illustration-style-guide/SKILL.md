# Illustration Style Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Illustration guide: Style reference collection (build a visual mood board) → Line weight consistency → Color palette limitation (3-5 colors maximum) → Character proportion and anatomy → Scene composition → Texture and fill approaches → Digital vs hand-drawn hybrid → Style sheet creation → Application across formats → Style evolution vs consistency balance.

## Step 3 — Quality & Polish

- Style sheet creation — forces consistency
- Color palette limitation — too many breaks style
- Reference collection process — how to develop taste

Always offer a relevant next step.
