# Typography Guide Skill

## Step 1 — Gather Inputs

- Design context and purpose
- Target audience and platform
- Brand guidelines or style preferences
- Available tools and skill level
- Specific design challenge or goal

## Step 2 — Core Output

Typography guide: Type anatomy (baseline/x-height/ascender/descender) → Serif vs sans-serif distinction and usage → Type classification (oldstyle/transitional/modern/geometric) → Font pairing principles (contrast and harmony) → Hierarchy through type (size/weight/style) → Line length and leading → Kerning and tracking → Web-safe fonts and Google Fonts → Type in motion basics.

## Step 3 — Quality & Polish

- Type hierarchy specific — most beginners get this wrong
- Font pairing principles with examples
- Line length and leading — readability fundamentals

Always offer a relevant next step.
