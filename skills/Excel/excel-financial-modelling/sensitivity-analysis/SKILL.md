# Sensitivity Analysis in Excel Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Sensitivity analysis: One-variable data table (Data / What-If / Data Table / Row input cell or Column input cell) → Two-variable data table (both row and column input cells / shows a matrix of outputs) → Tornado chart (ranks the impact of each assumption / the most impactful at the top) → Scenario Manager (save multiple sets of input values / generate a summary) → Monte Carlo (random inputs via RAND / run many iterations — requires VBA or specialist tools) → Output selection (test the one or two outputs that matter most: Enterprise Value / IRR / Net Income) → Assumption labelling (label every assumption clearly on the sensitivity table).

## Step 3 — Quality & Polish

- Two-variable data table: the standard financial model sensitivity output — WACC vs growth rate
- Tornado chart for assumption ranking: shows which inputs most affect the output
- Label all sensitivity assumptions: an unlabelled sensitivity table is unreadable
