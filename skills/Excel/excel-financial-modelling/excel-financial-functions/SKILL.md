# Excel Financial Functions Reference Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel financial functions: PV(rate, nper, pmt, [fv]) — present value of a series of payments → FV(rate, nper, pmt, [pv]) — future value → PMT(rate, nper, pv, [fv]) — periodic payment → NPER(rate, pmt, pv) — number of periods → RATE(nper, pmt, pv) — interest rate → EFFECT(nominal_rate, npery) — effective annual rate → NOMINAL(effect_rate, npery) — nominal rate → CUMIPMT(rate, nper, pv, start, end, type) — cumulative interest paid → CUMPRINC — cumulative principal paid → PRICE / YIELD — bond pricing functions.

## Step 3 — Quality & Polish

- FV for savings goal planning: how much will savings be worth at a future date
- EFFECT for comparing loan rates: convert nominal to effective for fair comparison
- CUMIPMT for total interest: how much total interest on a loan over any period
