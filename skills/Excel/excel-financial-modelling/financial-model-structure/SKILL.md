# Financial Model Structure Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Financial model structure: Separate sheets (Inputs / Calculations / Outputs — never mix) → Inputs sheet (all assumptions in one place / clearly labelled / colour-coded: blue font for hard-coded inputs) → Calculations sheet (all working formulas reference the inputs / no hard-coded numbers in calculations) → Outputs sheet (summary results / charts / P&L / Balance Sheet / Cash Flow) → Flow left to right (time flows left to right across columns) → Row labels (consistent labels down column A — period labels across row 1) → Audit trail (every number traceable back to an assumption on the Inputs sheet).

## Step 3 — Quality & Polish

- Blue font for hard-coded inputs: the universal financial modelling convention
- No hard-coded numbers in calculations: every number must trace back to the Inputs sheet
- Separate Inputs / Calculations / Outputs: the three-sheet structure every financial model should follow
