# Excel Collaboration and Sharing Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel collaboration: OneDrive / SharePoint (save to cloud for co-authoring) → Co-authoring (multiple users editing simultaneously / changes merge automatically) → Share settings (share link / Anyone with link / Specific people / Can edit vs Can view) → Comments (Insert / Comment — threaded discussions on cells) → Track Changes (Review / Track Changes — records every edit and who made it) → Workbook protection (Review / Protect Workbook — prevents adding or deleting sheets) → Sheet protection (Review / Protect Sheet / allow specific ranges to be edited by different users) → Version history (OneDrive / Version History — restore any previous version).

## Step 3 — Quality & Polish

- OneDrive for co-authoring: local shared network files do not support modern co-authoring
- Version history on OneDrive: the safety net for collaborative workbooks
- Sheet protection with editable ranges: lock formula cells / unlock input cells for each user

Always offer a relevant next step or tip to try.
