# Sales Reporting in Excel Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Sales reporting: Pipeline (deal name / stage / value / probability / weighted value / close date) → Funnel metrics (conversion rates between stages) → Sales by rep (PivotTable: Rep / Total Sales / Deal Count / Average Deal Size) → Sales vs target (=Actual/Target — conditional formatting for RAG) → Rolling 12-month trend (LINE chart / dynamic named range or Table) → Win/Loss analysis (won vs lost by reason / by rep / by deal size) → Forecast (=Actual YTD + SUMIF of weighted pipeline for remaining months) → Activity metrics (calls / demos / proposals per rep).

## Step 3 — Quality & Polish

- Weighted pipeline: =probability%×deal value — the most important pipeline number
- Rolling 12-month chart: more meaningful than a fixed financial year for identifying trends
- Win/Loss reason analysis: the most actionable sales insight — why deals are lost

Always offer a relevant next step or tip to try.
