# Correlation Analysis in Excel Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level
- Specific task
- Data type
- Intended output

## Step 2 — Core Output

Correlation analysis: CORREL(array1, array2) — returns the Pearson correlation coefficient (-1 to +1) → Interpretation (-1: perfect negative / 0: no relationship / +1: perfect positive) → Correlation matrix (Data Analysis ToolPak / Correlation / select multiple columns / output a full matrix) → Scatter chart (Insert / Scatter — visualise the relationship between two variables) → Correlation vs causation (correlation does not mean causation — never assume it does) → PEARSON(array1, array2) — identical result to CORREL → RSQ(known_ys, known_xs) — returns R² (the square of the correlation).

## Step 3 — Quality & Polish

- Correlation does not mean causation: the most important statistics caveat
- Correlation matrix for multiple variables: instantly shows all pairwise relationships
- Scatter chart alongside CORREL: always visualise as well as calculate
