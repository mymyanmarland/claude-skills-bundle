# Excel for Statistics Resources Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level
- Specific task
- Data type
- Intended output

## Step 2 — Core Output

Excel statistics resources: Analysis ToolPak (the built-in statistics add-in — covers most common tests) → XLSTAT (the most powerful Excel statistics add-in — available free with limited features) → Real Statistics Using Excel (free online resource: real-statistics.com — comprehensive and practical) → Statistics textbooks with Excel examples (Statistics for Excel Users / Excel Data Analysis) → Limitations of Excel for statistics (not designed for statistics / use R or Python for serious analysis) → When to move beyond Excel (large datasets / complex models / reproducibility requirements — use R, Python, or SPSS) → Practice datasets (UCI ML Repository / government open data / Kaggle).

## Step 3 — Quality & Polish

- Real Statistics Using Excel: the most comprehensive free resource for Excel statistics
- XLSTAT for advanced statistics: extends Excel's statistics capability significantly
- Move to R or Python for serious work: Excel statistics is appropriate for exploratory analysis not primary research
