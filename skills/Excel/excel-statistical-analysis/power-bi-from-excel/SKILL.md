# Using Excel Data in Power BI Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level
- Specific task
- Data type
- Intended output

## Step 2 — Core Output

Excel to Power BI: Import Excel data (Power BI Desktop / Get Data / Excel Workbook) → Import options (import worksheet data / or import a Table / or import from the Data Model) → Refresh (if the Excel file is on OneDrive / Power BI can refresh from it automatically) → Publish Excel to Power BI Service (from Excel: File / Publish / Upload to Power BI) → Analyse in Excel (from Power BI Service: open a dataset / Analyse in Excel — connects to Excel for PivotTable analysis) → Live connection (Power BI can connect live to an Excel Data Model on SharePoint) → Data type handling (Excel formats import differently — verify date and number formats after import).

## Step 3 — Quality & Polish

- Tables import more reliably than worksheets: always use Excel Tables as the Power BI data source
- OneDrive refresh: if the Excel file is on OneDrive Power BI can refresh automatically
- Analyse in Excel: use Power BI datasets in Excel PivotTables — the best of both tools

Always offer a relevant next step or tip to try.
