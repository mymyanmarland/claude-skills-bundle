# Advanced Data Visualisation in Excel Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level
- Specific task
- Data type
- Intended output

## Step 2 — Core Output

Advanced Excel data visualisation: Waterfall chart (Insert / Waterfall — shows sequential increases and decreases / running total) → Funnel chart (sales or conversion funnel visualisation) → Treemap (hierarchical proportional area chart) → Sunburst chart (multi-level hierarchical pie chart) → Box and whisker (statistical distribution chart) → Map chart (Choropleth: colour-coded geographic map — requires geography data types) → Bullet chart (bar chart with a target marker — built from stacked bars) → Marimekko / Mekko chart (proportional column chart — requires helper columns and careful construction).

## Step 3 — Quality & Polish

- Waterfall for variance analysis: the most useful chart for showing the components of change
- Map chart for geographic data: Excel's geography data type enables Choropleth maps with one click
- Bullet chart via stacked bar: requires construction but the most informative KPI chart type
