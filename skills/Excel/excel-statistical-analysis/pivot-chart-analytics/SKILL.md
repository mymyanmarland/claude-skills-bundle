# PivotChart Analytics Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level
- Specific task
- Data type
- Intended output

## Step 2 — Core Output

PivotChart analytics: Create PivotChart (click PivotTable / PivotTable Analyze / PivotChart / select chart type) → PivotChart fields (same as PivotTable / drag fields to Axis / Legend / Values / Filters) → Interactive filtering (PivotChart filters update the chart / slicers on PivotTables also update PivotCharts) → Change chart type (right-click chart / Change Chart Type) → Move to its own sheet (right-click chart / Move Chart / New Sheet — for a full-screen interactive chart) → PivotChart limitations (fewer formatting options than standard charts / cannot use all chart types).

## Step 3 — Quality & Polish

- Slicers update PivotCharts automatically: connecting a slicer to a PivotTable updates its PivotChart
- Move to its own sheet for dashboards: a dedicated chart sheet is cleaner than a chart in a worksheet
- Change chart type after creation: choose the chart type that best communicates the data
