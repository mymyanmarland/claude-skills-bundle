# Descriptive Statistics in Excel Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level
- Specific task
- Data type
- Intended output

## Step 2 — Core Output

Descriptive statistics: Data Analysis ToolPak (File / Options / Add-ins / Analysis ToolPak / enable) → Descriptive Statistics tool (Data / Data Analysis / Descriptive Statistics / select range / check Summary Statistics) → Output includes (mean / median / mode / standard deviation / variance / min / max / count / skewness / kurtosis) → Manual equivalents (AVERAGE / MEDIAN / MODE.SNGL / STDEV.S / VAR.S / MIN / MAX / COUNT / SKEW / KURT) → Population vs sample (STDEV.S for a sample / STDEV.P for the whole population) → Percentiles (PERCENTILE.INC / QUARTILE.INC for quartile analysis).

## Step 3 — Quality & Polish

- Analysis ToolPak for one-click descriptive stats: faster than individual functions
- STDEV.S for samples: most real-world data is a sample not the full population
- Skewness: positive skew means the tail is on the right / negative on the left
