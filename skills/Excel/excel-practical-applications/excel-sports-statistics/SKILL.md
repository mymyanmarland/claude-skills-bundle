# Sports Statistics Tracking Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level
- Specific task
- Data type
- Intended output

## Step 2 — Core Output

Sports statistics in Excel: Match log (date / opponent / venue / result / score) → Player statistics (games played / runs/goals/points / averages) → League table (SUMIF for wins/draws/losses/points / RANK for position) → Performance trends (line chart of key metric over time) → Head-to-head records (COUNTIFS: opponent × result) → Top performers (LARGE function for top scorers) → Team form (last 5 matches / OFFSET to the last 5 rows) → Season summary (SUMIF and AVERAGEIF by season) → Conditional formatting (highlight wins green / losses red).

## Step 3 — Quality & Polish

- RANK for league position: automatically reorders when points change
- OFFSET for last 5 matches: dynamic form table that always shows the most recent results
- COUNTIFS for head-to-head: filter by opponent AND result simultaneously
