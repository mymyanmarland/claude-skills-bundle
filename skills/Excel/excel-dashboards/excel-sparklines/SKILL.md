# Sparklines and Mini Charts Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Sparklines: Create (select the destination cell / Insert / Sparklines / select Line, Column, or Win/Loss / select data range) → Sparkline types (Line: trends / Column: comparison / Win/Loss: positive vs negative) → Formatting (Sparkline tab / style / markers / colour / high and low point markers) → Axis settings (Sparkline Axis / Same for All — compare sparklines on the same scale) → Date axis (if the data has irregular dates / set the date axis for accurate proportions) → Group sparklines (sparklines in a group share the same axis — essential for comparison) → Clear sparklines (right-click / Sparklines / Clear).

## Step 3 — Quality & Polish

- Same axis for all sparklines: different axes make comparison meaningless
- High and low point markers: the most useful sparkline visual enhancement
- Group sparklines before formatting: changes apply to the whole group at once
