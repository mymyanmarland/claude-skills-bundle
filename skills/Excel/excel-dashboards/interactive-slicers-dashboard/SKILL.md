# Interactive Slicers for Dashboards Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Interactive slicers: Create slicer (click any PivotTable / PivotTable Analyze / Insert Slicer) → Connect to multiple PivotTables (right-click slicer / Report Connections / check all connected PivotTables) → Format slicers (Slicer tab / style / columns / button size) → Timeline slicer (for date fields — a visual date range selector) → Slicer-driven charts (charts based on PivotTables automatically respond to slicer changes) → Hide the PivotTables (move PivotTables to a hidden sheet / slicers still control them) → Slicer reset button (a macro button that clears all slicer selections).

## Step 3 — Quality & Polish

- Report Connections for multi-table control: the foundation of an interactive dashboard
- Hide PivotTables on a separate sheet: slicers still work — keeps the dashboard clean
- Slicer columns setting: multi-column slicers take less vertical space

Always offer a relevant next step or tip to try.
