# Dashboard Navigation and UX Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Dashboard navigation: Hyperlink navigation (Insert / Hyperlink / Place in This Document / select a sheet or cell) → Button shapes (Insert / Shapes / assign hyperlink or macro) → Consistent nav bar (a row of navigation buttons at the top of every sheet) → Back button (link back to the main dashboard from every detail sheet) → Tab colour coding (right-click sheet tab / Tab Color — colour-code by category) → Hide detail sheets (right-click tab / Hide — users navigate through buttons not tabs) → Sheet protection (Review / Protect Sheet — prevent accidental editing of the dashboard).

## Step 3 — Quality & Polish

- Hide detail sheets from tab view: button navigation is cleaner than tab navigation
- Consistent nav bar on every sheet: users always know how to return to the home dashboard
- Protect the dashboard sheet: prevents accidental overwrites of formula cells

Always offer a relevant next step or tip to try.
