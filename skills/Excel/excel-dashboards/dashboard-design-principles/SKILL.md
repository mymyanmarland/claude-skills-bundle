# Dashboard Design Principles Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Dashboard design principles: One-screen rule (all key information visible without scrolling) → Hierarchy (most important KPIs at the top-left — the eye reads top-left first) → Colour restraint (2-3 colours maximum / use colour to signal meaning not decoration) → Consistent formatting (same font / same chart style / same grid alignment throughout) → Data separation (keep raw data on a separate sheet — the dashboard sheet contains only charts and summary cells) → Named ranges for all data inputs (formulas reference names not cell addresses) → Version control (include a last-updated date and a version number on the dashboard).

## Step 3 — Quality & Polish

- Raw data on a separate sheet: never display raw data on the dashboard sheet
- One-screen rule: scrolling breaks the dashboard experience
- 2-3 colours maximum: more colours create visual noise not information
