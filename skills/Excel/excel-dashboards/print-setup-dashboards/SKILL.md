# Print and PDF Setup for Dashboards Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Print and PDF setup: Page Layout view (View / Page Layout — shows exactly how the sheet will print) → Print Area (Page Layout / Print Area / Set Print Area — limits printing to the dashboard) → Page setup (Page Layout / Page Setup: Orientation / Scaling / Margins) → Fit to page (Page Setup / Scaling / Fit to 1 page wide) → Header and footer (Insert / Header and Footer — add company name / date / page number) → Print titles (Page Layout / Print Titles — repeat rows or columns on every page) → Export as PDF (File / Export / Create PDF — the most reliable PDF method from Excel).

## Step 3 — Quality & Polish

- Set Print Area first: prevents accidental printing of data sheets
- Fit to 1 page wide: the most common print setting for dashboards
- File / Export PDF: more reliable than printing to a PDF printer driver
