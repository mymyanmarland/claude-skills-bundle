# Excel Shortcuts and Productivity Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel shortcuts and productivity: Navigation (Ctrl+Arrow: jump to last data / Ctrl+Home/End: first/last cell / Ctrl+G: Go To) → Selection (Ctrl+Shift+Arrow: select to last data / Ctrl+Space: select column / Shift+Space: select row) → Editing (F2: edit cell / Ctrl+D: fill down / Ctrl+R: fill right / Ctrl+': copy formula from above) → Formatting (Ctrl+1: Format Cells / Ctrl+B/I/U: bold/italic/underline / Alt+H+H: fill colour) → Formulas (F4: toggle absolute reference / Alt+=: AutoSum / Ctrl+Shift+Enter: array formula) → Workbook (Ctrl+N: new / Ctrl+W: close / Ctrl+Page Up/Down: switch sheets) → Quick Access Toolbar (add frequent commands / Alt+1 / Alt+2 etc.).

## Step 3 — Quality & Polish

- Ctrl+Arrow to navigate: jumping to the last data cell is the most used navigation shortcut
- F4 to toggle absolute reference: the most important formula shortcut
- Quick Access Toolbar customisation: put your 5 most-used commands on the QAT

Always offer a relevant next step or tip to try.
