# Microsoft 365 New Functions Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Microsoft 365 new functions: XLOOKUP (replaces VLOOKUP — any direction / built-in error handling) → XMATCH (replaces MATCH — more options) → FILTER (returns rows meeting a condition) → SORT / SORTBY (dynamic sort) → UNIQUE (returns unique values) → SEQUENCE (generate number sequences) → LAMBDA / LET (custom functions / named intermediate values) → TEXTSPLIT / TEXTBEFORE / TEXTAFTER (text parsing) → VSTACK / HSTACK (stack ranges vertically / horizontally) → TOCOL / TOROW (convert a range to a column or row) → CHOOSECOLS / CHOOSEROWS (select specific columns or rows from a range).

## Step 3 — Quality & Polish

- XLOOKUP replaces VLOOKUP: learn XLOOKUP first if you are on Microsoft 365
- FILTER is the most impactful: replaces complex array formulas with a single readable function
- Check version compatibility: these functions do not exist in Excel 2019 or earlier
