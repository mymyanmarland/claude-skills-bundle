# Excel Data Import and Connections Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel data import: From CSV/Text (Data / From Text/CSV / Power Query opens for transformation before loading) → From Web (Data / From Web / paste URL — scrapes HTML tables) → From SQL Server (Data / Get Data / From Database / From SQL Server — connect with credentials) → From SharePoint / OneDrive (Data / Get Data / From Online Services / SharePoint) → From JSON / XML (Data / Get Data / From File / From JSON) → Refresh connections (Data / Refresh All — updates all Power Query and pivot connections) → Connection properties (Data / Queries and Connections — manage all data connections) → Automatic refresh (connection properties / refresh every N minutes).

## Step 3 — Quality & Polish

- Power Query for all imports: use Power Query for every import — not the legacy import wizard
- Refresh All for all connections: one click updates everything — schedule it
- Connection properties for automatic refresh: dashboards that refresh automatically require this setting

Always offer a relevant next step or tip to try.
