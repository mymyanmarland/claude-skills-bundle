# Advanced PivotTable Techniques Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Advanced PivotTables: Slicers (PivotTable Analyze / Insert Slicer / visual buttons for filtering) → Timeline (Insert Timeline — filter by date range with a visual slider) → Connecting slicers to multiple PivotTables (right-click slicer / Report Connections — one slicer filters several tables) → Show Values As (% of Total / % of Row Total / Running Total / Difference From — right-click a value field) → Conditional formatting on PivotTables (works on values in the data area) → GETPIVOTDATA (referencing a PivotTable value in a formula — toggle off in PivotTable Options if intrusive).

## Step 3 — Quality & Polish

- Slicers connected to multiple PivotTables: the foundation of an interactive dashboard
- Show Values As percentage: transforms raw numbers into meaningful proportions instantly
- Disable GETPIVOTDATA if it causes formula issues: PivotTable Options / uncheck Generate GetPivotData

Always offer a relevant next step or tip to try.
