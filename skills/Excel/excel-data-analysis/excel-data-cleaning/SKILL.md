# Data Cleaning in Excel Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Data cleaning: Remove Duplicates (Data / Remove Duplicates / select the columns to check) → Find and Replace (Ctrl+H / replace content across the sheet) → Text to Columns (split one column into multiple: Data / Text to Columns / delimiter or fixed width) → Flash Fill (Ctrl+E / pattern-based automatic fill — extracts or combines text intelligently) → TRIM and CLEAN (TRIM removes extra spaces / CLEAN removes non-printing characters) → Standardise case (PROPER / UPPER / LOWER) → Fix date formats (text-formatted dates: Text to Columns / date format column) → Data Validation to prevent future issues.

## Step 3 — Quality & Polish

- Flash Fill: the fastest data cleaning tool in Excel — pattern-based and intelligent
- TRIM then compare: lookup failures on clean-looking data are almost always hidden spaces
- Text to Columns for dates: fixes text-formatted dates that formulas cannot read

Always offer a relevant next step or tip to try.
