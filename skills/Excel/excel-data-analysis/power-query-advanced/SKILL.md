# Advanced Power Query Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Advanced Power Query: Append Queries (stack two tables with the same columns vertically) → Merge Queries (join two tables on a common key — like a JOIN in SQL) → Join types (Left Outer / Inner / Full Outer / Anti-join) → Group By (Group By / sum or count by a category — equivalent to a PivotTable without loading to the sheet) → Custom Column (Add Column / Custom Column / write an M language expression) → M language (each step is M code / Advanced Editor shows the full script) → Parameters (create a query parameter / reference it in filter steps — dynamic queries) → Reference vs Duplicate (Reference: query based on another / Duplicate: independent copy).

## Step 3 — Quality & Polish

- Merge vs Append: Merge joins columns / Append stacks rows — know which you need
- Group By in Power Query: the most powerful aggregation that stays in the query
- Parameters for dynamic queries: change a parameter value to change the query behaviour

Always offer a relevant next step or tip to try.
