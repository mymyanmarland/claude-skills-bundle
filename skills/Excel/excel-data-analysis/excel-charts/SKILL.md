# Excel Charts and Visualisation Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel charts: Recommended Charts (select data / Insert / Recommended Charts — Excel suggests appropriate types) → Chart types (Column/Bar for comparison / Line for trends / Pie for composition — use sparingly / Scatter for correlation) → Chart formatting (double-click any element to format it) → Secondary axis (right-click a data series / Format Data Series / Secondary Axis — for different-scale data) → Dynamic chart range (use a Table as the data source — chart expands automatically) → Sparklines (Insert / Sparklines — tiny charts within cells) → Chart templates (save a formatted chart as a template for reuse).

## Step 3 — Quality & Polish

- Table as chart data source: chart automatically includes new rows — no manual range updates
- Double-click any chart element to format it: the fastest route to chart customisation
- Secondary axis for different scales: without it one series dwarfs the other

Always offer a relevant next step or tip to try.
