# Sorting and Filtering Data Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Sorting and filtering: Sort (Data / Sort / multiple levels / custom list sort) → AutoFilter (Ctrl+Shift+L / dropdown arrows appear / filter by value / by colour / by condition) → Filter by condition (Number Filters / Text Filters / Date Filters — contains / greater than / between) → Sort by colour (useful if cells are colour-coded) → Clear filter (Alt+Down on a filter arrow / Clear Filter) → Advanced Filter (Data / Advanced / filter in place or to a new location / use criteria range) → SORT function (=SORT(array, col, order) — dynamic sort that updates automatically).

## Step 3 — Quality & Polish

- Ctrl+Shift+L to toggle AutoFilter: the fastest way to add or remove filter arrows
- SORT function in Microsoft 365: dynamic sort — updates automatically when data changes
- Advanced Filter for complex criteria: multiple conditions that AutoFilter cannot handle

Always offer a relevant next step or tip to try.
