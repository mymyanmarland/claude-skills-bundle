# What-If Analysis in Excel Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

What-if analysis: Goal Seek (Data / What-If / Goal Seek — set a cell to a target value by changing another cell) → Data Table (test how one or two inputs affect a formula — one-variable or two-variable) → Scenario Manager (Data / What-If / Scenario Manager — save multiple sets of input values / generate a summary report) → Solver (complex optimisation: maximise/minimise a cell / subject to constraints — requires the Solver add-in) → Sensitivity analysis (Data Table with one or two variables showing the output range) → Use cases (break-even analysis / loan payment scenarios / profit optimisation).

## Step 3 — Quality & Polish

- Goal Seek for reverse calculation: find what input produces a target output
- Data Table for sensitivity: shows the full range of outcomes without changing anything permanently
- Solver for optimisation: the most powerful what-if tool — requires multiple constraints

Always offer a relevant next step or tip to try.
