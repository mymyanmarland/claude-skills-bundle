# Pivot Tables Basics Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

PivotTable basics: Create PivotTable (select data / Insert / PivotTable) → Four areas (Rows / Columns / Values / Filters — drag fields into each area) → Value summarisation (default is SUM / right-click value / Value Field Settings / change to COUNT/AVERAGE/MAX) → Row and Column grouping (right-click a date field / Group — groups by month/quarter/year) → Filter (drag a field to the Filter area / use the dropdown to filter the whole PivotTable) → Refresh (PivotTables do not auto-update / right-click / Refresh after data changes) → Calculated Field (PivotTable Analyze / Fields Items & Sets / Calculated Field).

## Step 3 — Quality & Polish

- Refresh after data changes: the most commonly forgotten PivotTable step
- Value Field Settings: the SUM default is not always appropriate — check and change
- Group dates to months/years: the most common PivotTable transformation for time-series data

Always offer a relevant next step or tip to try.
