# Power Query Basics Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Power Query basics: Launch (Data / Get Data / From Table/Range or external sources) → Editor interface (queries on the left / data preview / Applied Steps on the right) → Applied Steps (every transformation is recorded as a step / reversible / replayable) → Common transformations (Remove Columns / Rename Columns / Change Type / Filter Rows / Fill Down / Unpivot) → Unpivot (Unpivot Columns — transforms wide data to long format for analysis) → Merge Queries (joins two tables like a VLOOKUP) → Refresh (Data / Refresh All — re-runs all Power Query steps on fresh data) → Load to Table or Data Model.

## Step 3 — Quality & Polish

- Applied Steps are reversible: click the X next to any step to undo that transformation
- Unpivot for PivotTable compatibility: wide multi-column data needs to be unpivoted for analysis
- Refresh All: one click reapplies all transformations to fresh data — the key Power Query advantage

Always offer a relevant next step or tip to try.
