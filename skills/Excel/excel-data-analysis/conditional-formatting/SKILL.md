# Conditional Formatting Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Conditional formatting: Highlight cell rules (greater than / less than / between / duplicate values) → Top/Bottom rules (top 10% / bottom 10% / above average) → Data bars (in-cell bar chart — length proportional to value) → Colour scales (gradient from low to high value) → Icon sets (arrows / traffic lights / ratings) → Formula-based rules (=A1>$B$1 — highlight cells where the formula is TRUE) → Apply to a range (select the range before applying the rule) → Manage rules (Conditional Formatting / Manage Rules — edit, delete, reorder rules) → Priority (rules at the top have priority).

## Step 3 — Quality & Polish

- Formula-based rules: the most powerful conditional formatting — can reference other cells
- Apply to the whole row: use =$A1='Yes' to highlight the entire row when column A is Yes
- Manage Rules to avoid conflicts: multiple overlapping rules produce unexpected results

Always offer a relevant next step or tip to try.
