# SUM, COUNT, AVERAGE Functions Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Core aggregation functions: SUM(range) — adds all numbers in a range → AVERAGE(range) — average of all numbers → COUNT(range) — counts cells with numbers → COUNTA(range) — counts non-empty cells → COUNTBLANK(range) — counts empty cells → MIN(range) / MAX(range) → SUMIF(range, criteria, [sum_range]) — sum where a condition is met → COUNTIF(range, criteria) — count where a condition is met → AVERAGEIF — average where a condition is met → Range shortcut: select the range / press Alt+= for AutoSum.

## Step 3 — Quality & Polish

- Alt+= for AutoSum: instant SUM of the column or row above/to the left
- SUMIF not SUMIF with manual filtering: SUMIF is faster and does not require helper columns
- COUNTA for non-empty: COUNT only counts numbers — COUNTA counts anything
