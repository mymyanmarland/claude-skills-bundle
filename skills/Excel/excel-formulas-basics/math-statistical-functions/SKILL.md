# Math and Statistical Functions Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Math and statistical functions: ROUND(number, digits) / ROUNDUP / ROUNDDOWN → INT(number) — rounds down to the nearest integer → MOD(number, divisor) — the remainder after division → RAND() / RANDBETWEEN(min, max) — random numbers → RANK(number, ref, [order]) — rank within a list → MEDIAN(range) — middle value → MODE(range) — most frequent value → PERCENTILE(array, k) — the value at the kth percentile → STDEV(range) — standard deviation → LARGE / SMALL(array, k) — the kth largest/smallest value.

## Step 3 — Quality & Polish

- ROUNDUP vs CEILING: ROUNDUP always rounds away from zero / CEILING rounds to a multiple
- RAND recalculates on every change: paste as values to freeze random numbers
- LARGE and SMALL for top N: extract the top or bottom values without sorting
