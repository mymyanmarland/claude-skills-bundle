# Excel Formula Fundamentals Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Formula fundamentals: All formulas start with = → Cell references (A1 / $A$1 absolute / A$1 mixed) → Arithmetic operators (+ - * / ^ for power / & for text) → Order of operations (PEMDAS: parentheses / exponents / multiply/divide / add/subtract) → Relative vs absolute reference (relative: changes when copied / absolute $A$1: stays fixed) → Pressing F2 to enter edit mode → Pressing F4 to cycle through reference types ($A$1 → A$1 → $A1 → A1) → Formula bar (always shows the formula / not the result).

## Step 3 — Quality & Polish

- F4 to toggle absolute references: the single most important formula shortcut
- Relative moves, absolute stays: understand this and 80% of formula errors are preventable
- Formula bar shows the formula: always check the bar when a cell looks wrong
