# Named Ranges and Excel Tables Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Named ranges and Tables: Define Name (Formulas / Define Name / type a name for a cell or range) → Use names in formulas (=SUM(SalesData) instead of =SUM(B2:B100)) → Name Manager (Formulas / Name Manager — view, edit, delete names) → Excel Tables (Ctrl+T / converts a range to a Table with auto-filtering and structured references) → Structured references (Table1[Column1] instead of $A$2:$A$100 — dynamically expands with the Table) → Total Row (Table Tools Design / Total Row — auto-calculated totals) → Table naming (Properties / Table Name — rename for readability).

## Step 3 — Quality & Polish

- Excel Tables auto-expand: new rows are automatically included in formulas — the most important Table advantage
- Named ranges make formulas readable: =SalesTotal-CostOfGoods reads better than =B2-C2
- Structured references over absolute ranges: Table references update automatically when rows are added
