# Excel Macro Basics Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Macro basics: Enable the Developer tab (File / Options / Customize Ribbon / check Developer) → Record Macro (Developer / Record Macro / name it / assign a shortcut / record your actions / Stop Recording) → Run a macro (Developer / Macros / select / Run / or the keyboard shortcut) → Macro storage (This Workbook: only available in this file / Personal Macro Workbook: available in all Excel files) → Macro security (File / Options / Trust Center / Macro Settings — enable only trusted macros) → View code (Developer / Visual Basic — see the recorded VBA) → Relative recording (Developer / Use Relative References — records relative movements not absolute cell addresses).

## Step 3 — Quality & Polish

- Use Relative References for flexible macros: absolute references only work in the exact recorded position
- Personal Macro Workbook for reusable macros: saves to PERSONAL.XLSB — available in all Excel files
- Review the recorded VBA: recorded code is often inefficient — understanding it is the first step to improving it

Always offer a relevant next step or tip to try.
