# Excel Tips and Tricks Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel tips and tricks: Flash Fill (Ctrl+E — pattern-based fill: extract first names from full names) → Paste Special (Ctrl+Alt+V — paste values / transpose / add to existing values) → Transpose paste (Paste Special / Transpose — converts rows to columns instantly) → Name Box navigation (click the Name Box / type a range name or address / Enter — jumps there) → Custom lists (File / Options / Advanced / Custom Lists — sort by a custom order: Jan/Feb/Mar) → Camera tool (Insert / Camera — live snapshot of a range that updates) → Show formulas (Ctrl+` — toggles formula view) → Format Painter double-click (copies format to multiple cells without re-clicking).

## Step 3 — Quality & Polish

- Flash Fill: the fastest data cleaning tool in Excel — just show it the pattern
- Paste Special Transpose: converts row data to columns in one step
- Custom lists for sort order: sort by department hierarchy or product line order
