# Professional Excel Formatting Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Professional formatting: Font consistency (one sans-serif font throughout / 10-11pt body / 12-14pt headers) → Colour palette (2-3 colours maximum / one accent colour / grey for secondary information) → Number formats (Ctrl+1: format cells / commas for thousands / 0 decimal places for whole numbers / negative numbers in red or brackets) → Cell alignment (numbers right-aligned / text left-aligned / headers centred) → Remove gridlines (View / Show / Gridlines — uncheck) → Borders (thin borders only where they add clarity / not every cell) → Print view (Page Layout view / check before sharing) → Remove sheet tabs (if using as a report: hide all sheets except the output).

## Step 3 — Quality & Polish

- One font throughout: mixing fonts is the most visible sign of amateur formatting
- Remove gridlines: a gridline-free report looks dramatically more professional
- Numbers right-aligned: the universal formatting standard for financial data
