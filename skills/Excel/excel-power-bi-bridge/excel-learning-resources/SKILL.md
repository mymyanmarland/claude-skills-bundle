# Excel Learning Resources Skill

- Excel version and platform

Excel learning resources: Microsoft Learn (free / official / structured courses for all levels) → Chandoo.org (practical Excel tutorials / especially strong for dashboards and charting) → ExcelJet (formula reference / the best single formula reference site) → Mr Excel forum (community Q&A / answer any Excel question) → Mynda Treacy / MyOnlineTrainingHub (video courses / Power Query and Power BI focused) → Excel Exposure (free structured curriculum for beginners) → Practice with real data (Kaggle / government open data — apply skills to real datasets) → Certification (Microsoft Office Specialist MOS Excel — the recognised credential).
