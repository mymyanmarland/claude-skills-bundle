# Excel to Power BI Transition Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel to Power BI: When Excel is better (ad-hoc analysis / small datasets / sharing with everyone / calculations that need editing / personal productivity) → When Power BI is better (large datasets / real-time refresh / enterprise sharing / mobile access / advanced visuals / row-level security) → Skill transfer (Power Query: identical in both / DAX: same language in Power Pivot and Power BI / PivotTable → visual / Excel chart → Power BI visual) → Excel in Power BI (analyse in Excel: connect Power BI datasets to Excel for PivotTables) → Power BI Desktop (free download / connects to most data sources).

## Step 3 — Quality & Polish

- Power Query skills transfer directly: the same M language in both tools
- DAX skills transfer: Power Pivot DAX is the same as Power BI DAX
- Analyse in Excel: use Power BI datasets in Excel PivotTables — best of both worlds
