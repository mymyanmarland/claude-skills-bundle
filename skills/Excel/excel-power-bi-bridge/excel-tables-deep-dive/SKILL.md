# Excel Tables Deep Dive Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel Tables deep dive: Create (Ctrl+T / the table takes the range and adds headers) → Auto-expand (new rows and columns automatically become part of the Table) → Structured references (Table1[Column] references the entire column / Table1[@Column] references the current row) → Total Row (Toggle: Table Design / Total Row / dropdown selects SUM/COUNT/AVERAGE etc) → Filter and sort (AutoFilter automatically added to headers) → Remove duplicates (Table Design / Remove Duplicates) → Slicer (Table Design / Insert Slicer — works on Tables as well as PivotTables) → Convert back (Table Design / Convert to Range — removes Table formatting).

## Step 3 — Quality & Polish

- Auto-expand is the Tables superpower: formulas and charts based on a Table never need updating
- Structured references: Table1[Sales] is always the whole Sales column — even when rows are added
- Total Row dropdown: built-in aggregations with a single click per column
