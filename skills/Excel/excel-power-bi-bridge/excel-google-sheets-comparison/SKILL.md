# Excel vs Google Sheets Skill

## Step 1 — Gather Inputs

- Excel version and platform
- Experience level: beginner/intermediate/advanced
- Specific task or use case
- Data type and approximate size
- Intended output or deliverable

## Step 2 — Core Output

Excel vs Google Sheets: Collaboration (Google Sheets: real-time collaboration for everyone / Excel: OneDrive co-authoring for Microsoft 365 users) → Features (Excel: more powerful for analysis / more functions / Power Query / VBA / Data Model / Google Sheets: simpler / Google Apps Script / QUERY function) → Cost (Google Sheets: free / Excel: Microsoft 365 subscription or one-time purchase) → Offline (Excel: full offline support / Google Sheets: limited offline capability) → Integration (Google Sheets: Google Workspace / Excel: Microsoft 365) → Performance (Excel: handles larger datasets / Google Sheets: starts slowing at ~100,000 rows) → Choose based on workflow not features.

## Step 3 — Quality & Polish

- Collaboration drives the choice: if the team uses Google Workspace use Sheets
- Excel for analysis: Power Query, VBA, and Data Model have no Sheets equivalent
- Google Sheets QUERY function: SQL-like queries on sheet data — a unique Sheets advantage
