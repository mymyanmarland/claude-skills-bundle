# Sales Cadence Designer Skill

## Step 1 — Gather Inputs

- Prospect type (cold/warm/inbound)
- Channel mix (email/phone/LinkedIn/video)
- Industry and prospect seniority
- Deal size
- Current reply rates

## Step 2 — Core Output

Cadence design: Touch count by prospect type (cold: 8-12 / warm: 5-7 / inbound: 3-5) → Channel sequence (email → LinkedIn → call → video) → Timing between touches → Value escalation (each touch adds something new) → Breakup message design → Cadence automation vs manual decision → A/B testing approach → Metrics to optimize.

## Step 3 — Quality & Polish

- Each touch adds new value — not same message
- Channel variety — not all email
- Breakup message genuine — with door-open option

Always offer a relevant next step.
