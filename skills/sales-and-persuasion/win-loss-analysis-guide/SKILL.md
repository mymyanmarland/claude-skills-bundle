# Win-Loss Analysis Guide Skill

## Step 1 — Gather Inputs

- Deal types and sizes
- Sales team size
- Data available
- Current analysis approach
- Decisions this will inform

## Step 2 — Core Output

Win-loss program: Interview methodology (neutral third party ideally) → Questions to ask won accounts → Questions to ask lost accounts → What to ask vs what not to (avoid defensiveness) → Analysis framework (themes across deals) → Internal findings sharing → Action recommendations from findings → Cadence (quarterly analysis) → Using insights to change sales process.

## Step 3 — Quality & Polish

- Third party interviews get more honest answers
- Won deals analyzed as carefully as lost — we learn from wins
- Action recommendations from data — not just interesting findings

Always offer a relevant next step.
