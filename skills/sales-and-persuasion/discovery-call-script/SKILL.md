# Discovery Call Script Skill

## Step 1 — Gather Inputs

- Product or service
- Target customer type
- Deal size and complexity
- Sales cycle length
- Common objections

## Step 2 — Core Output

Discovery call script: Opening (set the agenda — take control professionally) → Company context questions (2-3 max) → Problem discovery (open → specific → impact) → Current solution probe → Decision process questions (who/how/when) → Budget qualification (indirect) → Next step proposal (always end with a defined next step). MEDDIC elements woven throughout.

## Step 3 — Quality & Polish

- Problem questions open then funnel to specifics
- Impact questions quantify the pain — key for later proposal
- Next step proposed by rep — not left to prospect

Always offer a relevant next step.
