# Sales Forecast Guide Skill

## Step 1 — Gather Inputs

- Deal types and sizes
- Sales cycle length
- Current pipeline stages
- Historical win rates
- Reporting frequency

## Step 2 — Core Output

Forecasting system: Pipeline stage definitions (specific exit criteria per stage) → Win rate by stage (historical) → Weighted pipeline calculation → Commit vs best case vs pipeline categories → Deal inspection questions (what must be true to close this quarter?) → Forecast accuracy tracking → How to improve accuracy over time → CRM hygiene requirements.

## Step 3 — Quality & Polish

- Stage exit criteria specific — prevents premature advancement
- Historical win rates used — not optimistic assumptions
- Deal inspection questions reveal committed vs hoped deals

Always offer a relevant next step.
