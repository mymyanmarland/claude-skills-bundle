# Pipeline Management Guide Skill

## Step 1 — Gather Inputs

- CRM in use
- Deal types and sizes
- Sales cycle length
- Current pipeline problems
- Forecast accuracy

## Step 2 — Core Output

Pipeline management: Pipeline coverage ratio (3-4× quota in pipeline needed) → Stage progression rules (no deal sits more than [X] days without movement) → Pipeline review cadence (weekly individual, monthly full) → Deal aging alerts → Stuck deal protocol (what to do when deals stall) → Closed-lost analysis → Pipeline generation habits → Data hygiene requirements.

## Step 3 — Quality & Polish

- Coverage ratio specific — 3-4× quota is the target
- Deal aging alerts automated if possible
- Closed-lost analysis drives process improvement

Always offer a relevant next step.
