# LinkedIn Sales Navigator Guide Skill

## Step 1 — Gather Inputs

- Target prospect type
- Industry and geography
- Deal size
- Current LinkedIn activity
- Outreach capacity

## Step 2 — Core Output

Sales Navigator guide: ICP filter setup → Saved searches and alerts → Lead and account lists → InMail strategy (when and how) → Connection request sequencing → Activity feed for trigger events → TeamLink for warm intros → Integration with CRM → Social selling index improvement. Outreach sequences for different prospect types.

## Step 3 — Quality & Polish

- Trigger events used for timely outreach — not random
- Warm intros through TeamLink prioritized
- InMail reserved for when connection request won't work

Always offer a relevant next step.
