# Sales Data Analytics Guide Skill

## Step 1 — Gather Inputs

- CRM in use
- Data available
- Decision to make from data
- Team size
- Reporting audience

## Step 2 — Core Output

Sales analytics guide: Leading indicator identification (what predicts quota attainment) → Activity metrics vs outcome metrics → Cohort analysis (are newer reps performing like older ones?) → Win rate by source/segment/rep → Sales cycle analysis → Forecast accuracy tracking → Top performer pattern identification → Dashboard design for sales leaders vs reps.

## Step 3 — Quality & Polish

- Leading indicators — predict future, don't just measure past
- Top performer patterns identified and replicated
- Dashboard different for leaders vs reps — different decisions

Always offer a relevant next step.
