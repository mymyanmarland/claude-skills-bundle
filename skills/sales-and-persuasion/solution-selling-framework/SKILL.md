# Solution Selling Framework Skill

## Step 1 — Gather Inputs

- Product complexity
- Buyer sophistication
- Deal size
- Implementation involved
- Sales cycle length

## Step 2 — Core Output

Solution selling: Pain → Reason → Impact → Vision → Value chain → Solution → ROI. Customer-needs focus (diagnose before prescribing) → Pain questioning (surface, diagnose, impact) → Vision creation (help them see the solution before seeing the product) → Value proposition tailored to their specific situation → ROI methodology → Implementation planning as closing tool.

## Step 3 — Quality & Polish

- Pain fully diagnosed before solution introduced
- Vision created — buyer sees themselves succeeding before seeing product
- ROI methodology specific to their situation — not generic

Always offer a relevant next step.
